여기 있는 것은 전부 되돌릴 수 있거나 읽기만 합니다. 되돌릴 수 없는 것은 CLI 에만 둡니다 — 전면 재수집 · DB 초기화가 그것입니다.

점검 — 읽기만 합니다

진단 --diagnose
멈추지 않고 한 번 돌면서 전 결함을 모읍니다. 재수집하지 않고 저장된 원문으로 S4 부터 돕니다. 뿌리가 같은 결함을 묶어 냅니다.
python run.py collect --diagnose
실행 마지막 08-13
무결성 검사
원문 ↔ CORE 대조 · 고아 행 · FK 정합 · 스키마 일치를 봅니다.
python tools/check_src.py && python run.py verify
실행 약 6초
저장 공간
테이블별 크기와 증가 추이를 봅니다.
python run.py stats
보기 1.2GB

정비 — 되돌릴 수 있습니다

스키마 이행 migrate
DDL 을 고쳤을 때 기존 DB 를 따라가게 합니다. 데이터를 지우지 않고 표를 재작성해 옮깁니다. CREATE TABLE IF NOT EXISTS 라 DDL 만 고치면 기존 DB 는 옛 스키마로 남습니다.
python run.py migrate
실행 대기 1건
재파싱
저장된 원문으로 CORE 를 다시 만듭니다. 요청이 나가지 않습니다. 파싱 규칙을 고친 뒤에 씁니다.
python run.py collect --from S4
실행 약 8초
계수 재산출
차종별 감가 보정계수를 실측으로 다시 냅니다. 표본이 100건 미만인 차종은 건너뜁니다.
python run.py coefficient --recalc
실행 계수 #41
백업
DB 를 파일로 내립니다. 실행 중에는 받지 않습니다.
python run.py backup
받기 마지막 08-14

내보내기

데이터 내보내기
매물 · 판정 · 축별 근거를 CSV 로 냅니다. 개인정보는 빠집니다.
python run.py export --format csv
CSV 203건
리포트 재생성
L1~L3 리포트를 다시 만듭니다. 덮어쓰지 않고 새 파일로 냅니다.
python run.py report

여기에 없는 것

아래는 CLI 에서만 합니다.
collect --full 전면 재수집 — 18,800요청 · 되돌릴 수 없습니다
db reset DB 초기화 — 원문이 사라집니다
admin reset 비밀번호 재설정 — 사용자 화면에도 있으나 잠겼을 때는 CLI
버튼이 있으면 「일단 눌러보자」가 됩니다. 원문을 확인한 뒤 손으로 치는 편이 안전합니다.
실행 기록은 audit_request · config_change 에 남습니다
