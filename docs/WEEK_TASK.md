## 3. 이길 조건 — **차값 3,490만** 기준

부대비용(취득세 7% · 매도비 38~44만 · 대행료)은 어디서 사도 거의 같다.
**차값 차이가 곧 총비용 차이다. 차값으로 비교하라.**

```
A. 차값 3,490만 이하  →  주행 3.7만km 이하 + 사고가 더 가벼움
B. 차값 3,490~3,700만 →  주행 2.5만km 이하 또는 사고 0건
C. 차값 3,700~3,900만 →  2023년 이후 등록 + 흰색 + HUD + 진단 + 사고 0건
D. 차값 3,900만 초과  →  올리지 마라
```

**넷 다 아니면 올리지 마라.** 이미 예순 대를 걸렀다.

## 6. 찾는 법 — 순서대로

### 6-1. 아직 안 본 곳부터

```
KB차차차 — GV70 2.5T 675건이 status='new' 에 갇혀 있다
  상세가 안 받아져 active 로 못 올라간 것이다. 제조사·연식·가격이 전부 빈칸이다
  상세 경로: https://www.kbchachacha.com/public/car/detail.kbc?carSeq={id}
  → 이게 열린다. 개발측이 안 받았을 뿐이다
  화면에 나오는 것: 가격 · 연식 · 주행 · 색 · 시트색 · AI 적정시세 범위
  보험사고정보 · 전손 · 침수 · 용도이력 · 소유자변경이 한 줄로 나온다
```

### 6-2. 매물 하나당 확인할 네 가지

```
① 엔카진단 결과 — 코멘트 원문에 「교환」이 적혀 있는지
② 성능점검기록부 — 주요골격 A·B·C랭크 / 점검자 특기사항
③ 보험이력 — 내차피해 금액 · 상대차 피해 · 소유자 변경
④ 정비이력(국토부) — 아래 낱말이 있으면 탈락
```

**정비이력 탈락 낱말**
```
너클 · 로워암 · 래터럴암 · 어퍼암 · 서스펜션 · 쇽업소버 · 스트럿
스티어링기어 · 휠얼라인먼트 · ABS · 캘리퍼 · ECU · 휠(교환)
```
성능점검부가 「골격 무사고」여도 여기서 나오면 하체 사고다.
실제로 110루9860이 그랬다 — 점검부는 깨끗한데 부품값 628만.

### 6-3. 값을 재는 법

```
감가율 = (1 − 판매가 ÷ 신차출고가) × 100
  신차출고가 = 신차정가 + 옵션정가
  엔카 record API 의 firstDate 옆에 신차출고가가 나온다

25% 아래 → 값이 세다. 옵션 대비 확인
65% 넘음 → 반드시 큰 사고가 있다. 오늘 세 대가 그랬다
```

#### 6-4. 차값으로 비교하고, 소모품만 더한다

```
비교 기준 = 차값 + 소모품 예상
```
부대비용은 어디서 사도 같으니 비교에서 뺀다.
**다만 주행거리에 따라 곧 나갈 소모품은 차값에 더해서 봐야 한다.**

**소모품 예상 (주행거리로)**
```
타이어 4짝 19인치  120~150만  ← 4.5만km 넘으면
브레이크 앞뒤       30~50만   ← 5만km 넘으면
```

```

엔카 성능점검  https://api.encar.com/v1/readside/inspection/vehicle/{id}
  헤더 Referer: http://www.encar.com/ 필요
  404 = 이력 없음 / 407 = 일시 차단 (몇 분 뒤 재시도)
  옵션은 choice(선택) 코드만 나온다. HUD 는 컴포트 패키지 기본이라
  standard 에 있을 수 있으니 코드만 보고 「HUD 없음」이라 단정하지 마라

  rvo(기본) · carhistory(보험) · carJatoOptList(선택옵션) · tireDtlList(타이어)
  carOwnrChngHistList(소유자변경) · warrantyInfo(보증연장)
  주의: 사고 금액과 교환 부위는 이 API 가 주지 않는다. 화면을 봐야 한다

  → 이건 전량이 아니다. 439대뿐. 실제 재고는 훨씬 크다

  → 제네시스는 현대(101) 안에 classCode=1132 로 있다
  → makerCode=107 은 BMW 다. 개발측이 이걸로 GV70 을 찾고 있었다

리본카        https://m.reborncar.co.kr/m/smartbuy/SB1002/{id}
702 프라임    수입차 전용. GV70 없음. API 는 401
```

## 8. 보고 형식

**찾은 즉시 보고한다.** 모아서 주말에 내면 늦다.

```
매물 주소 (반드시 포함)
차번 · 등록년월 · 주행 · 색 · 구동 · 트림
★ 차값 (먼저 쓴다) / 신차출고가 / 옵션 / 감가율 / 소모품 예상 / (참고: 총비용)
사고: 내차 N회 N만원 · 교환 N곳 · 판금 N곳 · 골격 여부
이력: 용도변경 · 자차 미가입 개월 · 소유자 변경
진단: 등급 · 코멘트 원문
환불: 며칠 · 전액인지 계약금인지
910점 총점과 갈래별 (value / state / history / warranty / taste)

→ 그리고 한 줄: 「270오1279(★ 차값 3,490만 · 650점)를 무엇으로 이기는가」
```

**이기지 못하면 올리지 마라.** 마스터 시간을 쓰는 일이다.

## 9. 하지 말 것

```
· 「없다」를 한 번 두드리고 단정하지 마라. 오늘만 여러 번 틀렸다
· API 응답만 믿지 마라. K카는 사고 금액을 안 준다
· 선택옵션 코드에 HUD 가 없다고 「HUD 없음」이라 하지 마라
· 감가율이 낮다고 「싸다」로 올리지 마라. 반드시 이유가 있다
· 렌터카라고 빼지 마라. 마스터가 세 번 지적하셨다
· 총비용으로 비교하지 마라. 부대비용은 어디서 사도 같다. ★ 차값으로 비교하라
· 다만 주행 4.5만km 넘는 차는 소모품(타이어·브레이크)을 차값에 더해서 봐라
· 주소 없이 차를 설명하지 마라. 마스터가 확인하실 수 없다
```
