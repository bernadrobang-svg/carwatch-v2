## 결론

★ **볼보 셀렉트는 신차가를 안 준다.** 목록에도 상세에도 없다.

## 무엇을 어떻게 쟀나

### ① 목록 (`/kr/vehicles/xhr-results/{page}`)

카드 한 장의 글자를 통째로 뽑아 낱말을 셌다.

```

- 총 180가지의 기술적 품질 검사 - 무상 보증 수리 서비스 제공
- 24시간 긴급 출동 서비스 제공 - 7일 / 700km 차량 환불 프로그램
- 차량의 정비 이력 및 관련 필요 정보 제공 이미지 5 개 …
```

| 찾은 낱말 | 결과 |
|---|---|
| `신차` | ★ **0회** |
| 「만원」 꼴의 값 | 0회 (값은 `27,000,000원` 꼴이다) |

★ 목록은 ★ **판매가는 준다** — ★ 신차가는 안 준다.

### ② 상세 (`/kr/vehicles/volvo/{모델}/{슬러그}`)

표본으로 `xc60/inscription-b5-awd-mild-hybrid-m1bbhfn` 를 눌렀다 (56,447B).

```
값     34,000,000원
주행   72,729 km
연식   2022
신차   「신차」 낱말 2회 — ★ 둘 다 값이 안 붙어 있다
       (「신차급」·「신차 출고 후」 같은 서술이고 ★ 금액이 아니다)
```

★ 쌓인 상세 원문 **137건**에도 걸어 봤다 —

```
(신차\s*가격|신차\s*가|출고\s*가)[^0-9]{0,12}([\d,]{4,})   → ★ 0건
```

★ 참고 — ★ **현대 인증은 준다** (상세 8/8 · 값이 매물마다 다름).
