# CarWatch 개발 문서

**작업 단위로 쪼갠 지시서. 필요한 파일만 연다.**

```
guide/        공통 — 개요 · 시작하기 · 미확정 · 개정 이력
chapters/     챕터별 기준서.  한 챕터 = 한 소스 디렉터리
ref/          부록 — 검사 규격 · config 예시 · 표본
INDEX.md      어느 파일에 무엇이 있나
MAPPING.md    챕터 ↔ 디렉터리 ↔ 작업 순서
```

---

## 읽는 법

```
처음 한 번    guide/01_시작.md · chapters/00-standard.md · chapters/01-arch.md
작업할 때     T-*.md 에 적힌 파일만
막혔을 때     INDEX.md 로 찾는다
「왜」를 물을 때  guide/03_이력.md
```

```
금지   전체를 여는 것.  49파일 511KB 다
금지   「지시서를 참고하라」로 지시하는 것.  파일명을 적어 준다
```

---

## 이 문서의 성격

```
chapters/     무엇을 만드나 · 어떻게 · 금지        정본
guide/        착수 절차 · 못 정한 것 · 왜 이렇게 됐나
ref/          검사기 · 예시 · 표본                참조
```

```
값이 갈리면 chapters/ 를 따른다
```
