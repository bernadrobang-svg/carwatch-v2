# 끝 신호 (가이드 확정 08-29 · 개정 853)

개발측 물음 — 「`data-found` 가 받은 수와 늘 어긋난다.
총계를 끝 신호로 쓸지, 「링크가 `PAGE_LINKS` 보다 적은 쪽 = 마지막 쪽」을 쓸지 정해 달라」

## 08-29 정정 — 브라우저로 재보고 뒤집는다 (개정 854)

앞서 「쪽 링크를 쓴다」로 정했는데 **틀렸다**.
가이드가 서버에서만 재고 껍데기를 보고 정했다.  브라우저로 그려 보니 다르다.

### 브라우저 실측 (Chromium · 08-29)

```
차종 목록  /kr/vehicles/volvo/{이름}?manufacturer=64&model={코드}
           보기 — /kr/vehicles/volvo/s90?manufacturer=64&model=1323

S90 화면에 「21 차량 검색됨」이 세 번 · data-found="21"
매물 21건이 한 화면에 다 뿌려진다 — 값·연식·주행·연료·장비·딜러까지
쪽 링크는 「page=reset」 하나뿐 — 쪽넘김이 없다  ★ [실측 08-29 — ★ `xhr-results/{n}` 은 ★ **20쪽 · 전량 223건**이다.  ★ 빈 쪽에서 끝났다]

상세 주소  /kr/vehicles/volvo/{모델}/{트림-슬러그}
           보기 — .../s90/inscription-b6-awd-300-hp-aut-p7bbg3v
           끝에 붙은 p7bbg3v 가 매물번호다
           <a href> 가 아니다 — 「전체 상세 정보」를 눌러야 주소가 생긴다
```

## 정한다 — data-found 를 쓴다.  다만 차종별로

```
그 차종 화면의 data-found 와 그 차종에서 받은 매물 수를 견준다
같으면 done=True

쪽넘김이 없으니 「쪽 링크가 줄면 마지막」은 쓸 수 없다
data-found 가 유일한 총계다
```

## 왜 어긋났나

```
data-found 는 그 차종의 대수다.  사이트 전체가 아니다
전체와 견주면 늘 어긋난다 — 개발측이 그렇게 견주고 있었을 것이다
차종별로 견주면 맞는다

「전체 상세 정보」가 24개인데 data-found 는 21이다
접힌 것이나 광고가 섞였을 수 있다 — data-found 를 믿는다
```

## 08-29 정정 — 창구가 둘이다 (개정 855)

개발측이 적은 까닭 — 「마스터께서 브라우저로 보신 모델 화면과 다른 창구입니다.
`<a href>` 가 아니다 → 그건 **모델 화면 이야기**고 **`xhr-results` 에는 `href` 가 있습니다**」

옳다.  가이드가 **모델 화면 하나만 보고** 규격을 적었다.

| 창구 | 무엇 | 쪽넘김 | `href` |
|---|---|---|---|
| 모델 화면 | 사람이 보는 것 · `/kr/vehicles/volvo/{이름}?model={코드}` | 없다 | 없다 |
| `xhr-results` | 기계가 받는 것 | **있다** | **있다** |

```
가이드가 잰 것은 모델 화면이다 — 사람이 보는 자리
개발측이 쓰는 것은 xhr-results 다 — 기계가 받는 자리
둘 다 맞다.  서로 다른 것이다

「쪽넘김이 없다」·「매물번호를 못 센다」는 모델 화면 이야기다  ★ [실측 08-29 — ★ `xhr-results/{n}` 은 ★ **20쪽 · 전량 223건**이다.  ★ 빈 쪽에서 끝났다]
xhr-results 에는 쪽도 href 도 있다 (개발측 실측 — 1쪽 88,267B · href 120)
```

## 매물번호

```
슬러그 끝 일곱 자가 매물번호다
  b4-awd-ultra-bright-fmbbgcg  →  fmbbgcg
xhr-results 의 href 에 그대로 들어 있다
```

## 끝 신호 — 그대로 둔다

```
data-found 를 차종별로 견주는 것은 그대로다
개발측이 「차종별 수를 화면에 찍게」 했으니 모델 화면과 대볼 수 있다
```

## 왜 총계를 안 쓰나

```
data-found 는 사이트가 「몇 건 있다」고 말한 수다
우리가 받은 것과 다른 것이 정상이다 — 광고·리스·중복을 빼고 세거나
그 반대일 수 있다.  우리는 그 셈법을 모른다

KB 15,836 이 같은 무늬였다 (오판 152)
「사이트가 말한 수」를 「우리가 넣은 수」로 읽어 없는 일을 시켰다

쪽 링크는 우리가 눈으로 세는 것이다.  사이트 셈법을 안 믿어도 된다
```

## 다만 총계를 버리지는 않는다

```
data-found 와 받은 수를 나란히 적어 둔다
어긋난 폭이 갑자기 커지면 그때 재본다 — 무엇이 바뀐 것이다
검산  S46-124 — 볼보가 끝까지 받았는데 done=False 면 알림
```
