# GV70 전용 추천 화면 규격 (추천4)

마스터가 이틀에 걸쳐 예순 대 넘게 걸러 얻은 기준을 화면 하나로 옮긴다.

---

## 1. 마스터가 쓰신 기준 — 이것이 전부다

```
① 값        예산 안 · 신차출고가 대비 ★ 78% 이하
② 연식      ★ 2022년 5월 이후 (22MY 연식변경 이후)
③ 주행      ★ 8만km 이하
④ 사고      ★ 단순교환 수준까지 — ★ 골격에 안 갔으면 통과
⑤ 취향      ★ 디스플레이 1순위 · 인테리어 · 크기
⑥ 진단      ★ 진단이 없으면 확인 비용이 따로 든다
⑦ 옵션      ★ 깡통이어도 ★ 값이 맞으면 후보다
```

**렌터카 여부는 결격이 아니다.**
리본카·K카는 렌터카를 정리해 파는 곳이고, 그래서 값이 싸다.
그 안에서 좋은 것을 고르는 것이지, 렌터카라고 빼지 않는다.

## 3. 화면 맨 위 블록 — 판단이 갈리는 네 줄

```
값 / 신차출고가 / ★ 감가율      ← 78% 넘으면 회색
주행거리 / 최초등록일           ← 2022년 5월 이전이면 회색
★ 사고 금액 / 교환 N곳 / 판금 N곳
진단 등급 / 환불 조건
```

이 넷이 마스터가 매물마다 확인하신 것이다.

## 4. 사고를 어떻게 보여 줄 것인가

### 4-1. 교환과 판금을 갈라 낸다

```
교환  N곳 (부위명)   ← 판을 새로 달았다
판금  N곳 (부위명)   ← 폈다
골격  A·B·C랭크      ← 여기 글자가 있으면 사고차다
```

- **교환 4곳 이상 = 사고 1,000만 이상**이 확인된 규칙
- 골격이 깨끗하고 외판 1곳이면 마스터 기준 통과
- 문 2짝 이상 교환이면 옆을 크게 받은 것

### 4-2. 정비이력의 하체 낱말을 잡는다

정비이력에 아래 낱말이 있으면 **성능점검부가 「골격 무사고」여도** 경고.

```
너클 · 로워암 · 래터럴암 · 어퍼암 · 서스펜션 · 쇽업소버 · 스트럿
스티어링기어 · 휠얼라인먼트 · ABS · 캘리퍼 · ECU · 휠(교환)
```

- 실제 사례: 110루9860 — 점검부 「골격 무사고」, 정비이력에 **너클 앞뒤 교환 + 서스펜션 + ECU, 부품값 628만**
- **성능점검부는 골격만 본다. 하체·기계는 정비이력에만 남는다.**

### 4-3. 금액을 함께 낸다

```
내차 피해  N회 / 총 N만원
상대차     N회 / 총 N만원      ← 남을 크게 부쉈으면 내 차도 상했다
```

부품값이 크면(300만 이상) 판을 여러 개 갈았다는 뜻이다.

## 5. 감가율 — 마스터 기준 78%

```
감가율 = (1 − 판매가 ÷ ★ 신차출고가) × 100
```

- **신차정가가 아니라 신차출고가**로 잰다 (옵션 포함 값)
- 신차출고가가 없으면 「미조회」로 비운다 — 지어내지 않는다
- **78% 이하가 후보**. 그 위는 회색 처리
- 그런데 **너무 낮아도 신호**다
  - 65~68%였던 세 대가 전부 사고 1,000~3,600만이었다
  - 카드에 한 줄: `감가가 큽니다. 사고 이력을 확인하십시오`
- 25% 아래도 표시: `거의 안 빠졌습니다. 값이 센 편입니다`

## 6. 옵션 — 깡통도 후보다

```
신차출고가 − 신차정가 = 옵션값
선택옵션 목록 (이름 + 정가)
```

- **옵션이 적어도 뺀다는 뜻이 아니다.** 값이 맞으면 후보다
- 다만 **같은 값인데 옵션이 500만 차이**면 그것이 판단 근거가 된다
- 실제 사례: 김포 3,850만(옵션 750만) vs 수원 3,860만(깡통) — 10만 차이에 750만 차이

옵션 이름은 패키지 단위로 낸다. 「HUD 있다/없다」로 쪼개지 않는다.
```
파퓰러 패키지Ⅰ 420만 (HUD · 3D클러스터 · AR내비 · 서라운드뷰)
시그니처 디자인 셀렉션Ⅰ 230만 (나파가죽 · 스웨이드)
19인치 미쉐린 + 모노블럭 4P 100만
```

## 7. 진단 등급

```
엔카진단+ > 엔카진단 > K카 직영 / 리본카 RQI > 없음
```

- **「없음」이면** 카드에 표시하고 한 줄: `확인 비용 별도 (검수 약 20만)`
- 진단이 있으면 **코멘트 원문**을 펼쳐 볼 수 있게 한다
  「후드 프론트휀더(우)가 교환되었음을 확인」 같은 문장이 결정적이었다
- 진단이 없어도 **감가 70% 아래면 후보로 올린다** — 검수비를 써도 남는다

## 8. 환불·보증·소모품

### 환불
```
7일 / 8일 / 3일 / 계약금 일부 / 없음
```
- **전액 선납 후 환불**인지, **계약금만 걸고 무르는지** 구분해 적는다
  (전액 선납 7일보다 계약금 30만이 부담이 가볍다)

### 보증
```
YYYY.MM 까지 · 잔여 N개월 / N만km
```
- **기간과 주행 잔여 중 먼저 오는 것**을 굵게
  예: 「2027.07 또는 2.8만km — **km가 먼저 옵니다**」

### 소모품 예상비 (주행거리로 자동)
```
타이어 4짝 (19인치)   120~150만   ← 4.5만km 넘으면
브레이크 앞뒤          30~50만    ← 5만km 넘으면
```
실질 총비용을 바꾼다. 7.2만km 차는 +150~200만.

## 9. 총비용을 낸다 — 차값이 아니라

```
차값 + 이전등록비 + 매도비 + (보증연장) + (소모품 예상) = 총비용
```

- 이전비·매도비는 차값의 약 8.5%로 추정
- 마스터는 「총 얼마」로 판단하신다

## 10. 점수 — 910점 그대로

별도 점수를 만들지 말고 `config/scoring.json`의 910점을 쓴다.

```

state    289   연식·보증 80 · 사고 51 · 골격 43 · 외판 28 · 내차수리 28 …

taste    165   디스플레이 35 · 인테리어 20 · 옵션 30 · 크기 31 · 색 15 …
```

- 카드에 **총점 + 갈래별 막대 5개**

- **갈래별 1등을 표시**한다 — 값 1등과 취향 1등이 다른 차인 경우가 많다
  (실제로 값 1등 270오1279, 취향 1등 K카, 총점 1등 김포로 셋이 달랐다)

## 12. 지금 데이터로는 이 화면을 못 만든다

마스터가 DB를 직접 조회해 확인한 것:

```
GV70 2.5T  active 879건
  가격·주행·트림    100% 있음
  ★ 옵션·카탈로그    100% 없음  (879/879)
  ★ 사고이력         100% 없음  (879/879)
  ★ has_record       전부 빈칸
  ★ owner_change_cnt 전부 빈칸
```

**3~7장이 전부 빈 화면이 된다.**

### 고칠 차례

1. **GV70 상세를 받아라** — 목록만 받고 상세를 한 건도 안 받았다
   같은 제네시스 G70 2.0T는 옵션이 90% 있다. GV70만 0%인 이유를 재라
2. **보험이력을 채워라** — 엔카 `/v1/readside/record/vehicle/{id}/open`
   (404는 이력 없음, 407은 일시 차단 — 구분해 기록할 것)
3. **정비이력을 따로 저장해라** — 보험이력과 다른 자료다.
   여기서만 잡히는 하체 사고가 이틀 사이 두 건 있었다
4. **신차출고가**를 저장해라 — 감가율의 분모다
5. **KB차차차 옵션 5.7%** · **K카 옵션 0%** — 사이트는 주는데 파싱을 안 한다
6. **리스·렌트 승계**를 목록에서 기본으로 걸러라 — `sell_type`이 DB에 있는데 화면이 안 쓴다.
   GV70 879건 중 124건(14%)이 리스·렌트인데 「싼 매물」로 맨 위에 올라온다

### 채움율 검사

「사이트 × 칸」 채움율 표를 매 회차 낸다.
```
0%인 칸이 있으면 fatal — 받아 놓고 안 쓰는 것이다
지난 회차보다 떨어지면 fatal — 새 사이트가 물을 탄 것이다
```
지금 돌리면: `전체 13,971 · 가격 71% · 연식 71% · 카탈로그 52% · 사고 51% · VIN 41%`

## 13. 화면 문구

```
「무사고」 옆에    →  골격 기준입니다. 외판·하체는 아래를 보십시오

정비이력 하체 낱말 →  하체·조향 부품 수리 이력이 있습니다
```
