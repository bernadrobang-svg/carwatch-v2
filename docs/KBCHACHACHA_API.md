## 1-1. ★★ 봇 차단 — 반드시 다루어야 한다

```
증상  상세가 ★ 200 인데 ★ 2,759B 만 온다.  본문이 「로봇 여부 확인 중」 한 줄이다
실측  25건 중 ★ 7건(28%)이 이 응답을 받았다
      ★ 그 7건을 ★ 나중에 다시 부르니 ★ 정상 245KB 가 왔다
      ★ 헤더를 늘려도 · 간격을 6초로 벌려도 ★ 차이가 없었다 — 일시적이다

★★ 그러므로 ★ 「필드가 없다」와 ★ 「봇 차단을 맞았다」를 ★ 반드시 가른다
필수  응답 길이가 ★ 10KB 미만이거나 본문에 「로봇 여부 확인」이 있으면
      → ★ 수집 실패로 적고 ★ 다시 부른다.  ★ 절대 「없음」으로 저장하지 마라
      ★ 개정 289·434 — 「없음」과 「모름」은 다르다.  ★ 이것은 셋째 것 「우리가 못 받았다」다
필수  재시도 — 간격을 두고 최대 3회.  3회 다 실패하면 `source='missing'` 으로 남긴다
```
