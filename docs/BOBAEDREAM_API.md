# 3. ★★ 조심할 것 — 여기가 다른 사이트와 가장 다르다

## ① 「무사고」는 ★ 판매자가 쓴 글이다

```
실측  제목      「정식/무사고/2만km주행/V8 초호화 플래그십SUV」
      본문      「》보험개발원 사고이력 0원 0건 완전무사고 운행차량」
      ★ 둘 다 ★ 판매자가 쓴 홍보 문구다.  ★ 사이트 판정이 아니다

금지  ★ 제목·본문의 「무사고」를 ★ `state.accident` 축에 쓰는 것
      ★ 엔카 `inspection` · 헤이딜러 `accident_repairs` 와 ★ 급이 다르다
필수  ★ 판매자 글은 ★ `core_listing` 의 설명 칸에만 넣는다.  ★ 점수에 넣지 않는다
```

## ② 보험이력이 ★ 「미공개」 다

```
실측  ★ 「보험이력미공개」
★ 매물마다 다를 수 있다 — ★ 공개인 매물이 있는지 ★ 표본을 늘려 확인한다
필수  ★ 미공개는 ★ 「없음(0)」이 아니라 ★ NULL 이다 (개정 289·434)
```

## ③ 성능점검이 ★ 이미지다

```
「성능지 — 해당 매물의 성능점검 기록부의 이미지」
★ 부위별 판금·교환을 ★ 글로 주지 않는다.  ★ 사진뿐이다
필수  ★ 골격 · 외판 · 누유 축은 ★ NULL 이다.  ★ 0 이 아니다
★ 엔카·헤이딜러가 부위별로 주는 것과 ★ 다르다 — ★ 이 사이트의 한계다
```

## ④ 개인 직거래가 섞인다

```
★ 딜러 매물과 개인 매물이 ★ 같은 목록에 있다
★ 개인 매물은 ★ 사이트 검증 축이 ★ 0 이다 — ★ 아무도 확인하지 않았다
★ 「실차확인 — 보배드림 직접촬영」이 붙은 것만 ★ 한 단계 준다
필수  ★ 판매자 갈래를 ★ 저장한다.  ★ 섞어서 점수를 매기지 않는다
```
