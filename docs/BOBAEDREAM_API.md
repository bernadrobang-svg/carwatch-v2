# 3. ★★ 조심할 것 — 여기가 다른 사이트와 가장 다르다

```

      ★ 엔카 `inspection` · 헤이딜러 `accident_repairs` 와 ★ 급이 다르다
```

## ① ★★ 「실차확인」이 두 꼴이고 ★ VIN 이 그것으로 갈린다

```
실측  「보배드림 직접촬영」            ★ 9건 — ★ VIN 있는 것 ★ 9 / 9
      「직원이 직접 촬영 한 차량입니다」 ★ 16건 — ★ VIN 있는 것 ★ 0 / 16
★★ ★ 깨끗하게 갈린다.  ★ 우연이 아니다

뜻    ★ 「보배드림 직접촬영」 = ★ 보배드림이 ★ 실제로 가서 찍고 ★ 차대번호를 확인한 매물
      ★ 「직원이 직접 촬영 한 차량입니다」 = ★ 안내 문구다.  ★ 그 매물 이야기가 아니다

필수  ★ `warranty.site` 사이트 검증은 ★ 「보배드림 직접촬영」인 매물에만 준다 (9/25 = 36%)
      ★ 안내 문구를 ★ 「확인함」으로 읽지 마라 — ★ 개정 520 「실제로 받았는가」와 같은 자리다
필수  ★ VIN 은 ★ 있는 매물만 채운다.  ★ 없으면 NULL
```

## ② ★ 보험이력이 ★ 24/25 가 「미공개」다

```

필수  ★ 미공개는 ★ NULL 이다.  ★ 「사고 없음(0)」이 ★ 절대 아니다 (개정 289·434)

   ★ 이 사이트는 ★ 사고 이력을 ★ 못 준다고 보는 것이 맞다
```

## ③ 보증기간이 ★ 세 꼴이다

