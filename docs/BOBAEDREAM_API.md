# 끝 신호 (가이드 확정 08-29 · 개정 849)

개발측 물음 — 「`--pages N`(기본 5쪽)으로 한정해 훑는 구조라
「이번 목록에 없다」가 「팔렸다」를 뜻하지 않는다.  끝 신호를 정해 달라」

## 정한다 — 빈 쪽이 오면 끝이다

```
쪽을 늘려 가며 부르다가 매물이 0건인 쪽을 만나면 그 조건은 끝이다
그때만 done=True 로 두고 sweep_gone_groups 에 넘긴다
```

## 왜 이것인가

```
빈 쪽은 사이트가 「더 없다」고 말한 것이다 — 우리가 정한 수가 아니다
MAX_PAGES 80 에 닿으면 done=False 다.  그것은 못 받은 것이다
```

## 빈 쪽을 무엇으로 아나 — 크기로 가른다 [실측 08-29 · 가이드]

| 쪽 | 크기 | list_items |
|---|--:|--:|
| 매물이 찬 쪽 | 281~284KB | 50 |
| 마지막 쪽 | 62KB | 4 |
| ★ 빈 쪽 | ★ 42.6KB | ★ 0 |

```
maker_no=1010 으로 잰 것이다.  1~3쪽 50건 · 4쪽 4건 · 5쪽부터 0건이 이어진다
크기로 세지 말고 list_items 가 0 인 것으로 가른다.  크기는 곁근거다
「33건뿐이다」는 틀렸다 — 그것은 우리가 넣은 수이지 보배가 파는 수가 아니다
```

## 얼마나 있나 — 10묶음 전수 [실측 08-29 · 가이드]

```
maker_no 열 개를 빈 쪽까지 걸었다 — 고유 1,860건 · 우리 차종 이름에 걸리는 것 221건
  1010 154(83) · 3 404(16) · 49 431(79) · 21 542(18) · 1 193(6)
  26 52(0) · 1006 13(4) · 32 47(5) · 13 13(4) · 23 11(6)
세는 법  쪽마다 더하지 않고 매물번호를 집합으로 모았다
```

## 지킬 것

```
--pages 를 사람이 준 때는 done=False 다
  시험용으로 자른 것을 참으로 세면 안 된다
기본값에서 --pages 를 없앤다.  빈 쪽까지 간다
쪽마다 사이를 두어 사이트를 치지 않는다 (--interval 그대로)
```
