## 14장 정의서

**10장은 「화면에 무엇을 내는가」다. 14장은 「그것을 어떻게 띄우는가」다.**

```
10장   ListingRow · view_listings(account, filter) · 표시 규칙
14장   라우팅 · 템플릿 · 정적 파일 · 세션 · 폼 · 오류 화면 · 실행
```

```
★ 10장을 다 만들어도 화면이 안 뜬다.  그 사이가 이 장이다
근거   실제로 그랬다.  「데이터 계약만 있고 구현 규격이 없다」
```

### 계층

```
L8  Web      라우팅 · 템플릿 · 세션.  판정을 모른다
L7  View     10장 view_*(account, ...) → 화면 구조체
L6  Store    조회
```

```
금지   L8 이 core_* · result_* 를 직접 조회하는 것
필수   L8 은 view_* 만 부른다.  SQL 이 L8 에 없다
검증   V11-01  web/ 에 SQL 문자열이 없는가   contract · fatal
```

### 구조체

```python
@dataclass(frozen=True)
class Route:
    path: str                  # '/listings'
    method: str                # GET · POST
    view: str                  # 'view_listings'
    template: str              # 'listings.html'
    role: str                  # anonymous · user · admin
    menu: str | None           # 운영 · 조정 · 탐색 · None

@dataclass(frozen=True)
class ViewerState:             # 10장 STEP 105.  표시용.  차단은 guard() 가 한다
    role: str
    display_name: str
    can_watch: bool
    can_admin: bool
    must_change_secret: bool

@dataclass(frozen=True)
class MenuItem:
    label: str
    path: str
    group: str | None          # 운영 · 조정 · 탐색
    disabled_reason: str | None

@dataclass(frozen=True)
class PageContext:
    account: Account
    viewer: ViewerState
    versions: VersionStamp
    nav: list[MenuItem]
    flash: list[tuple[str, str]]   # (level, message)
    body: object                   # view_* 반환 구조체
```

