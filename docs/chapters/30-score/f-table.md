## 1-1. 시세 대비 100 — ★ 계단을 없애고 비례로 (개정 419)

**마스터 확정 08-20 — 「가격을 왜 계단식으로 하지? 감가는 커브로 만들고**
**가격은 커브로 안 만들지? 신차 대비 비용과 해당 연식의 시세가 기준으로**
**% 로 +− 처리가 맞지 않아」**

```
입력   price_current_won
      market_median = 같은 target_key · trim · form_year 의 중앙값 (표본 ≥5)
      option_median_by_trim  = 그 트림의 옵션가 합 중앙값
식     ★ 옵션 보정 — 그 차의 옵션 값어치만큼 기준을 올린다 (개정 421)
      adj_median = market_median + (내 옵션가 합 − option_median_by_trim)
      r% = (adj_median − price) ÷ adj_median × 100
      점수 = round(r% × 5)  싼 쪽 · round(r% × 8)  비싼 쪽   ★ 비대칭
      범위 = −100 ~ +100            ★ 마이너스를 허용한다
```

```
★ 왜 옵션으로 보정하나 — 마스터 08-20
  「옵션의 총합 가격도 트림별 가격 차이도 가격 점수에 넣자.
   그랜저도 깡통이 4000이면 최고트림의 풀옵션이 7000이니」

  전   같은 트림 안에서 깡통과 풀옵션이 한 중앙값으로 묶였다

```
