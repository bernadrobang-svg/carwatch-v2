# 관리 화면 시안 — 좁은 폭 360 기준

**★ 마스터 지적 — 「시안도 없이 말로 따우네」**
**★ 이 시안은 `[마스터]` 층이다 (S32). 마스터가 고치면 그것이 정본이다.**

```
그리는 법   글자로 자리와 차례를 보인다
           [단추]  (입력칸)  ▸접힘  ─선  ★강조
           → 누르면 무엇이 되는지
```
