# ★★★ 받은 것은 판정 전에도 보여준다 — 08-18

**마스터 지적 — 「내가 보는 게 우선이지 않니? 그런데 네가 판정을 못 내려서**
**받아 놓고 안 보이는데 말이 되니?」**

```
지금   원문을 받아도 축이 없거나 파서가 안 읽으면 화면에 안 나온다
       예   배터리 SOH — 엔드포인트도 있고 컬럼도 있는데 화면에 없다
★ 마스터는 판정을 보러 오는 게 아니라 차를 보러 온다
★ 우리가 못 판정하는 것과 마스터가 못 보는 것은 다른 문제다
```

## 규격

```
필수 [마스터]   받은 것은 판정 여부와 무관하게 상세에 낸다
                축이 없어도 · 배점이 없어도 · 파서가 안 읽어도
필수 [마스터]   상세 맨 아래에 「받은 원문 — 아직 판정에 안 쓰는 것」 절을 둔다
                엔드포인트별로 접어서
                「배터리 (ev-battery)  ▸  SOH 94.4% · 셀 밸런스 …」
                「엔카 진단 (clean-encar)  ▸  …」
필수 [기술]     파서가 없으면 원문 JSON 을 그대로 펴서 낸다
                ★ 「파서를 만들 때까지 안 보여준다」는 안 된다
필수           키 이름을 사전으로 옮길 수 있으면 옮기고, 없으면 원문 키 그대로
필수 [마스터]   판정에 쓰이기 시작하면 위쪽 축별 판정으로 올라간다
                ★ 아래 절에서는 사라진다.  두 곳에 나오지 않는다
```
