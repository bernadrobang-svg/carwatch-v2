```
① 머리말
   사진 480×360 (좁으면 100%) · 나머지 사진 4장 작게
   등급 · 비율 · 순위 · 차종 · 트림 · 연식 · 주행
   ♡ · 엔카에서 보기 · ⇄ 비교

② 값 — ★ 가장 크게
   신차가  5,273만   등급기준 4,560만 + 옵션 713만
   시세    3,070만   같은 조건 128건의 중앙값

   ─────────────────────────────
   시세보다   400만 (13.0%) 쌉니다

③ 왜 싼가 / 왜 비싼가 (개정 299)
   「싼 이유 3가지를 찾았습니다」

   · 점검을 판매자가 등록했습니다
   ★ 못 찾으면 「싼 이유를 찾지 못했습니다.  직접 확인하십시오」

④ 무엇을 조회했는가
   응답 · 상태 · 무엇을 주는가 · 없으면
   ★ 「안 부른 것」과 「불렀는데 못 받은 것」을 가른다

⑤ 축별 판정 — 24축
   갈래 · 축 · 점수 / 배점 · 값 · 근거 필드
   ★ 갈래별로 접는다 (details)
   ★ 0점인 축은 「확인됨」과 「확인 안 됨」을 가른다

⑥ 마이너스
   렌트 이력 −50 · 우수등급 없음 −30 · 합 −80

⑦ 확인 못 한 것
   「555점 중 483점을 확인했습니다 (87%)」
   「확인 못 한 72점 — 카탈로그 미조회 20 · 엔카진단 미조회 10 …」
   ★ 무엇을 받으면 무엇이 살아나는지 (개정 328)

⑧ 옵션
   선택 옵션   이름 · 가격 · 합계
   주요 옵션   이름만
   ★ 사전에 없는 코드는 코드 그대로

⑨ 비용
   차량가 · 이전등록비 · 보증 가입비 · 총 예상
   ★ 점수에 반영하지 않는다

⑩ 참고 자료
   알려진 문제 · 리콜
   ★ 사람이 넣는다

# ★★★ 상세에 사진이 없다 — 08-18 실측

**마스터 지적 — 「목록은 간략하게 상세는 최대한 모든 정보가 들어가야 한다고 했는데**
**왜 반영 안 해. 그게 1순위야」**

```
실측   /why 의 <img> 0개 · ci.encar 0개
★ 상세인데 사진이 하나도 없다
★ 차를 사는 사람이 상세에서 실물을 못 본다
```

## 규격

```
필수 [마스터]   상세에 사진을 전부 낸다
                큰 사진   1장 · 480×360 (좁으면 100%)
                썸네일    나머지 전부 · 128×96 (개정 368)
                          ★ 엔카는 33장까지 있다
필수 [마스터]   썸네일을 누르면 큰 사진이 바뀐다
필수 [기술]     JS 없이도 — 썸네일마다 앵커로 큰 사진을 갈아 끼운다
                ★ 또는 세로로 늘어놓는다.  좁은 폭이면 그편이 낫다
필수 [원문]     ci.encar.com 을 직접 참조한다 (개정 274)
필수           사진이 없으면 「사진이 없습니다」
금지 [마스터]   상세에 사진을 안 내는 것
검산            V11-132  상세에 큰 사진과 썸네일이 있는가
```

# ★★★ 목록과 상세를 가른다 — 08-18 실측 확인

```

★ 「근거」 글자 하나만 누를 수 있다
★ 개정 338 V11-116 「행 어디를 눌러도 상세로」가 안 됐다
```

```

                ★ 손가락으로 아무 데나 눌러도 간다
