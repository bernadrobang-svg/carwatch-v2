## 사진 크기 — ★ 화면마다 다르다

| 화면 | 넓음 | 중간 | 좁음 |
|---|--:|--:|--:|
| **목록** | **88×66** | **88×66** | **80×60** |
| **추천** | 80×60 | 72×54 | 64×48 |
| 관심 | 88×66 | 88×66 | 80×60 |
| 비교 | 120×90 | 100×75 | 88×66 |
| **상세 — 큰 사진** | 480×360 | 100% | 100% |
| **상세 — 나머지 썸네일** | **128×96** | **128×96** | **128×96** |

