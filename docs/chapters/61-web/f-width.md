```

## 규격

```
필수   스크린샷을 다섯 폭에서 찍는다
       360 · 640 · 900 · 1100 · 1400
       ★ 경계 바로 안쪽·바깥쪽을 함께 본다
       640 은 좁음↔중간 경계 · 1100 은 중간↔넓음 경계
필수   경계에서 배치가 바뀌는지 확인한다
       639 카드 → 640 표 2줄 → 1099 표 2줄 → 1100 표 22열
필수   ★ 검사가 스크린샷을 쓴다.  찍기만 하지 않는다
       ★ 지금은 찍고도 아무도 안 본다
검산   V11-113  다섯 폭 스크린샷이 있는가
       V11-114  폭마다 부록 G 의 배치인가
       V11-115  ★ 어느 폭에서도 한 칸의 글자가 세로로 떨어지지 않는가
                한 칸 폭 ÷ 글자 폭 < 3 이면 실패
```

```
