## ★★★ 7-4. 적재 로그 — ★ 두 번 넣지 않는다

```
★ 마스터 — 「★ 어떤 파일을 만들어서 어디까지 데이터를 썼다는 걸 ★ 로그로 관리돼야 …

| 칸 | 무엇 |
|---|---|
| `file_path` | ★ **열쇠**.  `raw/{site}/{endpoint}/{날짜}/{이름}.json` |
| `site` · `endpoint` · `source_id` | 어느 사이트의 무엇인가 |
| `file_bytes` · `file_hash` | ★ 파일이 바뀌었나를 가른다 |
| `loaded_at` | ★ **적재한 날** (마스터 말씀) |
| `run_id` | 어느 회차가 넣었나 |
| `rows_in` · `rows_new` · `rows_changed` · `rows_same` | ★ 무엇을 얼마나 넣었나 |
| `status` | `ok` · `parse_error` · `skipped` |

필수  ★ 넣기 전에 ★ `file_path` 로 대본다 — ★ **이미 있으면 안 넣는다**
필수  ★ 파일이 다시 받아졌으면 ★ `file_hash` 가 다르다 — ★ 그때만 다시 넣는다
필수  ★ `core_listing` 에도 ★ 이미 `first_seen` · `last_seen` 이 있다 — ★ 그것과 섞지 않는다
       ★ ★ `load_log.loaded_at` 은 ★ **파일 기준** · `first_seen` 은 ★ **매물 기준**이다
```
