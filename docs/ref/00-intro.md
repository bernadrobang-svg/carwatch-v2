
| 규칙 | 이유 |
|---|---|
| **값이 갈리면 본문 STEP 표를 따른다** | 부록은 발췌다 |
| **부록을 고칠 때 본문도 같이 본다** | `check_spec` 이 둘을 대조한다 |
| **부록만 읽고 구현하지 않는다** | 부록에는 「왜」가 없다 |
