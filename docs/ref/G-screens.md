# 화면 정본 — CarWatch v2 · 2026-08-17

**마스터 지적 — 「화면도 네가 제대로 가이드 준 게 아냐. 내가 목록을 원했는데 이렇게 나오니」**

**맞다. 배점은 표로 줬는데 화면은 말로만 줬다. 여기 자리와 크기를 적는다.**

# 0. 공통

## 폭 세 단계

```
넓음   ≥ 1100px    표
중간   640~1099    표 · 묶어서
좁음   < 640       카드
```

## 사진 크기 — ★ 화면마다 다르다

| 화면 | 넓음 | 중간 | 좁음 |
|---|--:|--:|--:|
| 목록 | 96×72 | 88×66 | 80×60 |
| **추천** | **80×60** | **72×54** | **64×48** |
| 관심 | 96×72 | 88×66 | 80×60 |
| 비교 | 120×90 | 100×75 | 88×66 |
| 상세 | 480×360 | 100% | 100% |

```
★ 마스터 지적 — 「추천에는 이미지 너무 커」
필수   추천은 목록보다 작다.  한 화면에 여러 후보가 보여야 한다
필수   비율 4:3 을 지킨다.  찌그러뜨리지 않는다
필수   크기를 CSS 로 고정한다.  이미지가 오기 전에 칸이 흔들리지 않게
금지   화면마다 다른 비율을 쓰는 것
검산   V11-107  화면별 사진 크기가 이 표와 같은가
```

   ♡ · 엔카에서 보기 · ⇄ 비교

   신차가보다 2,603만 (49.4%) 내렸습니다

④ 무엇을 조회했는가
   응답 · 상태 · 무엇을 주는가 · 없으면
   ★ 「안 부른 것」과 「불렀는데 못 받은 것」을 가른다

   ★ 갈래별로 접는다 (details)
   ★ 0점인 축은 「확인됨」과 「확인 안 됨」을 가른다

   렌트 이력 −50 · 우수등급 없음 −30 · 합 −80

   ★ 무엇을 받으면 무엇이 살아나는지 (개정 328)

   선택 옵션   이름 · 가격 · 합계
