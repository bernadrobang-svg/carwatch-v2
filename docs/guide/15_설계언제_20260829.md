# 설계 2판 — 지금 쓸까, 개발 넷 뒤에 쓸까 (08-29)

★ **짐작 말고 두 길이 무엇에 걸리는지 쟀다.**

---

# 1. ★ 지금 쓰면 — 걸리는 것 **하나**

| | 무엇 |
|:--:|---|
| ★ | ★ **`V2-01`(ok 원문 수 == CORE 행 수)이 아직 실패다** |

```
★ 그것이 ★ **설계 3걸음(맞대기)의 잣대**다 —
   ★ 「임시표에 있고 DB 에 없다 → 넣는다」가 맞는지 ★ 그 수로 안다
★ ★ 지금 ★ 원문 수와 CORE 행 수가 ★ **안 맞는데 까닭을 모른다**
   ★ ★ 모르는 채로 3걸음을 쓰면 ★ **그 안 맞는 것을 설계에 굳힌다**

★ 나머지 셋은 ★ **설계를 안 흔든다** —
   배포 올리기(화면) · K카 `cno`(짝짓기 열쇠 · 설계 밖) · KB 부위별(파서 하나)
```

---

# 2. ★ 나중에 쓰면 — 걸리는 것 **셋**

| | 무엇 | 얼마나 |
|:--:|---|---|
| ★ 1 | ★ **개발측이 멈춘다** | 남은 넷이 **작다**(화면 하나·파서 둘·검사 하나). 끝나면 **할 일이 없다** |
| 2 | ★ **`SWEEP_OFF` 여섯 곳이 꺼진 채 쌓인다** | 지금 **여섯 수집기가 팔린 차를 안 거른다**. 설계 3걸음이 그걸 대신할 자리인데 늦어진다 |
| 3 | 물음지 58개 답이 **낡는다** | 오늘만 `locked 0` · 렉서스 상세 · `SWEEP_OFF` 셋이 바뀌었다 |

```
★★ ★ 2 가 가장 아프다 — ★ 지금 ★ **여섯 곳이 「죽이지도 살리지도 않는」 상태**다
   ★ ★ 팔린 차가 목록에 계속 서 있게 된다.  ★ 마스터께서 그것을 보신다
```

---

# 3. ★★★ 그래서 — **지금 쓴다. 다만 3걸음만 비운다**

```
★ 1·2·4·5 걸음은 ★ **지금 쓴다** — ★ 물음 58개 답이 다 있고 ★ 오늘 잰 수도 다 있다
   (파일 자리·이름 · 임시표 `stage_{run_id}.db` · 적재 로그 · 상태 · 클렌징)

★★ ★ **3걸음(맞대기)만 ★ 「`V2-01` 을 받은 뒤」로 비워 둔다**
   ★ ★ 그 자리에 ★ **「무엇을 받아야 채우나」를 적어 둔다** — ★ 빈칸이 아니라 ★ 조건이다
   ★ ★ 개발측이 `V2-01` 을 닫으면 ★ 그 수로 3걸음을 채운다

★ ★ 이러면 ★ **개발측이 안 멈추고** · ★ **모르는 것을 굳히지 않는다**
```

---

# 4. ★ 내가 안 하는 것 — 정직하게
