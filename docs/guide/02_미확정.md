# 미확정

`SPEC-2026.08.24-r654`


**「지금 정할 수 없는 것」만 여기 둔다. 「내가 안 쓴 것」은 미확정이 아니다.**

```
필수   미확정을 발견하면 이 표에 행을 추가한다.  장 안에만 적지 않는다
근거   흩어져 있으면 「무엇이 안 정해졌나」를 물을 때 답할 수 없다
금지   규격을 안 쓴 것을 미확정으로 적는 것
```
