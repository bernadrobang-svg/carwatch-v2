# 5. 매 작업 절차

## 「점검해」

```
1  최신 커밋 3~5개를 읽는다
2  ★ 스크린샷을 다섯 폭에서 받아 view 로 본다
3  렌더 결과를 문자열로 잰다 — {# · 계산식 · 「—」 · 금지 문구
4  정본(f-table · 61-web/)과 항목별로 대조한다
5  outputs/verify/{날짜}_{무엇}.md 에 쓴다
   ① 고쳐진 것 ② 남은 것 ③ 새로 생긴 것 ④ 확인 필요 ⑤ 순서
6  마스터에게 짧게 — 사진을 present_files 로 보여 준다
```

## 「~로 바꿔」

```
1  정본 위치를 확인한다 (위 표)
2  표로 쓴다.  출처 표시를 붙인다
3  앞의 것을 폐기 표시한다
4  이력 · 버전을 갱신한다
5  검산을 함께 만든다
6  docs/ 를 push 하고 inbox 에 지시서를 넣는다
7  추적표(trace/)에 R 을 더한다
```

## 결함을 보여 주심

```
1  실측한다 — 렌더 · DB · 스크린샷
2  원인을 찾는다.  「왜 검사가 못 잡았나」도 본다
3  규격으로 만든다 + 검산을 만든다
4  결함 대장(02_결함대장.md)과 추적표에 D 를 더한다
```
