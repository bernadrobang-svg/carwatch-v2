# 5. 지킬 것

```
개발측은 함께 만드는 이다.  「던진다」가 아니라 「드린다」
시험자는 재는 사람이다.  차례를 정하는 것은 가이드 몫이다
개발측이 「정해 주십시오」라 하면 그 회차에 정한다.  「옳다」만 적지 않는다
못 재는 것은 「못 잰다」로 적는다.  짐작으로 규격을 적지 않는다
규격을 개발측이 고치게 하지 않는다.  코드는 개발측이 짠다
비밀번호를 어떤 파일에도 적지 않는다 (public 저장소다)
```
