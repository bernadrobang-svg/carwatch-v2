# K카 목록 API · 매핑 규격

`SPEC-2026.08.22-r468` · 2026-08-22 · **가이드가 직접 실측했다 (원칙 4)**
`docs/KCAR_API.md`(개발측 08-17 1차 조사)를 잇는다 — **1차가 못 찾은 XHR 을 찾았다**

---

# 0. 결론

```
★★ 목록은 ★ 완전히 뚫렸다 — ★ 응답이 평문 JSON 이고 항목이 매우 풍부하다
★ 요청 본문만 암호화되어 있다 ({"enc":"…"})  ★ 응답은 암호화가 아니다
★ 상세(`/bc/detail/carInfoDtl?`)는 ★ robots 금지다.  ★ 목록은 허용이다
```

# 1. 경로

| 무엇 | 방식 | 경로 | robots |
|---|---|---|:--:|
| **목록(직영)** | `POST` | `https://mapi.kcar.com/bc/search/list/drct` | ★ 허용 |
| **목록(제휴·인증)** | `POST` | `https://mapi.kcar.com/bc/search/list/acm` | ★ 허용 |
| 관심여부 | `POST` | `/bc/wish-yn-list` — body 에 `carList:["EC61366001",…]` | 허용 |
| 지역·센터 | `GET` | `/bc/region-center` | 허용 |
| 코드표 | `GET` | `/bc/sub-codelist?sMstCode=CAR_OPTION2%2CCENTER_REGION%2CSELL_CL_CD` | 허용 |
| ~~상세~~ | ~~GET~~ | ~~`/bc/detail/carInfoDtl?i_sCarCd=…`~~ | ★ **금지** |

```
★ 호스트는 ★ mapi.kcar.com 이다.  ★ api.kcar.com 도 www 도 아니다
★ 개발측 1차 조사(`docs/KCAR_API.md`)가 「값이 HTML 에 없다 · XHR 을 더 찾아야 한다」로 끝난 그 XHR 이다
```


```
   (마스터가 브라우저로 보시는 것과 같다.  ★ 조건은 화면에서 고른다)
```

# 2. ★ 응답 — 평문 JSON · 항목이 풍부하다

```json
{"data":{"totalCnt":798,"pageNo":1,"limit":10,"totalPageCnt":80,"rows":[ … ]}}
```

```
★ 총건수 · 쪽 수를 ★ 그대로 준다 (KB차차차는 안 준다)

```

# 3. ★★ 축을 어떻게 채우나 — 마스터 확정 (개정 468)

**마스터 확정 08-22 — 「K카는 직매라 보장이 되니 신뢰하고 줘라」**
**「압류·저당은 직매라 걱정 안 해도 된다」 「신차가는 다른 데서 보충해라」**

```
★ K카 직영은 ★ 회사가 직접 사서 직접 판다.  ★ 개인 딜러 매물과 신뢰도가 다르다
★ 그러나 ★ 「직영이 보장하는 것」과 ★ 「목록에 값이 없는 것」은 다르다.  ★ 갈라서 채운다
```

## 3-1. 목록에서 그대로 오는 것 — 495점

```
트림 59 · 연식 80 · 주행 107 · 예산 95 · 색상 15 · 옵션 43 · HUD 18 ·
지정옵션 18 · 선루프 12 · 사고 48 (`acdtHistCd` 코드 해석 뒤)
```

## 3-2. ★ 직영이라 신뢰해서 주는 것 — 220점

| 축 | 배점 | 근거 |
|---|--:|---|
| `warranty.site` 사이트 검증 | 36 | ★ **만점** — K카 직영은 이미 만점 자리다 (개정 428) |
| `state.frame` 골격 | 40 | ★ **무사고 기준** — 직영은 사고차를 직영으로 팔지 않는다 |
| `state.outer` 외판 | 26 | 〃 |
| `state.special` 특수 사고 | 20 | 〃 (전손·침수·도난) |
| `state.leak` 누유 | 14 | 〃 |
| `state.integrity` 진정성 | 7 | 〃 (K카가 직접 등록한다) |
| `state.my_cost` 자차 수리비 | 26 | 〃 |
| **`history.seizing` 압류·저당** | **7** | ★ **마스터 확정 — 「직매라 걱정 안 해도 된다」** |
| `history.use` 용도 | 21 | ★ 직영은 렌트·영업용을 직영으로 팔지 않는다 |
| `history.owner` 소유자 변경 | 10 | 〃 |
| `history.not_join` 자차 미가입 | 17 | 〃 |

```
필수  ★ 이 220점은 ★ 「K카 직영(`sellDcd` GNRL · 직영 센터)」 인 매물에만 준다
필수  ★ 제휴·인증(`/acm`) 매물에는 ★ 주지 않는다 — 직영이 아니다.  ★ 0점 + 미확인 표시
필수  ★ 화면에 밝힌다 — 「★ K카 직영 보장으로 채운 항목입니다 (상세 미조회)」
      ★ 조용히 만점을 주지 않는다 (V11-165 · 개정 325)
금지  ★ 소모품 14 는 주지 않는다 — ★ 엔카도 KB 도 안 주는 값이다.  0점 + 분모 유지
```

## 3-3. ★ 다른 데서 보충하는 것 — 105점

**마스터 확정 — 「신차가는 다른 데서 보충해라」**

| 축 | 배점 | 어떻게 |
|---|--:|---|
| `value.origin` 신차가 | 75 | ★ **차종·트림별 신차가 표에서 끌어온다** |
| `value.market` 시세 | 30 | ★ **우리 시세(같은 차종·트림·연식 중앙값)로 낸다** |
| `warranty.power`·`general` 제조사 보증 | 54 | ★ **연식 + 제조사 보증 기간표로 계산한다** |

```
★ 신차가는 ★ 매물 속성이 아니라 ★ 차종·트림의 속성이다 — 같은 차면 같은 값이다
   → ★ 엔카·KB 에서 이미 받고 있다.  ★ 그 표를 K카 매물에 붙이면 ★ 만점이 아니라 진짜 값이다
★ 시세도 같다 — 우리가 매물 전체로 산출한다.  ★ K카 매물도 그 분포에 넣어 잰다
★ 제조사 보증도 같다 — 연식과 제조사만 알면 잔여를 계산할 수 있다 (개정 464 · 수입 브랜드 표)
★ 매칭 키 — 제조사(`mnuftrNm`) · 모델(`modelGrpNm`) · 트림(`grdNm`·`grdDtlNm`) · 연식(`prdcnYr`)
★ 매칭이 안 되면 ★ 0점 + 「신차가 미확인」.  ★ 지어내지 않는다
```

## 3-4. 합계

```
목록에서            495
직영 보장으로        220
다른 데서 보충       105
소모품 (0점 유지)     14
                  ─────
합                 820 / 910 (90%)  ★ 채워진다
★ 못 채우는 것은 ★ 소모품 14 하나뿐이다 (엔카·KB 도 못 준다)
```

```
★ 정식으로 풀려면 ★ K카에 제휴·데이터 이용 문의를 넣는다.  ★ 마스터 판단이다
```
