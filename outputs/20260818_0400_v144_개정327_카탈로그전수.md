## 4. 무엇을 했나 · 왜 그렇게 했나

### ① 조합을 셌습니다 — 「몇 건」이 아니라 「몇 개 중 몇 개」

```
필요 조합   148       (판정하는 매물의 distinct model_catalog_key)
받은 것     126  85.1%
못 받은 것   22
  empty      21조합 · 매물 505건
  not_found   1조합 · 매물  23건
  not_called  0조합            ★ 우리 잘못은 없다
카탈로그가 없는 매물  528건 / 3,528
```

★ `raw_response.source_id` 가 곧 `model_catalog_key` 입니다 (호출은 매물 ID,
저장 키는 모델 키).  그래서 조합 단위로 바로 셀 수 있었습니다.

### ② 「필요한 조합」을 판정하는 매물로 좁혔습니다

처음엔 `core_listing` 전체로 셌더니 **`not_called` 3조합이 「우리 잘못」으로**
나왔습니다.  들여다보니 셋 다 `status='out_of_scope'` 였습니다 —
판정하지 않는 매물이라 카탈로그를 안 부른 것이 맞습니다.

```
규격    「core_listing 에서 distinct 로」
한 것   status='active' 로 좁혔습니다
왜     안 좁히면 「우리 잘못 3조합」이 영영 뜹니다.  거짓 경보는 검사가 아닙니다
물어봄  이 좁힘이 맞습니까 (7절 ①)
```

### ③ ★ 대표 하나만 부르고 포기하고 있었습니다 — 수집을 고쳤습니다

`empty` 21조합이 진짜 빈 것인지 엔카에 직접 물었습니다.

```
조합 823860820240405 (매물 6건)
  42120782  404
  42183995  200  []
  42205543  404

조합 824569420240215 (매물 23건 · not_found 로 기록돼 있던 것)
  42062857  200  []      42065834  404
  42263023  200  []      42263116  404
  42263289  200  []      42277177  404
```

**같은 조합인데 매물마다 404 가 갈립니다.** 그 매물만 사라진 것이지
조합이 없는 것이 아닙니다.  대표 하나가 404 면 「못 받았다」로 끝났습니다.

```
고침   collect/runner.py S7
      전    MIN(source_id) 하나로 부르고 끝
      후    한 조합에서 catalog_reps(3) 매물까지 다시 묻는다
           404 가 아니면 바로 멈춘다
config  endpoints.json  catalog_reps = 3
```

★ 이걸로 `not_found` 는 「모른다」에서 **「없다」로 확정**됩니다.
21+1 조합은 엔카가 진짜로 `[]` 를 줍니다 — **우리 잘못이 아닙니다.**

### ④ V1-23 · V1-24 를 만들었습니다


## 7. 판단이 필요한 것

### ① 「필요한 조합」을 `status='active'` 로 좁혔습니다

규격은 「core_listing 에서 distinct 로」라 합니다.  그대로 세면
`out_of_scope` 매물 4,243건의 조합까지 들어가 **「우리 잘못 3조합」이
영영 뜹니다.**  판정하는 매물로 좁혔습니다.  맞습니까.

### ② `empty` 22조합 · 매물 528건은 엔카가 안 줍니다

`GET /vehicles/car/{id}/options/choice` → `200 []` 입니다.
대표를 셋까지 바꿔 물어도 같습니다.  **이 528건은 옵션 축 20점이
「확인 안 됨」으로 남습니다** (부록 F ④-2 ②).
다른 경로로 옵션가를 받을 수 있습니까 — 아니면 이대로 둡니까.

### ③ 고친 수집은 아직 안 돌았습니다

`catalog_reps=3` 은 **다음 S7 부터** 적용됩니다.
이미 `not_found` 로 기록된 1조합(23매물)은 그 행이 있어 다시 안 부릅니다.
그 한 조합만 다시 부르려면 해당 `raw_response` 행을 지워야 하는데,
**원문은 버리지 않습니다 (P3 무손실)** — 지우지 않았습니다.
재수집 방법을 정해 주시면 그때 돌리겠습니다.
