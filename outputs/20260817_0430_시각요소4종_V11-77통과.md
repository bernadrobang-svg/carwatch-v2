## 2. 물음 ① — 대기 축은 `panel` 하나가 맞습니다

```
pending    panel 35
confirmed  trim 68 · color_ext 23 · color_int 10 · fuel 5 · panel_rank 5 ·
           panel_status 4 · accident_type 3 · sell_type 3
```

**가이드 짐작이 맞습니다.** 나머지는 이미 확정됐습니다.
화면에 그렇게 적었습니다 — 「지금 대기 중인 축은 **1가지**입니다 — 나머지 축은 이미 확정됐습니다」.

### 「매물 0건」은 0 이 아니라 **셀 수 없는 것**이었습니다

```python
DICT_AXIS_COLUMN = {"fuel": …, "color_ext": …, "color_int": …,
                    "trim": …, "sell_type": …}
# ★ panel 이 없다
```

`panel` 값은 `core_listing` 의 열이 아니라 **점검 원문**에 있습니다.
매핑이 없어 0 이 나온 것인데, **0 으로 내면 「확정할 이유가 없다」로 읽힙니다.**

```
전   매물 0건
후   매물 수 셀 수 없음
     title="이 축은 core_listing 에 열이 없습니다. 값이 점검 원문에 있어
            매물 수를 여기서 셀 수 없습니다"
```

`listings` 를 `0` 이 아니라 `None` 으로 돌려주고, 화면이 그것을 구분합니다.

## 3. 물음 ② — ★ 제가 만든 결함입니다


머리말과 값이 어긋나 「관측·매물·출처가 빈 칸」으로 보인 것입니다.

```css
후   main table td, main table th { white-space:nowrap; word-break:keep-all; }
     ★ 칸을 안 접게만 하면 안쪽 표가 스스로 넓어져 가로로 넘어간다.
       그래야 머리말과 값이 같은 표 안에서 줄을 맞춘다
```

**스크린샷으로 확인했습니다** — 관측이 189 · 177 · 130 으로 제자리에 나옵니다.

`V11-78` 이 옛 방어책(`min-width`)만 찾고 있어 함께 고쳤습니다 —
**둘 중 하나면 통과**입니다.
