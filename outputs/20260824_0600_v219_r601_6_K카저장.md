### 2-1. ★ 지시한 함정 둘 — ★ 그대로 지켰다

**① `data` 를 벗긴다**

```python
data = body.get("data") or {}
rvo  = data.get("rvo") or {}
```
★ 규격 2-1 대로 ★ `rvo.carCd` 가 있는지로 「없는 매물」을 가른다. ★ 상태코드로 안 가른다.

**② `Yn` 은 ★ 문자열이다 — `bool()` 로 안 가른다**

```
실측 —  yn('N') = 0    ← ★ bool('N') = True
        yn('Y') = 1    ← bool('Y') = True
        yn('0') = 0    ← ★ bool('0') = True
        yn('1') = 1    ← bool('1') = True
        yn(None) = None
        yn('기타') = ★ None   ← ★ 표에 없는 값은 「모름」이다.  ★ 지어내지 않는다
```
★ `master.szrMogeYn='N'` · `carhistory.rentHistYn='N'` · `master.dshbExchgYn='1'` — ★ 전부 문자열이었다.
