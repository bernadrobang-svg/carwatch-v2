# 정식 서비스 착수 — 지금 안 하기로 한 것

**S36 (개정 359) · 마스터 지시 — 「보안은 제일 마지막에 해. 미리 설레발 치지 말자」**

```
★ 이 파일은 「없어진 것」이 아니라 「미뤄 둔 것」의 목록이다
★ 되돌릴 때 여기만 보면 된다
검산   S36-1  이 목록이 있는가
```

---

## 1. 지금 꺼 둔 것 — 되돌릴 것

| 무엇 | 지금 | 되돌릴 값 | 어디 |
|---|--:|--:|---|
| `min_secret_length` | **1** | 8 이상 | `config/admin.json` |
| `login_fail_limit` | **0** (안 잠금) | 10 | `config/admin.json` |

```
근거   개정 359 — 「그냥 제한 없애. 정식 서비스할 때 강화해」
★ 코드는 그대로다.  config 값만 바꾸면 되살아난다
★ 시도 기록(auth_login_attempt)은 지금도 남긴다 — 기록을 지우는 것은
  되돌릴 수 없다
```

---

## 2. 지금도 지키는 것 — ★ 나중에 붙이면 이미 샌 뒤다

```
비밀번호 해시를 로그에 안 남긴다
개인정보 테이블을 쿼리로 안 연다        (V10-xx · /admin/query 가 막는다)
HTTPS 를 쓴다                        (Caddy · deploy/README.md)
쿠키에 Secure · HttpOnly
```

## 3. 정식 서비스 착수 때 할 것

```
비밀번호 규칙 (길이 · 문자 종류)
```
