# 3. ★★ 재계산 도중 찾은 결함 — `bool('0')` 이 참이었다

```
명령서 ⓔ  「★ 진단 ★ 미조회인데 사이트 보증 만점을 주는 것 → ★ 주지 마라」

첫 조치   맨 위 단계에 needs_ok=diagnosis_status 를 걸었다
그런데    ★ 그래도 480건이 만점을 받았다.  ★ 이상해서 원문을 열었다

실측   core_listing.warranty_extend 는 ★ 문자열이다 —  '0' 3,836건 · '1' 43건
      analyze/axis/site.py warranty_grade() 가  ★ bool(have)  로 갈랐다
      ★ bool('0') 은 ★ 참이다
      → ★ warranty_extend='0' 인 522건이 ★ 「엔카진단++」 만점을 받고 있었다

고침   _truthy() 신설 — '0' · 'N' · 'false' · '' · None 을 거짓으로 본다
결과   ★ 엔카진단++ 480 → 0.  (warranty_extend='1' 43건은 ★ 전부 진단 미조회라
       needs_ok 에 걸린다)
```

```
★ 이것이 ⓔ 의 진짜 까닭이다.  ★ needs_ok 만으로는 안 고쳐졌다
★ 「진단이 없는데 만점」이 ★ 사이트 검증 축 전체를 흔들고 있었다
```
