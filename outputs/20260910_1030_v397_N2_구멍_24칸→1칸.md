### 3-1. ★ 호스트를 지어내지 않았다 — 사이트가 알려 준다

기아 상세의 사진은 **상대 경로**다 (`public/product/merchandising/…`).
앞에 붙일 호스트는 **목록이 스스로 준다** — 상대 경로와 온전한 주소를 나란히 적는다.

```
exteriorImagePath  public/model/SPORTAGE_25_SIG_X_FSB.png
exteriorImageUrl   https://cpo-cdn.kia.com/public/model/SPORTAGE_25_SIG_X_FSB.png
```

받아 봤다 — `HTTP/2 200 · image/jpeg · 3,225,303 바이트`. 진짜 사진이다.
보배드림도 받아 봤다 — `HTTP/1.1 200 · image/jpeg`.

### 3-2. ★ 보배드림 — 한 쪽에 **여러 차의 사진**이 섞여 있다

딜러의 다른 매물과 광고 띠가 같은 쪽에 있다.
그 차의 것을 가리는 열쇠는 `og:image` 다 — 쪽이 **대표 사진**으로 지목한다.
실측: 한 쪽에 CyberCar 폴더가 셋 있었는데 **그 차 폴더 23장 · 남의 것 1장씩**이었다.
폴더로 가르면 안 섞인다.

### 3-3. ★ K카가 **값이 붙은 선택 옵션**을 준다

```
carJatoOptList[]  optNm "파퓰러 패키지"  optPrc "5100000"
```

이름만 있는 것(`optList`)과 **값이 붙은 것**(`carJatoOptList`)을 갈라 담았다 (지시 H).
252건에 값이 붙었다 — 신차출고가 셈에도 쓸 수 있다.

### 3-4. ★ 현대 인증도 **신차가**를 준다 — 신차출고가 7,772 → 8,923

`<input id="normPrc" value="62130000">`. 쪽이 스스로 「신차가」라 적고,
「신차 가격 대비 **21,230,000원** 절약」이 판매가와의 차와 정확히 맞는다.

```
신차가   62,130,000
판매가   40,900,000
차       21,230,000   ← 쪽이 적은 절약액과 같다
```

★ 다만 쪽에 **사이트 자신의 단서**가 붙어 있다 —
「**신차가는 실제출고가격과 다르게 표현될 수 있습니다**」.
지어낸 말이 아니라 원문에 적힌 것이라 **그대로 적어 둔다** (규칙 2).
출처는 `price_origin_total_src = 'hyundai_신차가'` 로 갈라 담았다.

## 4. 남은 1칸 — `bobaedream.트림` 은 **사이트가 안 준다**

보배드림 제원표에 트림/등급 칸이 **없다**.
120장을 훑어 나온 칸은 연식·주행거리·연료·배기량·색상·변속기·최고출력·복합연비·
승차정원·제작일·차대번호·제시일·신차대비… — **등급이 없다.**

판매자가 자유글에 「- 등급 : AWD 2.5」라고 적은 것이 **416장 중 20장**뿐이다.
그것은 사이트의 칸이 아니라 **사람이 친 글**이다. 값으로 삼지 않는다 (금지 6).

★ `S46-296` 이 이 한 칸을 계속 붉게 낼 것이다.
**「사이트가 안 주는 곳」을 가려 주는 자리**가 필요하다 — 확인을 받는다 (규칙 2).

★ BMW BPS 도 거의 안 준다 — 상세 217장 중 「차량등급」이 채워진 것 **3장** ·
옵션 이름이 있는 것 **16장**이다. 0 은 아니게 됐지만 1.0% · 3.6% 다.
**파서 잘못이 아니라 사이트가 안 적은 것**이다.

## 5. 새 자 — `tools/reparse_stored.py`

`tools/parse_stored_encar.py` 는 엔카 전용이고 **JSON 만** 읽었다.
열두 곳 중 여럿은 원문이 **HTML** 이다 (리본카 · 볼보 · BMW · 보배 · 현대).


* JSON 이든 HTML 이든 읽는다
* 파서마다 받는 꼴이 다르다 (`(html, source_id)` 둘인 곳도 있다) — 있는 대로 부른다
* **파서가 안 준 칸은 안 건드린다** — 있던 값을 「없음」으로 덮지 않는다 (금지 12)
* 다시 받지 않는다 — 파일이 정본이다 (S46-185)
