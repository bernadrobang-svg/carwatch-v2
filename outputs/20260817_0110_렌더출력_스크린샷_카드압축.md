## 8. 못 한 것 · 막힌 것 · 판단이 필요한 것

### ① ★ 시세는 아직 표다 — 스크린샷으로 확인했다

`outputs/shot/market_360.png` 를 보시면 가격 분포가 **막대가 아니라 숫자 표**다.
가이드 지적 ③ 이 맞다. **CSS 에 `.hist` 는 있는데 `market.html` 이 `<table>` 이다.**

**다음 작업으로 이것을 먼저 한다.**

### ② `/market` 이 360px 에서 가로로 넘친다

첫 표(관측일·매물·대상·최저·P25·중앙·P75·최고)가 화면 밖으로 나간다.
`V11-71` 은 `.rows`(목록)만 보므로 못 잡았다. **검사 범위를 넓혀야 한다.**

### ③ ★ 축 기호 「O」가 숫자 0 으로 읽힌다

스크린샷에서 `HUD 0` 처럼 보인다. 실제로는 대문자 O(있음)다.
규격 STEP 149f 가 「O 있음 · · 없음 · ? 확인 못 함」으로 못 박아 두어
**임의로 못 바꾼다.** `config/labels.json` 의 `VALUE_MARKS` 한 줄이면 바뀐다.

```
지금   O  ·  ?        ← 0 과 구분이 안 된다
안     ✓  ·  ?   또는   ●  ·  ?
```

**바꿔도 되는지 지시를 부탁한다.**

### ④ 카드 높이 — 규격 두 줄이 서로 부딪힌다

```
「카드에도 22개 값이 전부 들어간다」
「한 카드가 화면 절반을 넘지 않는다」
```

360px 에서 값 25개에 이름표를 붙이면 12줄 ≈ 440px 이다.
휴대폰 화면(약 800px)의 **55%** 라 「절반」을 조금 넘는다.
더 줄이려면 이름표를 빼야 하는데, 그러면 카드끼리 세로로 못 맞춘다.
**이대로 둘지, 이름표를 줄일지 지시를 부탁한다.**
