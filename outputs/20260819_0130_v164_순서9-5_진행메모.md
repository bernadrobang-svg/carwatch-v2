## 3. 무엇을 했나 · 왜 그렇게 했나

### ① `watch_note` — 새 표

```sql
CREATE TABLE watch_note (
  note_id    INTEGER PRIMARY KEY AUTOINCREMENT,
  account_id INTEGER NOT NULL,   -- ★ 계정별이다 (STEP 126)
  listing_id INTEGER NOT NULL,
  kind       TEXT NOT NULL,      -- contacted · visited · done
  body       TEXT NOT NULL,      -- ★ 본체.  비워 둘 수 없다
  noted_at   TEXT NOT NULL,
  CHECK (kind IN ('contacted','visited','done')),
  CHECK (body <> '')
);
```

```
★ 단계를 강제하지 않는다 — 순서도 없고, 앞 단계 없이 'done' 을 적어도 된다
★ 한 매물에 여러 줄이다 — 전화를 두 번 할 수도 있다
```

`python3.11 tools/migrate.py` 로 반영했습니다.

```
신규 테이블 1개: watch_note
데이터는 보존됐다.  원문은 무손실이다 (P3)
core_listing 7,809행 그대로
```

### ② `store/watch.py`

```
NOTE_KINDS   {"contacted":"연락함", "visited":"보러 감", "done":"끝"}
note_add()   갈래를 거른다 · 빈 메모를 거른다
notes_of()   ★ account_id 로 막는다 — 남의 메모는 안 보인다 (V7-12)
note_delete() ★ 남의 메모는 못 지운다.  note_id 는 연속 정수다
```

실제로 돌린 것

```

빈 메모 거절 무엇을 했는지 적어 주십시오.  메모가 본체입니다
남의 것 거절 남의 메모는 지울 수 없습니다
```
