## 2. 먼저 물음 두 개

### ⑥ `why_3_360.png` 는 옛 이름의 잔재입니다

파일 이름을 `why_{listing_id}` → `why_listing_id` 로 바꾸면서 옛 파일이 남았던 것입니다.
지금은 **`why_listing_id_360.png` 125,471바이트**입니다. 감가 곡선이 보입니다.

### 지역 · 연차가 「—」인 이유 — **원문에는 있는데 집계가 안 옮깁니다**

```
core_dealer.region          0 / 719      ← 비어 있다
core_dealer.career_years    0 / 719
core_listing.dealer_region  7,629건      ← ★ 원문에는 있다
```

**`S11` 딜러 집계가 매물의 지역을 딜러 행으로 안 옮깁니다.**
고쳐지기 전까지 화면이 매물에서 읽게 했습니다 (`_dealer_region`).
연차·판매는 원문에도 없어 「—」로 두고 이유를 툴팁에 적었습니다.

**S11 을 고쳐야 합니다 — 규격 확인을 부탁드립니다.**
