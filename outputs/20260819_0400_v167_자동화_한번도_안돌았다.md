## 3. 진짜 원인 — `done` 을 안 넘긴다

```python
# collect/pipeline.py  run_recalc()
return run_pipeline(conn, ctx, executors, steps=tuple(plan["steps"]))
                                          ★ done 이 없다
```

```python
# run_pipeline()
done = set(done or ())        ← 빈 집합으로 시작한다
for step in steps:
    rep = run_step(conn, ctx, step, done, executors, progress)
```

```python
# precheck()
missing = [s for s in PRECEDES.get(step, ()) if s not in done]

```

```
listing_updated 는 ("S5","S6","S9","S10") 을 돈다 — S4 는 안 돈다
done 이 비어 있으니 S5 의 선행 S4 가 영원히 「미완료」다
★ 사유 여섯 중 다섯이 같은 이유로 첫 단계에서 죽는다
```

### ★ `diagnose()` 는 처음부터 맞게 하고 있었습니다

```python
def diagnose(...):
    done = completed_steps(conn)      ← 이쪽은 채운다
```

`completed_steps()` 의 주석이 이미 답을 적어 두었습니다.

```
「이어서 돌 때 앞 단계를 다시 요청하지 않기 위한 것이다」
```

**한쪽만 쓰고 다른 쪽은 안 썼습니다.**
