## 4. ★ 엔카 옵션 이름 **3개 → 88개** — 그런데 파퓰러는 여전히 못 읽는다

`raw/encar/catalog/` **731장**이 코드 ↔ 이름 ↔ 정가를 준다. 아무도 안 읽고 있었다.

```
1055 = 증강현실 헤드업 디스플레이(AR-HUD) …     → 42543098 은 HUD 있다
1081 = 파퓰러 패키지 I
```

### 자를 의심해 살린 것

이름을 풀고 「파퓰러 패키지Ⅰ 이상」을 걸었더니 ★ **기준차인 김포조차 「없다」**로 나왔다.
마스터가 고른 차가 조건을 못 지킬 리 없다 — **자가 틀린 것이다.**

까닭 — 엔카 **기본 옵션(`001`~`099`) 67개가 이름이 하나도 없다.**
`catalog` 는 **선택 옵션(1xxx)** 만 준다. 파퓰러 패키지Ⅰ 는 그 기본 묶음 쪽일 수 있다.

★ **모르면 「미조회」다.** 「없다」라 하지 않았다 (금지 12).
