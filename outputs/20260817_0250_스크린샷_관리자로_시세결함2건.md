## 2. ★ 제 잘못입니다 — 「36장 찍었다」를 확인 없이 보고했습니다

가이드 지적이 정확합니다.

```
렌더 결과(outputs/render/)   관리자로 만들었다 — 내용이 있다
스크린샷(outputs/shot/)      돌고 있는 서비스를 찍었다 — 세션이 없어 「권한 없음」
```

**「돌았다」가 아니라 「쓸 수 있는가」인데, 제가 장수만 셌습니다** (개정 279).

### 고친 방법 — 렌더 결과를 그대로 찍는다

세션을 흉내 내지 않는다. **이미 관리자로 만든 HTML 을 `file://` 로 찍는다.**

```
outputs/render/*.html  →  임시 폴더에 복사 (app.css 를 옆에 두고 링크만 고침)
                       →  firefox --screenshot file://…
★ 화면과 스크린샷이 같은 HTML 에서 나온다 — 둘이 어긋날 수 없다
```

### 그리고 「내용이 있는가」를 도구가 스스로 본다

```python
# ★ 「찍었다」가 아니라 「내용이 있는가」를 본다 (개정 279)
DENY_MARK = "관리자만 볼 수 있습니다"
if DENY_MARK in html:
    empty.append(f"{name} — 권한 없음 화면이다")
```

빈 장이 있으면 `outputs/shot/README.md` 에 「내용이 없는 화면」으로 적히고
실행 로그에도 찍힌다. **같은 실수를 다시 하면 도구가 먼저 말한다.**

### ② 스크린샷에서 사진은 여전히 빈 칸이다

`file://` 로 찍으므로 `ci.encar.com` 을 부르지 않는다.
**마스터 브라우저에서는 뜬다** — 렌더 HTML 에 주소가 있고 HTTPS 혼합 콘텐츠도 0이다.
서버가 스크린샷을 위해 수천 장을 받아 오는 것은 하지 않는 것이 맞다고 판단했다.
