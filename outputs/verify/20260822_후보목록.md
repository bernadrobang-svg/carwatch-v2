# 0. ★ 앞 개정을 고친다 — 관문을 「버리는 것」에서 「등급을 낮추는 것」으로


## 고친 규칙 — 가격은 **등급 상한**으로 작동한다

| 구간 | 등급 상한 | 근거 |
|---|:--:|---|
| 예산 이하 · 신차가 대비 50~75% | **제한 없음** (S 가능) | 마스터가 사시는 자리 |
| 예산 초과 ~ **+500만** · 밴드 안 | **B** | 「500만원까지는 인내하고 볼 거야 · 다만 등급이 낮아야겠지」 |
| 예산 **+500만 초과** | **C** | 「내 예산보다 머니」 · ★ 그래도 버리지 않는다 |
| 신차가 대비 **75% 초과** | **C** | 「차라리 새 차를 사지」 |
| 신차가 대비 **50% 미만** | **제한 없음 + 사유 표시** | 「후보는 버리지 마」 → 개정 446 질문 ① 은 ㉯ 로 답이 왔다 |
| 신차가 **미확인** (556건) | **제한 없음 + 「신차가 미확인」 표시** | 「없음」과 「모름」은 다르다 (개정 289·434) |
