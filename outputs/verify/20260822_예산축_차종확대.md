# 1. 값 250 을 다시 나눈다

## 1-1. 지금

```

★ 셋 다 「시장」 기준이다.  ★ 마스터 예산은 어디에도 없다

```

## 1-2. 바꿀 것 — ★ 예산 축 신설

```
값 250  =  시세 대비 70  +  신차가 대비 60  +  주행 70  +  ★ 예산 대비 50

★ 총점 675 는 그대로다.  ★ 갈래(값 250)도 그대로다.  ★ 값 안에서만 나눈다
  → 마스터가 정하신 총점·갈래를 안 흔든다 (오판대장 모양 ③)
```

**예산 대비 점수 — 계단이 아니라 직선으로 (개정 419 「계단표를 없앴다」를 따른다)**

```
d = (그 차종 예산 − 표시가) / 그 차종 예산 × 100      ← 예산보다 몇 % 싼가

d ≥ 20%   → 50점 (만점)
0 < d < 20% → d × 2.5 점
d ≤ 0     → 0점            ★ 감점하지 않는다.  4,000만 관문이 따로 막는다 (개정 444)

config/scoring.json
  components.value = { market: 70, depreciation: 60, mileage: 70, budget: 50 }
  axis_rules.value.budget_per_percent_cheap = 2.5
  axis_rules.value.budget_max = 50
  axis_rules.value.budget_min = 0
  axis_rules.value.budget_full_percent = 20
```

# 2. 차종별 예산 — 관리페이지에서 넣는다

## 2-1. 어디에 넣나

`ref/screens/v2_admin_targets_시안.html` 의 **「차종」 화면**이 이미 있다.
지금 4단계다 — `1 모델 지정 → 2 facet 확인 → 3 트림 선택 → 4 등록`.
★ **여기 4단계에 「예산」 칸을 더한다.** 새 화면을 만들지 않는다 (원칙 1).

```
차종 등록/수정 화면에 더할 칸
  ★ 목표 가격 (예산)   [        ] 만원      ← 이 차종을 이 값 이하로 사고 싶다
  안내문  「값 250점 중 예산 50점이 이 값을 기준으로 붙습니다.
           비워 두면 전역 기본값을 씁니다」

목록 표에도 한 칸 더한다 — 차종 · 제조사 · 모델그룹 · 건수 · ★ 예산 · 상태
```

## 2-2. 저장 위치

```
config/targets.json 의 차종마다   "budget_won": 33000000        ← 없으면 전역값
config/scoring.json               "budget_default_won": 40000000  ← 전역 기본값 (마스터 4,000만)

★ 등급 관문(개정 444 — 4,000만 초과는 S·A 불가)도 ★ 같은 값을 쓴다
  차종 예산이 있으면 그 차종은 ★ 그 값이 관문이 된다
  예) 그랑 콜레오스 예산 3,300만 → 3,300만 초과 그랑 콜레오스는 S·A 를 못 받는다
★ 예산을 바꾸면 ★ S9 부터 다시 돈다 (개정 426 — 배점을 축 함수가 직접 읽는다)
  ★ 미리보기 금지.  config 에 저장하고 recalc 한다
```

# 3. 차종 확대 — BMW · 렉서스

## 3-1. ★ 렉서스는 마스터 조건에 정확히 맞는다

| 모델 | 2.0 가솔린 | 하이브리드 | 판단 |
|---|---|---|---|
| **NX** | ★ **있다** — NX200t(2.0 터보 238마력, 2015~) → 2017 부분변경으로 **NX300** 으로 개명 | ★ **있다** — NX300h · 2022~ **NX350h · NX450h+**(PHEV) | ★ **등록** |
| **RX** | ★ **있다** — RX200t → RX300 (2.0 터보) | ★ **있다** — RX450h · RX350h · RX500h | ★ **등록** |

```
★ 마스터 말씀 「하이브리드와 2.0 가솔린」이 ★ 렉서스 NX·RX 에 그대로 있다

  → year_range 를 좁히면 2.0 가솔린이 통째로 빠진다.  ★ 넓게 열고 트림으로 가른다
```
