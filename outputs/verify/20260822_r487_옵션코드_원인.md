
# 2. ★ 그래서 이렇게 된 것이다

```

사전 →  dict_option_code(code='1039', ★ display='1039')                        ✘ 이름 없음

채점 →  dict_model_option 을 읽는다                                            ✔ 이름·가격 씀

```

```
★ `report/render.py:414` 주석에도 이렇게 적혀 있다 —
  「★ 코드만 내면 사람이 못 읽는다.  사전에 이름이 있으면 붙인다 —
    없으면 코드를 그대로 낸다.  추정으로 이름을 만들지 않는다」
★ 코드는 ★ 맞게 짜여 있다.  ★ 「사전에 이름이 있으면」의 ★ 그 사전이 ★ 빈 것이다
★ 정확히는 ★ 빈 것이 아니라 ★ 이름 대신 코드가 채워져 있다
```

# 3. ★ 고칠 것 — 셋 중 하나

```

```

