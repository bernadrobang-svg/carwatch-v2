## 2. L-10 — 3건 받고 60초 쉰다

마스터 실측을 그대로 값으로 옮겼습니다.

```
0.3초로 몰아침        2~3건에서 407 로 잠긴다
잠긴 뒤 0.5초 12번    200 이 2건
잠긴 뒤 2.0초 12번    200 이 ★ 0건 — 느리게 해서 될 일이 아니다
쉬어 봄               ★ 1분이면 풀린다
```

★ 값은 `config/endpoints.json` `encar.browser_batch` 가 정본입니다 (코드에 안 박았습니다):

```json
"inspection": {"n": 3, "rest_sec": 60},
"record":     {"n": 3, "rest_sec": 60}
```

★ **상세는 안 묶습니다** — 서버에서도 열리는 창구입니다.

### 잠기면 — **건너뛰지 않고 그 자리를 다시** 부릅니다

```
http 0 · 407 · 429  →  60초 쉰다  →  ★ 같은 매물을 다시
```

★ 쉬는 동안에도 ★ 남은 초를 화면에 셉니다 — ★ 멈춘 것처럼 보이면 안 됩니다.

### 걸리는 시간을 **쉬는 시간까지 넣어** 냅니다

```
성능점검 30건   3초  →  ★ 9분 3초
보험이력 10건   1초  →  ★ 3분 1초
상세     30건        3초  (안 쉰다)
```

★ 전에는 쉬는 시간을 빼고 적어 ★ **거짓말**이었습니다.

★ 단계 단추가 이제 주소를 옮깁니다 (`/fetch?step=3&n=30`) —
★ 창구마다 묶음·쉼이 다르므로 ★ **그 단계 값이 실려야** 합니다.
★ 실측 — `?step=3` 에서 `BATCH 3 · REST 60000` 이 실립니다.
