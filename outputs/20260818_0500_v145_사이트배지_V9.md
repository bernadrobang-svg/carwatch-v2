## 6. 못 한 것 · 판단이 필요한 것

### ① 「사이트별로 거를 수 있게 한다 — 단추」를 안 만들었습니다

```
「엔카만」 「K카 직영만」 「전부」
```

**쓰는 사이트가 엔카 하나라 단추가 하나뿐입니다.**  지금 넣으면
「엔카만」 단추 하나가 늘 켜져 있는 화면이 됩니다.
K카가 `active` 가 될 때 함께 넣겠습니다.  그래도 지금 넣을까요.

### ② 부록 G 좁은 폭 도면에 「사이트」가 없습니다

50-multisite 는 「목록 전부에 배지」라 하고,
부록 G 좁음(<640) 도면에는 사이트 칸이 없습니다.

```
한 것   배지는 HTML 에 늘 있습니다 (V9-06 통과).
       640 이상과 /why 에는 보이고, 360px 목록에서만 접힙니다
       (config/web.json narrow_folded_labels)
       ★ 추천 카드에는 360px 에서도 보입니다 — 트림 줄에 있어서입니다
물어봄  360px 목록에서도 배지를 보여야 합니까
```

### ③ V9-07 은 아직 못 재 봤습니다

사이트가 하나라 「합친 값」이 없습니다.  검사는 「해당 없음」을 내고
**왜 해당 없는지를 적습니다** — 「사이트가 하나라서 통과」로 위장하지 않습니다.
K카가 붙는 순간부터 진짜로 잽니다.

### ④ K카 어댑터가 아직 없습니다

`config/sites.json` 의 `kcar` 는 `planned` 입니다.
「K카 XHR 6경로 → `adapters/kcar.py`」가 다음 차례입니다.
★ 배지·검사는 K카가 붙으면 **코드를 안 고치고** 바로 「K카 직영」을 냅니다.
