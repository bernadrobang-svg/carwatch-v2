## 4 · 5 몇 → 몇 — ★ 눌러서 쟀다

주소를 직접 눌러 빈 쪽까지 걸었다 (200 으로 세지 않았다) —

```

빈 질의(전량)    → 590건 · 59쪽
```

★ 거르개가 **실제로 먹는다** (276 ≠ 590).
규격은 08-29 에 200건이라 적었다 — 오늘은 **276건**이다. 재고가 늘었다.
