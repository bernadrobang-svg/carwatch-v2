### ★★ 파싱 결함 — 이것이 2단계의 핵심이었다

옛 파서는 `name.split(maxsplit=2)[1]` — **연식 다음 낱말**을 차종으로 삼았다.

```
「2021 더 뉴 G70 가솔린 2.0 …」        → 차종 = ★ 「더」
「2023 더 뉴 그랜저 (IG) LPG 3.0 …」   → 차종 = ★ 「더」
```

★ `site_model_group='더'` 인 매물이 **221건**이었고, ★ 그 안에 **「더 뉴 그랜저」 152건**이 있었다.
★ 그것이 규격이 「`IG02`·`GN01` ★ 둘 다 받으라」 한 **`IG02` 세대**다 (`TARGET_KEY_MAP` 4장).
★ 즉 **대응표를 아무리 잘 넣어도 IG02 는 닿지 못하는 상태**였다.

`_model_group()` 은 연식을 떼고 → 꾸밈말(`디 올 뉴`·`올 뉴`·`더 뉴`·`신형`·`Electrified`)을 떼고
→ 다음 낱말을 차종으로 삼는다. ★ 꾸밈말 목록은 **DB 에 실제로 들어온 제목에서 세어 뽑았다** — 지어내지 않았다.

## 3. 왜 그렇게 했나

```

TARGET_KEY_MAP 6장  mapped 가 빈 사이트값은 「차종 미정」으로 둔다 — 버리지 않는다
TARGET_KEY_MAP 4장  그랜저가 코드 둘(IG02·GN01)로 갈려 있다 — 둘 다 받아야 한다
```
