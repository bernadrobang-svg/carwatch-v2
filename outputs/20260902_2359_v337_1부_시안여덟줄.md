## 1-1 「N곳」 배지 — **8회차째** · 틀은 멀쩡했다

★ 여덟 회차 동안 「배지가 0개다」라고 적혔다. **재 보니 틀은 맞았다** —

```
/listings                 배지 0개   ← 기본 쪽 (차례 = 순위)
/listings?order=price     배지 3개   ← ★ 난다
```

★ 까닭 — **같은 차가 여러 곳에 있는 매물은 순위가 낮다.**
화면에 나오는 5,522행 중 배지 대상은 **154행(2.8%)** 이라
앞 30행에 하나도 안 들어온다. **틀이 아니라 차례의 문제다.**

★★ 그런데 **진짜 어긋남을 하나 찾았다** —

```
목록 화면   같은 차 = ★ **번호판**만
/track     같은 차 = ★ **번호판 ＋ 차대** (union-find)
★ 같은 「같은 차」를 ★ **두 자로 재고 있었다**
```

이 판이 막으려는 것이 바로 그것이다(「선언과 실제의 괴리」·`docs/guide/00_개요.md`).
화면도 차대를 보게 했다.

| | 앞 | 뒤 |
|---|--:|--:|
| 배지가 붙는 행 (화면 5,522행 중) | 154 | **161** |

★ `/track` 의 **176대**와는 아직 다르다 — union-find 는

## 1-4 「왜 없나」를 글로 (`RULES.md` 2)

```
현대인증 174 · 헤이딜러 92 · 보배드림 47 · BMW BPS 9 = ★ 322건
   → ★ 그 사이트에서 ★ **한 장도 못 받았다** (우리 잘못)
엔카 28건
   → ★ 9,319장을 받고 있다.  ★ **그 매물에 사진이 없다** (사실)
```

둘을 가르는 글을 낸다 — `store.core.photo_ready_sites()` 로 잰다.

```
확인   /listings?site=bobaedream   「보배드림은 사진을 아직 못 받았습니다」 60
      /listings?site=heydealer    「헤이딜러는 사진을 아직 못 받았습니다」 60
```

★ 조사도 맞췄다 — 「보배드림**는**」이 아니라 「보배드림**은**」이다
(받침 셈 `(ord(글자) − 0xAC00) % 28`).
★ 목록·관심·상세 세 틀에 넣었다.

