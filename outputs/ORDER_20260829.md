## 2. 관리 질의 ORDER BY＋LIMIT 허용

| 파일 | 줄 | 지금 |
|---|--:|---|
| `store/adminops.py` | 43 | `WRITE_OPCODES` 에 `Delete`·`IdxInsert` 포함 |
| 〃 | 523 | `ops & WRITE_OPCODES` 로 판정 |

정렬은 임시 테이블을 쓰므로 `Delete`·`IdxInsert` 가 나온다. 커서 번호(P1)로 구분한다.

```python
TEMP = {"OpenEphemeral","SorterOpen","OpenAutoindex","OpenDup","OpenPseudo"}
HARD = {"Clear","Destroy","DropTable","DropIndex","CreateBtree","OpenWrite"}
temp = {r[2] for r in plan if r[1] in TEMP}
hard = [r[1] for r in plan if r[1] in HARD]
bad  = [r[1] for r in plan if r[1] in WRITE_OPCODES and r[2] not in temp]
is_write = bool(hard or bad)
```

확인 완료: 조회 4종 통과, `INSERT`·`DELETE`·`UPDATE`·`DROP`·`CREATE` 5종 차단 유지.

## 진행 방식

멈추지 않는다. 질문이 있어도 멈추지 않는다.

| 상황 | 어떻게 |
|---|---|
| 막히는 것이 있다 | 그 항목만 남기고 **다음 항목으로 넘어간다** |
| 판단이 필요하다 | 가장 안전한 쪽으로 정하고 **회차 문서에 적는다** |
| 지시가 틀린 것 같다 | **그렇게 적고 그대로 진행한다**. 되돌리는 것이 진행 안 하는 것보다 싸다 |
| 다 끝냈다 | 회차 문서 하단에 「여쭐 것」과 「이견」을 적는다 |

허락을 기다리지 않는다. 앞 회차에서 질문하고 멈춘 일이 있었다.
질문은 회차 문서에 적고 작업은 끝까지 한다.
