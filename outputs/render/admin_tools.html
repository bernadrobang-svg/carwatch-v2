도구

도구는 읽기 또는 설정 변경만 합니다. 데이터를 고치지 않습니다 — 데이터 수정은 재파싱·재판정으로 합니다.
★ 도구 결과는 제안입니다. 적용은 설정 화면에서 사유와 함께 합니다 — 「산출했다」와 「바꿨다」는 다릅니다. 근거 STEP 135

DDL 을 고쳤을 때 기존 DB 를 따라가게 합니다. 데이터를 지우지 않습니다.

python run.py migrate

내보내기

매물 · 판정 · 축별 근거를 CSV 로 냅니다. 개인정보는 빠집니다. 덮어쓰지 않고 새 파일로 냅니다.

python run.py export --format csv
python run.py report
