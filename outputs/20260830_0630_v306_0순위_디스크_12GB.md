## 3 ★ 까닭이 둘이었다 — 하나만 고치면 또 샌다

### ① `check_all` 은 **한 번도 안 치웠다**

명령서는 `run_tests._sweep_temp` 을 짚으셨는데, 재보니 그것은 **끝에 치우고 있었습니다.**
안 치우던 것은 **`check_all`** 입니다 — 청소기를 아예 안 부릅니다.
제가 하루에 수십 번 돌리는 것이 그쪽입니다. **그것이 12GB 의 진짜 자리입니다.**

### ② 청소 조건이 우리 자리에 안 맞았다

```
cutoff = now - 60초 · stale = now - 6시간
if made < cutoff and made > stale:  continue   # 「남의 것이고 아직 쓸 수 있다」
```

`/tmp` 에는 남의 프로세스 것이 섞이므로 맞는 규칙입니다. 그런데
**`outputs/check-tmp` 은 검사기만 쓰는 자리**라 「남의 것」이 없습니다.
`check_all` 한 판이 몇 분이라 **그 사이에 생긴 것이 전부 60초~6시간 구간**에 들어가
**영영 안 치워졌습니다.**
