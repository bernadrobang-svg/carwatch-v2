### ★ 결론 — **③ 이되 「규칙이 안 맞다」가 아니라 「규칙이 맞게 걸러낸 것」**

**① 목록 쿼리 — 아니다**

브라우저가 부른 URL 391개의 `q=` 를 전부 뽑아 서로 다른 조건을 셌다.

```
서로 다른 q 조건 8개 = collect_group 8개
(And.Hidden.N._.MultiViewHidden.N._.Year.range(202100..)._.Price.range(..6000)
 ._.(C.CarType.Y._.(C.Manufacturer.제네시스._.ModelGroup.…)))
```

**8묶음 전부에 제조사·모델군 조건이 들어 있다.** 쿼리는 정상이다.

**② 다른 차종이 섞였나 — 아니다**

NULL 매물의 제조사·모델군을 셌다.

```
현대 그랜저 1,291 · 기아 스포티지 1,195 · 제네시스 GV70 1,046
제네시스 G80 533 · 제네시스 G70 74 · 르노코리아 그랑 콜레오스 50
```

**전부 우리가 고른 8종 안이다.** 다른 차종은 한 건도 없다.

**③ 분류 — 여기다. 다만 규칙이 의도대로 걸러냈다**
