### CORS — 서버에서 잴 수 있는 만큼은 쟀다

```
curl -H "Origin: http://43.201.16.78:8765" ...

/v1/readside/vehicle/39554653   HTTP/2 200
    access-control-allow-origin: *
/search/car/list/mobile         HTTP/2 407
    access-control-allow-origin: http://43.201.16.78:8765   ← Origin 을 되돌려준다
```

**엔카는 두 엔드포인트 모두 CORS 를 허용한다. 407 은 CORS 가 아니라 IP 차단이다.**
따라서 휴대폰 회선에서 407 이 안 나면 브라우저 JS 가 응답을 읽을 수 있다 —
`STEP 136c` 가 성립할 공산이 크다. 확정은 휴대폰 결과로만 된다.
