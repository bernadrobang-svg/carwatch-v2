```

         로직에 반영하거나 수집 또는 리포트일 텐데」
```

**★ 「해당 없음」으로 치우려 한 것이 잘못입니다. 화면이 아니면 어딘가 다른 층에 있습니다.**

| 층 | 어디 |
|---|---|
| 수집 | `collect/` · `adapters/` |
| 저장 | `store/` · `sql/ddl/` |
| 파싱 | `parse/` |
| 사전 | `store/dict.py` |
| 판정 | `analyze/` · `score/` |
| 화면 | `web/` · `report/screens/` |
| 검사 | `validate/` · `tools/` |
| 운영 | `store/adminops.py` · `deploy/` |

```
필수   R 마다 층을 적는다
필수   ★ 「화면」 칸은 층이 「화면」인 R 에만 요구한다
       다른 층이면 「—」.  「화면 없음」이 아니다
필수   층이 둘이면 둘 다 — 「수집·화면」
       예   「407 을 그대로 화면에 낸다」 → 수집이 잡고 화면이 낸다
금지   층을 안 적고 「해당 없음」이라 치우는 것
검산   S39-1 · S39-2
```
