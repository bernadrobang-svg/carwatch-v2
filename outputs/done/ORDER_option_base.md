# 개정 381 — 옵션 기준값을 차종 단위로

**마스터 확정 — 「트림 다 챙겨야지. 그런데 스탠다드에 옵션이 좋아」**

---

# 1. 지금 배점으로도 마스터 뜻과 맞습니다

```
GV70_EV 트림 3개
  스탠다드 + 옵션 700만   트림 8.3 + 옵션 20 = 28.3
  스포츠 깡통            트림 16.7 + 옵션 0 = 16.7
★ 스탠다드가 높습니다
```

**트림 25 + 옵션 20 은 그대로 둡니다.**

---

# 2. ★ 다만 옵션 기준값을 고칩니다

```
전   B = 그 차종·트림의 P90
     ★ 트림별로 재면 스탠다드끼리만 견줍니다
     ★ 다른 스탠다드도 옵션이 많으면 점수가 안 높아집니다
후   B = 그 차종 전체의 P90
```

```
필수   B 는 차종 단위.  트림으로 나누지 않는다
필수   전 차종을 뭉치지도 않는다 — 제네시스와 스포티지는 폭이 다르다
필수   화면에 — 「옵션 713만 / 이 차종 기준 900만」
검산   V3-73  옵션 기준값이 차종 단위인가
       V3-74  ★ 같은 신차가면 옵션 많은 하위 트림이 더 높은가
              표본 두 건으로 대조
```

---

# 3. ★ 확인해 주십시오

```
GV70_EV 71건으로 실측하십시오
  트림별 건수 · 트림별 옵션가 합 분포
  ★ 스탠다드에 옵션 많은 차가 실제로 위로 올라오는가
★ 안 올라오면 그것이 결함입니다
```

---

# 4. 왜 중요한가

```
마스터는 「스탠다드에 옵션을 넣은 차」를 찾고 계십니다
★ 트림 이름이 아니라 실제로 무엇이 달렸는지가 값입니다
★ 트림 25 는 「어느 급인가」, 옵션 20 은 「얼마나 채웠나」 — 둘 다 필요합니다
```
