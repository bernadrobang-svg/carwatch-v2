## 2-1. 상태를 세 칸에서 유도한다

| 소스 | 화면 | 검사 | 상태 |
|---|---|---|:--:|
| 있음 | 참 또는 「해당 없음」 또는 「—」 | 있음 | **○** |
| 있음 | 하나라도 빔 | | **◐** |
| `미구현` · `미확인` | | | **✗** |

```python
def derive_state(src, ui, chk):
    """★ 상태는 계산값이다.  사람이 적지 않는다 (개정 405)."""
    if src in (NO_SRC, UNKNOWN, ""):
        return "✗"
    ui_ok = ui not in ("화면 없음", "")          # 「해당 없음」·「—」는 충족 (S39)
    chk_ok = bool(chk) and chk != "—" and "검사 없음" not in chk
    return "○" if (ui_ok and chk_ok) else "◐"
```

```
필수   ★ 「검사 없음(규격에만)」도 「검사 없음」이다.  번호가 있어도 코드가 없으면 못 지킨다
필수   화면 칸 「—」는 층이 화면이 아니라는 뜻이다 (S39).  「해당 없음」과 같이 본다
검산   S38-4  상태가 유도값과 다른 행이 있는가 (있으면 실패)
```
