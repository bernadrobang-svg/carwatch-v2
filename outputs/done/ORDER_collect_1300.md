# ★★ 자동 수집을 13:00 으로 — 개정 388

**마스터 지시 — 「수집은 내가 해줘야 한다면 시간이 틀렸다. 오후 1시로 바꾸자」**

---

# 1. 왜 04:00 이 틀렸나

```
엔카 목록은 407 — 서버가 못 받습니다
★ 마스터가 /admin/collect 를 눌러야 목록이 들어옵니다
★ 새벽 4시에 큐를 넣고 알림을 띄워도 마스터가 못 봅니다
★ 그동안 가격 변동이 멈춥니다
```

---

# 2. 새 시간표

| 무엇 | 언제 | 누가 |
|---|---|---|
| 가벼운 점검 | 4시간마다 (02·06·10·14·18·22) | 서버 |
| **자동 수집 큐** | **13:00** | **서버 → 마스터 알림** |
| 일일 점검 | 23:00 | 서버 |
| 주간 일제 | 금 02:00 | 서버 |

```
★ 13:00 에 큐를 넣고 마스터를 기다립니다
★ 마스터가 누르면 그 뒤 단계가 이어서 돕니다 (STEP 136g)
```

---

# 3. 규격

```
필수   자동 수집은 13:00 — config.collect_daily_at
필수   ★ 사람 손이 필요한 일은 사람이 깨어 있을 때 돈다
       ★ 이것을 규칙으로 둔다
필수   서버가 혼자 하는 것은 시간을 안 가린다 — 파싱 · 판정 · 검사 · 점검
필수   13:00 에 목록이 오래됐으면 화면 맨 위에
       「목록이 N일째입니다 — 브라우저 수집을 눌러 주십시오」
검산   V10-31 · V10-32
```

---

# 4. 고칠 것

```
deploy/carwatch-daily.timer
  OnCalendar=*-*-* 04:00:00  →  13:00:00
config
  collect_daily_at = "13:00"   ★ 새 키
★ 타이머가 config 를 읽게 하거나, 둘을 함께 고친다
```
