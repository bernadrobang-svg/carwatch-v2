# 1. 개정 412 — 32건 전부 `used` 로 등록한다

```
★ 이 32건은 「새로 쓸까 말까」가 아니다.
  파서가 이미 읽고 있는데 사전(field_usage.json)에 없는 것이다
  목록의 「파서가 읽는 곳」 칸이 32건 전부 파일·줄을 갖고 있다
★ 읽는데 사전에 없으면 판정이 멈춘다.  그것이 V4-11 fatal 이다
```

```
필수   32건 전부 status=used 로 등록한다
```

## 개발측이 확인할 것 — 셋 중 무엇인가

| 갈래 | 뜻 | 어떻게 가르나 |
|---|---|---|
| ① 원문에 없다 | 엔카가 안 준다 | 원문 `body` 를 열어 그 키가 있는지 |
| ② 원문에 있는데 못 읽는다 | 경로가 틀렸다 | 키는 있는데 파서가 `None` 을 받는다 |
| ③ 아직 안 받았다 | 그 엔드포인트를 안 부른다 | `raw_response` 에 그 `endpoint` 행이 있는지 |

```
필수   아홉을 하나씩 위 셋으로 가른다.  ★ 뭉뚱그리지 않는다
필수   ★ 원문을 직접 열어 확인한다.  파서 결과만 보지 않는다 (S43-②)
필수   ② 이면 어느 키에 있는지 실제 원문 조각을 함께 낸다
필수   ③ 이면 왜 안 부르는지 — 목록에 없나 · 실패했나 · 조건이 있나
필수   결과를 표로 낸다 — 경로 · 갈래 · 근거 · 원문 조각
금지   「값이 없습니다」로 끝내는 것
검산   V1-24  판정 축이 쓰는 경로 중 전건 null 인 것을 센다 (신설)
```
