## 3. 무엇을 했나 · 왜 그렇게 했나

### ① `config/sites.json` — 사이트마다 구매비용 구성

```json
"encar": { "purchase_cost": {
   "total_from_site": false,          ← 엔카는 총액을 안 준다
   "transfer_fee_rule": "acquisition",
   "warranty_fee": 0, "etc_fee": 0, "delivery_fee": 0, "extra_benefit": [] }}

"kcar":  { "purchase_cost": {
   "total_from_site": true,           ← ★ K카는 화면에 낸다.  받아서 쓴다
   "transfer_fee_rule": "acquisition",
   "warranty_fee": 498000, "etc_fee": 385000, "delivery_fee": 0,
   "_measured": "차량가 34,300,000 + 이전등록 2,523,000 + K Car Warranty 498,000
                 + 기타 385,000 + 배송 무료 = 37,706,000" }}
```

★ **사이트 이름을 코드에 안 씁니다** (V3-55).  `sites.json` 이 정본입니다.

### ② `report/finance.py: purchase_cost()`

```
사이트가 총액을 줬다   →  그것을 쓴다.  내역을 지어내지 않는다
                        「사이트가 낸 부대비용」 한 줄로 차액만 적는다
안 줬다              →  차량가 + 이전등록비 + 보증 가입비 + 기타 + 배송
                        ★ estimated=True.  「추정」을 숨기지 않는다
```

실제로 돌린 것

```
엔카  차량가 26,700,000 · 이전등록비 1,869,000            → 28,569,000  추정
K카   차량가 34,300,000 · 이전등록비 2,401,000
      · 보증 가입비 498,000 · 기타 385,000                → 37,584,000  추정
K카   차량가 34,300,000 · 사이트가 낸 부대비용 3,406,000   → 37,706,000  사이트 제공
```

### ★★ 우리 계산이 K카 실측과 122,000원 모자랍니다 — 그것이 「추정」의 정체입니다

```
K카 실측   37,706,000
우리 계산  37,584,000
차이          122,000   ← 공채 · 증지 · 이전등록 대행비
```

```
2,523,000 / 34,300,000 = 7.355%
취득세 7% = 2,401,000                   ← finance.json tax_acquisition_rate
나머지 122,000 = 공채 + 증지 + 이전등록 대행비  ← bond_table 이 비어 있다
```

★ 규격이 「**요율 조사 필요**」라고 적어 둔 바로 그 자리입니다.
**숫자를 지어내지 않았습니다.**  화면에 「추정」과 함께
「실제로는 이보다 조금 더 나옵니다」를 적었습니다.

## 6. 못 한 것 · 막힌 것 · 판단이 필요한 것

### ① ★ 막힘 — K카 총액을 아직 못 받습니다

```
규격   「사이트가 총액을 주면 그것을 쓴다.  ★ K카는 화면에 낸다.  받아서 쓴다」
지금   K카 매물이 0건이다 (순서 8 — 목록 경로를 못 찾았다)
       parse/kcar/ 가 없다
```

**받는 길은 만들어 뒀습니다.**  `purchase_cost(..., site_total_won=…)` 에
숫자를 넣으면 바로 「사이트 제공」으로 나옵니다.
K카 목록이 뚫리는 대로 파서에서 이어 붙이겠습니다.

### ② ★ 판단이 필요합니다 — 공채·증지 요율 (규격이 「조사 필요」라 적은 것)

```
지금   취득세 7% 만 넣는다.  K카 실측 대비 122,000원 모자란다
필요   config/finance.json 의 bond_table — 지역별 공채 매입률
       fee_stamp (증지대) · fee_transfer (이전등록 대행비)
```

```
① 마스터가 요율을 주십니다  →  config 에 넣고 「추정」을 뗍니다
② K카 실측에서 역산합니다   →  ★ 표본 1건이라 일반화가 위험합니다
③ 이대로 둡니다            →  「추정」이 계속 붙습니다
```

**②는 제가 하지 않았습니다.**  한 대에서 나온 122,000원을 요율표로 만들면
그것이 「선언과 실제의 괴리」가 됩니다.

### ③ ★ 판단이 필요합니다 — 「제네시스 10년 보증」을 어디서 압니까
