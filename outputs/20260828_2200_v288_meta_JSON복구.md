## 1. 무엇이 문제였나

`tools/repair_facet_chunks.py` 가 조각을 표시할 때 **JSON 뒤에 글자를 이어붙였다.**

```sql
UPDATE raw_response SET status='error',
  response_meta = COALESCE(response_meta,'')
    || ' | 조각이다 — 이어붙인 것이 따로 있다 (개정 307 복구)'
```

```
결과   {"fetched_by": "browser", "http_code": 200} | 조각이다 — 이어붙인 것이 …
       ★ JSON 이 아니다.  55건
```

무엇이 깨지나

```
① sqlite 의 json_extract 가 「malformed JSON」으로 ★ 죽는다
   ★ v287 이관을 처음 돌렸을 때 실제로 여기서 터졌다
② V11-47 이 그 55건의 「보낸 바이트」를 못 잰다
③ 원문 압축(v287)이 그 55건을 ★ 못 눌렀다 — 잴 길이를 남겨야 했다
```

★ 또 하나 — 이어붙인 것을 저장할 때도 `(row[6] or "{}").rstrip("}")` 로
**글자를 잘라 붙였다.** `response_meta` 가 이미 JSON 이 아니면 **더 망가진 것**을 만든다.

## 2. 무엇을 했나

`tools/repair_facet_chunks.py`

```
새로   meta_of(text) -> dict
       ★ JSON 이면 그대로.  아니면 앞의 JSON 만 떼고 뒤 글을 note 로 옮긴다
       ★ 버리지 않는다
새로   fix_meta(conn, apply)  ·  --fix-meta 모드
       ★ JSON 이 아닌 response_meta 를 되돌린다.  조각을 다시 이어붙이지 않는다
고침   이어붙인 것의 meta   글자 손질 → json.dumps({**meta_of(...), "transfer": "chunked"})
고침   조각 표시           || ' | 조각이다 …'  →  {"note": FRAGMENT_NOTE}
       ★ 글자는 앞판과 똑같이 뒀다 — 사람이 찾던 말이다
```

```

```
