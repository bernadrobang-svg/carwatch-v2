### 2-1. ★ `ld+json` 을 먼저 쓴다

상세 머리에 `application/ld+json` 이 있다. ★ 차명·제조사·값이 ★ 파싱 없이 온다.

```json
{"name":"BMW X3 (G45) xDrive 20 M Sport (2026년형)",
 "brand":{"name":"BMW"},
 "offers":{"price":"73800000","priceCurrency":"KRW"}}
```
★ 값이 ★ **원 단위**로 온다 — ★ `×10000` 하지 않는다 (`MULTISITE_MAPPING` 5a① 은
「KB 는 만원」이라 적었으나 ★ `ld+json` 은 원이다. ★ 아래 6장 ⓒ).

### 2-2. ★★ `is_bot_wall` 이 ★ 진짜 끝을 ★ 봇 차단으로 읽고 있었다

```
★ 진짜 끝 쪽은 ★ 3,585B 다.  ★ `bot_min_bytes` 가 ★ 10,000 이라
  ★ 「10KB 미만 = 봇 차단」에 ★ 끝 쪽이 걸린다
→ ★ 끝에서 ★ 3회씩 다시 부르고 ★ 멈추지도 못한다
조치  ★ `is_real_end()` 를 ★ 먼저 본다.  ★ 끝이면 ★ 봇 차단이 아니다
```

| 넣은 것 | 봇차단 | 진짜끝 |
|---|:--:|:--:|
| 3,585B + 「차량이 없습니다」 | **False** | **True** |
| 「로봇 여부 확인 중」 | **True** | False |
| 300,000B 정상 | False | False |

```

**② 차종이 「The」·「뉴」가 됐다 — ★ 현대와 같은 병이다**

```
