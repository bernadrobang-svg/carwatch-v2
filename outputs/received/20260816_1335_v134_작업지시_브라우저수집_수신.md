# 2. `STEP 136c` — 브라우저 수집 (`/admin/collect`)

**CORS 가 되면 이걸 만듭니다.**

## 흐름

```
① 「조회」    브라우저 JS 가 엔카를 직접 부른다 (사용자 회선)
② 화면에 뜬다  Count 몇 · 매물 몇 건 · 원문 일부
③ 「저장」    받은 원문을 그대로 서버로 POST
④ 서버       raw_response 에 넣고 S4 부터 이어서 돈다
```

## 지켜야 할 것

```
필수   ②를 건너뛰지 않는다.  사람이 보고 저장한다
필수   원문을 가공하지 않고 그대로 보낸다 (P3)
필수   origin='browser'   ('collector' · 'import' 와 구분)
필수   호출 간격을 브라우저에서도 지킨다 (interval_sec)
필수   407 · 403 이면 그대로 화면에 낸다.  삼키지 않는다
금지   서버가 이 응답을 다시 검증하려고 엔카를 부르는 것 — 막혀 있다
검산   V11-43 · V11-44
```

## JS 규격

```
필수   바닐라 JS · 한 파일 · CDN 도 npm 도 안 쓴다
필수   JS 가 꺼져도 조회·필터·정렬은 링크로 돈다
       JS 는 「브라우저만 할 수 있는 일」에만 쓴다
금지   JS 로 화면을 그리는 것.  HTML 은 서버가 만든다
근거   STEP 145b — 금지된 것은 빌드 도구이지 JS 자체가 아니다 (개정 248)
```
