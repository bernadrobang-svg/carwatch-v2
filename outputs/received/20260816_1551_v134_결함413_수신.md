# 2. 모순 세 가지

## ① 413 이 날 수 없는 크기인데 났다

```
1쪽 = 20건 = 약 13KB
상한 = 65,536 바이트
```

**쪽 단위로 보냈다면 413 이 안 납니다.**

```
★ 쪽으로 나눈다고 해 놓고 실제로는 통째로 보냅니다
  개정 263 「JS 가 나눠 보낸다」가 구현되지 않았습니다
```

## ② 「391쪽 저장」이 숫자가 안 맞는다

```
예상        21쪽
8차종 × 21 = 168쪽
표시        391쪽
```

**어느 쪽으로도 391 이 안 나옵니다. 세는 기준이 틀렸습니다.**

## ③ 「끝났습니다」인데 전부 실패다

```
전체 16/16묶음 · 저장 391쪽
끝났습니다.
실패 — 8차종 전부 413
```

**「끝났습니다」와 「전부 실패」가 같은 화면에 있습니다.**

```
★ V11-33 정신 위반 — 저장이 안 됐는데 성공처럼 보입니다
  「16/16묶음」·「저장 391쪽」이 먼저 보이고
  실패는 그 아래 한 줄로 나옵니다
필수   하나도 저장 안 됐으면 그것이 머리말이어야 합니다
```
