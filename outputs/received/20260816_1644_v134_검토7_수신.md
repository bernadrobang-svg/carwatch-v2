# 2. ★ `V3-37` 오탐 — 제 검사 설계 잘못입니다 · 개정 269

```
V3-37   목록 관측분의 source 가 'list' 인가
실제    사람이 확정한 것도 source='list' 이고 status='confirmed' 다
검사가  「list 인데 confirmed = 자동 확정했다」로 잡았다
```

**★ 제가 「출처」와 「확정 방법」을 한 필드로 보게 규격을 썼습니다.**

## 정정

```
source_endpoint   어디서 왔나 (facet · list)
status            지금 무엇인가 (pending · confirmed · retired)
★ 둘은 서로 독립이다

source='list' · status='pending'     목록에서 관측만 함
source='list' · status='confirmed'   ★ 사람이 확정한 것.  정상이다
source='facet' · status='pending'    facet 에서 왔지만 미검토
```

```
필수   V3-37 은 「자동 확정을 했는가」를 본다.  source 만 보고 판정하지 않는다
필수   사람이 확정했는지는 config_change 이력으로 가른다
금지   source 로 「사람이 했는지」를 추정하는 것
```

**개발측이 이미 `config_change` 이력으로 가르게 고쳤습니다. 그 방법이 맞습니다.**
