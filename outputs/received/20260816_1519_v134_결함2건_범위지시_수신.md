# ★ 신규 — 범위: 차종별 · 전 차종 (개정 264)

**마스터 지시 — 차종을 하나씩 고르는 것은 도구가 할 일입니다.**

## 화면

```
범위
  □ 차종 하나        KOLEOS_HEV
  □ 여러 차종        고른 것만
  ● 전 차종          targets.json 의 status='active' 전부
```

## 규격

```
필수   전 차종은 「높음」이다 (STEP 149l)
       예상 쪽수 · 예상 시간 · 예상 건수를 먼저 낸다
       확인 문구를 받는다 — 「all 을 입력하십시오」
필수   차종마다 목록과 facet 을 함께 받는다
       facet 이 없으면 그 차종 사전이 안 채워진다 (V4-25)
필수   한 차종이 실패해도 나머지를 이어서 한다
       실패한 차종을 화면에 남기고 그것만 다시 할 수 있게
필수   진행을 차종 단위로 — 「KOLEOS_HEV 4/8쪽 · 전체 3/12차종」
필수   중단할 수 있다.  중단하면 어디까지 됐는지 남긴다
금지   전 차종을 확인 없이 시작하는 것
금지   한 차종이 실패했다고 전체를 멈추는 것
검산   V11-48 · V11-49
```

## 실측 규모 (차종 12 · 매물 200 가정)

```
목록   2,400건 = 120쪽 × 20건 · 약 7MB
시간   간격 0.3초 → 약 1분 · 1.0초 → 약 2분
```

```
★ 브라우저는 목록·facet 만 받는다.  상세(S5)는 서버가 받는다
  상세 약 7,500 호출은 별개다 — /admin/run 이 한다
```
