# 3. `STEP 136e` — `/admin/dict` 신설

## 화면

```
① 확정 대기 목록
   축 · 값 · 몇 건에서 나왔나 · 출처(facet · list) · 처음 본 시각
   ★ 'list' 출처는 따로 표시 — 전체 집합을 본 게 아니다

② 값마다
   확정 · 보류 · 폐기(retired)

③ 묶어서 확정
   축 하나를 통째로 — 41종을 하나씩 누르지 않는다
   ★ 다만 몇 건인지 먼저 낸다

④ 확정하면 무엇이 달라지는지
   「이 값을 확정하면 매물 N건이 판정 가능해집니다」
```

## 규칙

```
필수   사유를 받는다 (STEP 149k)
필수   미리보기 없이 확정 불가
필수   'list' 출처를 그렇게 표시
       「facet 없이 목록에서 관측한 것입니다.  전체 집합이 아닙니다」
필수   facet 을 나중에 받으면 대조 결과를 이 화면에 (V3-38)
       facet 에 없는데 목록에 있던 값을 ★ 로
필수   폐기한 값이 다시 관측되면 알린다
       「사이트가 바뀌었을 수 있습니다」
금지   확정을 자동으로 하는 것
금지   pending 인 채로 판정에 쓰는 것
검산   V10-24 · V10-25
```

```
★ 왜 자동으로 안 하는가
  사전은 「같은 값을 같은 것으로 인정하는 규칙」이다
  기계가 정하면 「흰색」과 「화이트」를 다른 것으로 두거나
  「진주색」을 흰색에 넣어 버린다
  그 판단은 사람이 한다.  그래서 pending 이 있는 것이다
```
