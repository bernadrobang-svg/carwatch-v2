# 1. ★★★ 지금 수집된 것으로 순위·등급을 다시 매긴다

## 1-2. 표시 차단 — ★ 하나뿐이다


## 1-3. 등급 상한 — ★ 버리지 않는다. 등급만 내린다

| 조건 | 상한 |
|---|:--:|
| 신차가 대비 75 ~ 78% | **C** |
| 신차가 대비 50 ~ 75% | 없음 |
| 신차가 대비 50% 미만 | 없음 + ★ 「왜 이렇게 싼가」 표시 |
| 예산 이하 | 없음 |
| 예산 초과 ~ **+500만** | **B** |
| 예산 **+500만 초과** | **C** |
| 신차가 **미확인** (556건) | 없음 + 「신차가 미확인」 표시 · ★ 조용히 빼지 마라 |

```
★ 「제외」(리스·침수·골격 관문 배제)는 그대로다.  ★ 가격 규칙과 섞지 마라
```
