## 6. ★ 만들다 나온 결함 셋 — 전부 제 것

### ① 카드 CSS 가 관리 화면 열아홉까지 걸려 있었다

`class="rows"` 를 쓰는 표가 **열아홉 개**다 (관리 화면 대부분).
어제 넣은 부록 G 카드 규칙이 `.rows` 에 걸려 있어 **좁은 폭에서
관리 화면의 이름표까지 지우고** 있었다.

```
고침   app.css 의 부록 G 블록 51곳을 .car-rows 로 좁혔다
      listings.html  class="rows" → class="rows car-rows"
      추천은 이미 .cand-rows 였다
      V11-109 의 대상도 car-rows 로 바꿨다
```

★ 스크린샷 두 장(목록·추천)만 보고 「됐다」 한 것이 이 사고의 원인이다.

### ② 검사가 자기 주석에 걸려 넘어갔다

`V11-109` 를 만들 때 CSS 주석 안에 예시로 `{ span 6 }` 를 적었더니
**중괄호가 규칙 쪼개기를 깨뜨려 축 규칙 넷이 통째로 사라졌다.**
검사가 「통과」로 나왔다 — 실제로는 아무것도 안 보고 있었다.

```
고침   주석을 먼저 뗀 뒤 규칙을 쪼갠다
확인   버그 셋을 되살려 전부 잡는 것을 확인했다 (어제 기록 8절)
```

### ③ 어림값이 결함을 감췄다

`GRID_COLS_DEFAULT = 12` 를 두었더니 CSS 에서 격자를 못 읽어도
조용히 12 로 넘어갔다.  기본값을 없애고 「없으면 그것이 결함」으로 바꿨다.
그러자 진짜 결함이 나왔다 — 격자 선언은 1099 블록에 있는데
639 블록만 보고 있었다.

★ **어림값을 두면 「못 봤다」가 「봤는데 괜찮다」로 둔갑한다.**
