# 4. ★ 판정과 다음 할 일

## 4-1. K카 — 상세가 robots 금지인 것을 어떻게 볼 것인가

```
사실   목록은 허용 · ★ 상세는 금지
뜻     우리가 필요한 값(성능점검·사고이력·보증)이 ★ 전부 상세에 있다
★ 이것은 ★ 기술 문제가 아니라 ★ 마스터가 정하실 문제다 — 가이드가 임의로 정하지 않는다
```

## 4-2. 지금 확실한 것 · 아직 모르는 것

```
확실  · KB차차차 robots 는 열려 있다
      · K카 상세는 robots 로 막혀 있다
      · 헤이딜러는 매물 사이트가 아니다
      · K카 API 서버(api.kcar.com)가 실재한다
      · 두 사이트 다 ★ 목록이 HTML 에 없다 — ★ XHR 이다 (마스터 물음 「스크롤 여부」의 답)

모름  · K카·KB차차차의 ★ 목록 XHR 정확한 경로·헤더·본문
      · 두 사이트 상세가 어떤 항목을 주는지 (항목 대조표는 다음 단계다)
      · KB차차차 호출 간격 (503 을 한 번 받았다)
```
