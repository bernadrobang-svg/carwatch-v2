## 2. ★★★ 답 — 「항목별 점검 리포트」는 **로그인이 필요합니다**

마스터가 보시는 **틴팅 · 차량 키 수량 · 소화기 · 리페어 장비 · 제조사 매뉴얼**은
번들 안에 항목표로 그대로 있습니다.

```js
ID = {
  성능점검기록부 : {category:"etc",   id:235},
  기타정비내역   : {category:"etc",   id:239},
  "차량 키 수량" : {category:"basic", id:10},
  "제조사 매뉴얼" : {category:"basic", id:11},
  "틴팅 (정면 유리)": {category:"basic", id:16},
  "리페어 장비"  : {category:"exterior", id:186},
  소화기        : {category:"exterior", id:189},
}
탭   기본정보 BASIC · 등화장치 · 실내 INTERIOR · 외관 EXTERIOR · 휠타이어 STATE · 옵션
```

**그것을 주는 API 는 이것입니다.**

```
/v2/verification/{id}/unified-report/free
/v2/verification/{id}/unified-report/lite
/v2/verification/{id}/unified-report/paid
/v2/verification/{id}/report-analysis/performance-inspection
/v2/verification/{id}/report-analysis/options
/v2/verification/{id}/report-analysis/insurance-history
```

### 서버에서 불러 봤습니다 — **401 Unauthorized**

```
401  {"status":401,"error":"Unauthorized",
      "path":"/v2/verification/38016911/unified-report/free"}

```

마스터가 엔카에 로그인한 채 그 화면에서 수집을 누르면 세션 쿠키가 함께 갑니다.

## 3. ★ 그 밖에 새로 찾은 것 — **서버에서 바로 됩니다 (200)**

우리가 지금 부르는 6종 말고, 인증 없이 열리는 것이 넷 더 있습니다.

| 엔드포인트 | 상태 | 주는 것 |
|---|:--:|---|
| `/v1/readside/inspection/vehicle/{id}/summary` | **200** | 외판 요약 · **점검자 이름** |
| `/v1/readside/record/vehicle/{id}/summary` | **200** | 보험이력 요약 — 차량번호 · **용도(use)** · 연료 · 최초등록 |
| `/v1/readside/clean-encar/vehicle/{id}` | **200** | `cleaned: true` — **엔카 클린 판정** |
| `/v1/readside/diagnosis/vehicle/{id}/sellingpoint` | **200** | 판매 포인트 (「깔끔한 실내관리」 등) |
| `/v1/readside/vehicle/ev-battery/{id}` | 200 | 전기차 배터리 (지금은 전부 null) |
| `/v1/readside/extend-warrant/vehicle/{id}` | 404 | 이 매물엔 없음 — 엔카보증 후보 |

**`record/summary` 의 `use` 가 개정 296 §4 「용도 변경 — 렌트가 여기 있다」입니다.**

## 5. ★ 시세 막대는 아직 못 찾았습니다

```
「157호6282 차량은 시세대비 가격이 적정해요 · 3,831만 ── ● ── 4,056만」
```

번들 47경로에 시세·가격 관련 경로가 없습니다. 셋 중 하나입니다.

```
㉮ 서버 렌더로 HTML 에 박혀 온다
㉯ 다른 번들(지연 로딩)에 있다
㉰ 로그인 리포트 안에 함께 온다
```

**마스터가 그 화면에서 개발자도구 → 네트워크를 한 번만 보여 주시면 확정됩니다.**
`unified-report` 를 받으면 ㉰ 인지 바로 압니다.

## 9. 못 한 것 · 판단이 필요한 것

### ① 새 엔드포인트 4종을 수집에 넣을까요

```
inspection/summary · record/summary · clean-encar · sellingpoint
★ 인증이 필요 없어 서버가 바로 받습니다
★ 다만 3,470건 × 4 = 13,880 요청이 늘어납니다
```

**`record/summary` 의 `use`(용도)는 렌트 판정에 바로 쓰이므로 값어치가 큽니다.**
넷 다 받을지, `record/summary` 만 받을지 지시를 부탁합니다.

### ② `/v2/verification/*` 은 브라우저 수집으로 — 화면을 만들까요

`/admin/collect` 에 이 엔드포인트를 넣으면 마스터가 **엔카에 로그인한 채**
수집을 눌러 받을 수 있습니다. 다만 **로그인 세션을 쓰는 것이므로
엔카 이용약관을 마스터가 확인하셔야 합니다.** 지시를 기다립니다.

### ③ 시세 막대는 마스터 화면의 네트워크 탭이 필요합니다

번들에 경로가 없습니다. **한 번만 보여 주시면 확정합니다.**
