## 2 ★ 먼저 쟀다 — 규격의 전제와 둘이 다르다

### ① `body.s-… :root` 23곳은 **죽은 규칙**이었다

```
body.s-admin-api :root { --bg:#0e1013; … }   ← 23곳 · 내용은 다 똑같다
```

★ `:root` 는 `<html>` 입니다. `<html>` 은 `<body>` 의 **자손이 될 수 없습니다.**
그러므로 이 23곳은 **한 번도 맞은 적이 없습니다.** 지웠고, 지워도 화면이 안 바뀝니다.

★ 다만 그 안의 `--mono`·`--sans` 값이 진짜 `:root` 와 달랐습니다
(`'JetBrains Mono'` · `BlinkMacSystemFont`). **한 번도 안 먹은 값**이라 버렸습니다 —
정말 쓰고 싶으셨던 것이면 말씀해 주십시오.

### ② 「색은 `:root` 한 곳에만 있다」가 아니었다

```
:root 밖의 리터럴 색 — hex 122회 · rgba 30회 = ★ 152곳
```

규격은 「색은 app.css 맨 위 `:root` 한 곳에만 있다 — 39곳을 안 손대도 된다」고
적었지만 실제로는 그렇지 않았습니다. 값만 바꿨으면 **머리띠가 검게 남고
「CarWatch」가 안 보이는** 화면이 됐을 것입니다 (실제로 한 번 그렇게 났고, 사진으로 봤습니다).

★ 그런데 **122회가 전부 이미 있는 토큰과 같은 값**이었습니다.
그래서 `var()` 로 바꿨습니다 — **화면이 한 픽셀도 안 바뀌는 것을 사진 해시로 확인**한 뒤에.
