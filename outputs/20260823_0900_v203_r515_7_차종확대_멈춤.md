## 407 응답 머리 — ★ CloudFront 가 낸 것이다

```
HTTP/2 407
content-length: 0
x-cache: ★ Error from cloudfront
via: 1.1 …cloudfront.net (CloudFront)
```

```
★ 「Proxy Authentication Required」를 ★ 엔카 서버가 아니라 ★ CDN 이 낸다
★ 본문이 0B 다 — 사유를 안 준다
★ 경로로 가른다 — /search/* 만 막고 /v1/readside/* 는 연다
   → ★ IP 차단이 아니다.  ★ 그 경로만 막은 것이다
```
