## ★★★ 회차 중에 내가 만든 결함을 잡았다 — 두 개

### ① 재판정이 **옛 코드로 돌았다** — 「0건」이 거짓이었다

끌어오기를 넣고 재판정을 돌렸더니 **0건**이 나왔습니다. 논리는 맞았습니다 —
직접 태워 보니 133건이 붙었습니다.

★ 까닭 — **소비기(`collect/worker.py`)는 웹 서버 프로세스 안의 스레드**입니다.
`analyze/`·`collect/runner.py`·`contracts.py` 를 고쳐도 **이미 떠 있는 carwatch 가
옛 코드를 메모리에 들고 있습니다.**

```
재시작 전 재판정 → 끌어온 신차가 ★ 0건
재시작 후 재판정 → 끌어온 신차가 ★ 132건 · origin_price_missing 459 → 327
```

★ 이것을 모르면 「고쳤습니다」가 거짓이 됩니다. **판정에 걸리는 코드를 고쳤으면
재판정을 넣기 전에 `sudo systemctl restart carwatch` 를 먼저 합니다.**

### ② ★ 내가 넣은 현대 신차가가 **절약액**이었다

아홉 사이트 1등 매물(10217 · 그랜저)을 뜯어 보니 —

```
값 25,900,000 · 신차가 ★ 9,100,000  → 값/신차가 = 284.6%
→ value.origin 75점이 ★ 0점
```

★ 그랜저 신차가가 910만원일 수 없습니다. 원문을 보니 —

```
「304루9851은 ★ 신차 가격 대비 9,100,000 원 절약 할 수 있어요」   ← ★ 내가 잡은 것
「2023 더 뉴 그랜저 (IG) LPG 3.0 프리미엄 ★ 신차가 35,000,000 원」  ← ★ 진짜
```

제 정규식이 「신차 가격」 뒤 12자 안의 첫 수를 잡아 **절약액**을 넣었습니다.
「대비」가 붙은 것을 빼고 「신차가 {값} 원」만 잡게 고쳤습니다.

| | 고치기 전 | 고친 뒤 |
|---|--:|--:|
| 현대인증 신차가 값 범위 | **9,100,000 부터** | **34,100,000 ~ 88,750,000** |
| 신차가 < 현재값 (있을 수 없는 것) | ? | ★ **0건** |

★ 앞 회차에 「197건을 채웠다」고 보고드린 것은 **수는 맞지만 값이 틀렸습니다.**
정정합니다.

★ 참고 — 다른 사이트에도 같은 무늬가 남아 있습니다 (신차가 < 현재값) —
