## 2. 무엇을 했나

### ① 축 기호 — `O · - · ?` (지시 1)

```
config/labels.json  VALUE_MARKS
전   {"1":"O", "0":"·", "-1":"·", "na":"·", "unknown":"?"}
후   {"1":"O", "0":"-", "-1":"-", "na":"-", "unknown":"?"}
```

렌더 결과 실측 — `outputs/render/listings.html` 에 **`O` 61개 · `-` 9개**.

**가이드가 「0」으로 읽은 것은 대문자 O 였다.** 점(`·`)이 「없음」이라 눈에 안 띄던 것도
`-` 로 바뀌어 셋이 확실히 갈린다.

`test_spec_ui A-4` 가 옛 기호를 코드에 박고 있어서 함께 고쳤다 —
**시험이 config 를 읽는다.** 기호를 또 바꿔도 시험을 안 고친다.

### ② 시세 히스토그램 (지시 2)

```
전   <table> 구간 · 건수 · 중앙
후   <div class="hist"> 막대 8개 + <div class="histx"> 눈금
     숫자 표는 <details> 로 접어 남겼다 — 값을 버리지 않는다
```

막대는 **`<a>` 다.** 시안은 `<div>` 에 JS 로 걸었지만 우리는 **JS 없이 링크**로 했다
(개정 248). 누르면 그 가격대 매물로 간다. 높이는 `Bucket.height_pct` 로
**report 계층이 계산해 내려준다** — 화면이 최대값을 찾지 않는다.

## 6. 가이드 물음에 대한 답 (검토 14 §4)

### ① 사진 자리가 빈 회색 상자

**`thumb-none` 이 아니다.** `<img class="thumb">` 는 있는데 headless 브라우저가
`ci.encar.com` 을 못 받아 빈 칸으로 보인 것이다. 렌더 HTML 에는 주소가 있다.

```
outputs/render/listings.html   class="thumb" 10개 · thumb-none 0개
사진 원문 보유                  3,440 / 3,470건 (99%)
```

**마스터 브라우저에서는 뜬다** — HTTPS 로 바꾼 뒤 혼합 콘텐츠도 0이다.
다만 **스크린샷에서는 계속 빈 칸으로 보인다.** 서버가 바깥으로 이미지를 받는 것은
느리고 필요도 없다 — 판단하실 때 참고해 주십시오.

### ② 시세차 · 변동 · 딜러 · 정직도 가 「—」

**값이 없는 것이지 계산이 안 된 것이 아니다.** 각각 이유가 다르다.

```
시세차   SPORTAGE_LPI 는 차종 보정계수 1.517 로 범위(0.8~1.2) 밖이다.
        판정에서 가격 축을 안 쓰므로 화면에도 안 낸다.
        ★ 시세차를 낼 수 있는 매물은 3,250 / 3,470건이다 —
          첫 두 건이 하필 그 차종이었다 (G80_25T 는 나온다: -1,337만)
변동     첫 게시가와 지금 값이 같다.  오늘 처음 본 매물이라 바뀐 적이 없다
딜러     원문에 상호가 없는 매물이다.  ★ 그래서 링크도 안 만든다 (V11-72)
정직도   core_dealer 719곳 전부 sample_sufficient = 0 이다.
        딜러 집계(S11)가 표본 부족으로 아무것도 못 냈다 — 0 으로 내지 않는다
```

**전부 툴팁에 이유를 적어 두었다.**

### ③ 「선루프 ·」 는 무엇인가

`-` 로 바뀌었고 **「없음」이다.** 「모름」은 `?` 다.
