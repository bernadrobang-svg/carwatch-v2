## 3. ★★ ② 거르개 차례 — ★ 시안을 열어 재서 옮겼다

### 3-1. 시안의 실제 차례 (재서 적었다)

```
매물(제목) · 건수 → ★ 이 화면은 무엇을 하는 곳인가
→ 차종 — 전체 → 트림 — 전체 → 등급 — 전체
→ 추천 순위 · 가격 낮은순 · 등급순  (정렬)
→ 자세한 조건 (2) ▾ → 고른 칩(2,500~3,500만 · S·A · 사고 OK · 지우기) → 카드
```

★★ **시안에는 「가격대」가 기본 칩에 없다.**
★ 고른 뒤 「2,500~3,500만」 칩으로만 보인다 — 곧 **「자세한 조건」 안**이다.

★ 마스터께서 말씀하신 차례(「이 화면은 → 등급 → 차종 → 트림 → 가격 → 자세한 조건 → 정렬」)와
★ **시안 파일이 조금 다르다.** ★ 「③ 시안 파일을 열어 그 차례대로」라 하셔서 **시안을 따랐다.**
★ 다른 자리는 ★ 등급이 차종·트림 뒤라는 것과 ★ 정렬이 자세한 조건 앞이라는 것이다.
★ **어느 쪽이 정본인지 알려 주시면 그대로 바꾼다.**

### 3-2. 1차 결과 (고치기 전)

```
화면  차종 → 트림 → ★ 가격대 → 등급 → 정렬 → 자세한 조건
시안  차종 → 트림 →        등급 → 정렬 → 자세한 조건 → (가격은 그 안)
```

### 3-3. 고친 곳

| 파일 | 무엇 |
|---|---|
| `web/templates/listings.html` | 「가격대」 칩을 기본에서 빼고 **「자세한 조건」 맨 앞**으로 옮겼다 |
| `web/views.py` | `ORDER_MENU` 차례를 시안대로 — **추천 순위 → 가격 낮은순 → 등급순** |

★ 정렬도 어긋나 있었다 — 화면은 `추천 순위 → 등급순 → 가격 낮은순` 이었다.

### 3-4. 조치 후 (배포 실측)

```
매물 → 5,242건 중 30건 · 175쪽 중 1쪽
→ ★ 이 화면은 무엇을 하는 곳인가
→ 차종 → 트림 → 등급 → 정렬(추천 순위 · 가격 낮은순 · 등급순)
→ 자세한 조건 → 가격대
```

★ **시안과 같다.**

### 4-1. 재는 법 — ★ 낱말이 아니라 **차례**다

```
① 양쪽의 보이는 글을 ★ 차례대로 늘어놓는다
② 고정 메뉴(탭·nav)는 뺀다 — ★ 소스에서는 위 · 화면에서는 아래다 (position:fixed)
③ ★ 양쪽에서 **한 번만** 나오는 낱말로만 견준다
④ 숫자가 절반을 넘는 줄은 뺀다 — ★ 「2,990만」은 자리가 아니라 **보기 값**이다
⑤ 처음 어긋난 자리를 그대로 낸다
```

★ ③④ 는 **검사가 거짓 실패를 내서** 넣은 것이다 (아래 4-3).
