|--:|---|

### 원인 셋

**① 카드 전환 폭이 규격과 달랐습니다**

```
규격   넓음 ≥1100 표 · 중간 640~1099 표 2줄 · 좁음 <640 카드
코드   @media (max-width:1099px) 에서 표를 카드로 바꿨다
      → 640~1099 가 통째로 카드가 됐다.  규격은 표다
```

**② 넓음 경계 1100 이 물리적으로 불가능했습니다**

부록 G 목록 22열의 **폭 합이 1,710px** 입니다 (표에서 계산).

```

       config/web.json  list_wide_min_px
★ 규격의 1100 과 어긋납니다 — 6절에 보고합니다
```

**③ `grid-area:1 / 13 / 3 / 13` 이 13번째 칸을 만들었습니다**

제가 쓴 중간 폭 규칙입니다.  칸 폭이 0 이라 브라우저가 **암시적 13번째
칸**을 만들었고, 그 칸이 「근거 엔카에서 보기 ↗」의 nowrap 폭(약 140px)을

## 6. ★ 만들다 낸 결함 넷 — 전부 제 것

| # | 무엇 | 잡은 것 |
|---|---|---|
| ① | 격자 칸 수를 블록 아무 데서나 `repeat(` 로 읽었다 | `.tiles { repeat(2,1fr) }` 를 읽어 **cols=2** — 「칸이 안 들어간다」가 무더기로 났다. `tr` 규칙에서만 읽게 고쳤다 |

| ④ | V11-71 이 옛 경계(1099)를 봤다 | 카드 변환 블록이 1749 로 넓어지자 「카드로 안 바뀐다」로 헛짚었다 |
