### ② 팝업 — ★ JS 없이 닫힙니다

```
/reports?open={이름}   →  팝업이 열린 목록
[닫기] → /reports       →  ★ 링크다.  JS 가 아니다
```

규격이 「details 또는 별도 경로」라 했습니다.  **별도 경로**를 썼습니다 —
`details` 는 목록이 길어지면 어디가 열렸는지 안 보입니다.

```
형식별로 다르게 냅니다
  md    <pre> 그대로 (max-height:60vh · 스크롤)
  json  <pre> 그대로
  csv   ★ 표로.  첫 줄이 머리말이다
```

### ③ 다운로드 — ★ 누를 때만

```
/reports/{name}   →  Content-Disposition: attachment; filename="…"
                     Content-Type: text/markdown; charset=utf-8
```

```
★ 열자마자 받지 않습니다.  팝업 안의 [이 파일 내려받기] 를 눌러야 받습니다
★ 목록에 있는 것만 줍니다 — 임의 경로를 받으면 파일이 새 나갑니다
```

### ④ 큰 파일 — config 상한

```
config/web.json   report_preview_bytes = 200000
넘으면   「★ 파일이 커서 앞부분만 냈습니다.  전체는 내려받으십시오」
★ csv 는 잘린 마지막 줄을 버립니다 — 반쪽 행을 표로 내면 칸이 밀립니다
```

### ⑤ `V11-122`

```
① /reports · /reports/{name} 이 라우팅에 있는가
② ★ 형식마다 하나씩 실제로 연다 — md 만 되고 csv 가 깨지는 것을 잡는다
③ 팝업에 내용이 실렸는가 — 이름만 있고 본문이 없으면 못 읽는 것이다
④ 팝업에 다운로드 단추가 있는가
⑤ 내려받기가 첨부로 나가는가
⑥ ★ 목록에 없는 이름(../config/secrets.json)을 거절하는가
```
