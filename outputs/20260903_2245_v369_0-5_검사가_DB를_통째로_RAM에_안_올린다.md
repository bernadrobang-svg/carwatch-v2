## 3. 왜 그렇게 했나

`conn.backup(probe)` 는 **DB 전체**를 사본으로 옮긴다.  받는 쪽이 `:memory:` 면
그 사본이 통째로 RAM 에 앉는다.  지금 DB 는 **1.08 GiB** 고 장비 RAM 은 **1,841 MB** 다.

`conn.backup` 을 쓰는 까닭은 없앨 수 없다 — 파일을 복사하면 **아직 커밋 안 된 스키마가
사본에 안 따라온다** (실측 08-15 · `v10_admin.py:671` 주석).  그래서 받는 쪽만
**디스크 임시 파일**로 바꿨다.  이 본은 저장소에 이미 있었다 —
`v10_admin.py:676`(`pii.db`) · `v11_web.py:5034`(`probe.db`) 가 그렇게 한다.

```
★ /tmp 에 두지 않았다 — 921MB tmpfs(RAM) 다.  거기 두면 같은 잘못이다
  받는 자리는 outputs/check-tmp (디스크 · 15G 남았다) · atexit 로 지운다
```
