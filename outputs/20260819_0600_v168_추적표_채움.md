### ① — 「마스터께 여쭐 것」은 요구가 아닙니다

표 머리말로 가렸더니 하나를 놓쳤습니다 (`| R | 무엇 | 왜 여쭙나 |`).
**머리글(`# ★ 마스터께 여쭐 것`)로 가르게 고쳤습니다.**
질문 넷이 요구 행으로 넓혀져 원문이 뭉개져 있었습니다 — **되돌렸습니다.**

### ② — 상태는 ○·◐·✗ 만 다시 매깁니다

```
전   「!」 「?」만 빼고 다시 매겼다  →  D-500b · 「◐ 오늘」이 지워졌다
후   ○ · ◐ · ✗ · 빈 칸만 다시 매긴다.  나머지는 사람이 적은 것이다
```

### ③ — 있는 것을 없다고 하는 것이 더 나쁩니다

```
문턱 3개를 그대로 걸었더니 낱말이 둘뿐인 요구가 전부 미구현이 됐다
```

## 7. 판단이 필요합니다

### ① 질문 16건은 안 채웠습니다

```
「★ 마스터께 여쭐 것」 표의 R 16건입니다
「R-891 전 요소를 ReportMeta 에서」 → ★ 근거가 약합니다.  쓰는 사람이 있습니까
```

요구가 아니라 **물음**이라 소스·화면·검사가 없습니다.
그래서 849/865 입니다.  **채워야 한다면 말씀해 주십시오.**

### ② 소스 칸은 **기계가 추정한 것**입니다

```
단정인 것   「미구현」 · 「화면 없음」 · 「검사 없음」 뿐입니다 —
           그것은 「기계가 못 찾았다」는 사실이고, 그것이 만들 목록입니다
추정인 것   나머지 소스 자리.  낱말이 겹치는 곳을 고른 것입니다
```

색인(`docs/trace/INDEX.md`)에 그렇게 적어 두었습니다.
**틀린 것을 짚어 주시면 그 규칙을 고치겠습니다.**

### ③ 상태를 S38 대로 다시 매겼습니다

```
소스 「미구현」  → ✗
화면 「화면 없음」 → ◐
검사 「검사 없음」 → ◐
넷이 다 차면    → ○
```

★ 그래서 ○ 가 538 → 243 으로 줄었습니다.  **기능이 사라진 것이 아니라
「검사가 없다」가 드러난 것입니다.**
