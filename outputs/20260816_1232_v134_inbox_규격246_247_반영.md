### ① ★ 새 `E-attach.md` 의 E-2 블록이 깨진 JSON 이다 — 규격 정정 필요

`docs/ref/E-attach.md` 의 **E-2 (`tests/fixtures/EXPECTED.json`)** 블록에 이렇게 들어왔다.

```
 "catalog.json": {,
 "diagnosis.json": "encarDiagnosis == 0 인 매물의 진단 결과. items 에 ... (STEP 21b)"
  "len": 9,
```

두 가지가 잘못됐다.

```
1  "catalog.json": {,     ← 여는 중괄호 뒤에 쉼표.  JSON 으로 읽히지 않는다
2  diagnosis.json 설명 문자열이 catalog.json 객체 "안"에 들어갔다
   실제 EXPECTED.json 에는 diagnosis.json 항목이 아예 없다
```

E-3(`NOTES.json`)에 넣으려던 문장이 E-2 에도 잘못 붙은 것으로 보인다.
**어떤 유효한 파일로도 이 블록과 일치시킬 수 없으므로 코드로 해소할 수 없다.**
규칙 2 에 따라 문서를 건드리지 않았다. → **E-2 블록을 원래대로 되돌리는 정정이 필요하다.**

되돌릴 정확한 원문은 다음 한 줄이다.

