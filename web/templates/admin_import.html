넣을 것

형식은 붙여넣은 내용을 보고 스스로 판별합니다. 고르지 않아도 됩니다.

  • ① 엔카 목록 응답 JSON 원문 — 원칙입니다. 원문이 그대로 남습니다
  • ② 매물 ID 목록 — 한 줄에 하나. 최소 입력이라 원문 없음으로 표시됩니다
  • ③ CSV — source_id,target_key,trim,year_month,mileage_km,price_won. ②와 같이 원문 없음입니다
  • ④ facet 원문 JSON — iNav.Nodes 가 있는 응답. color_ext·color_int·fuel 사전은 여기서만 나옵니다. 상세를 아무리 받아도 안 채워집니다. 받으면 S2 를 대신합니다 — 차종을 함께 골라야 합니다

파일이 커서 붙여넣을 수 없으면 파일로 올립니다. 본문 상한을 넘으면 잘린 채 저장되지 않고 413 으로 거부합니다.

어디에 넣는가

CSV 에 target_key 가 있으면 그 값이 먼저입니다. 차종이 없는 행은 out_of_scope 로 들어가 수집 대상이 되지 않습니다.
