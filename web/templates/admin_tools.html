여기에 없는 것

아래는 CLI 에서만 합니다. 버튼이 있으면 「일단 눌러보자」가 됩니다 — 원문을 확인한 뒤 손으로 치는 편이 안전합니다.

  • db reset DB 초기화 — 원문이 사라집니다
  • admin reset 비밀번호 재설정 — 잠겼을 때 씁니다
