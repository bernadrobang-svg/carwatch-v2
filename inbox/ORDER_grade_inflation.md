# ★★★ 등급 인플레 — 개정 287

**2026-08-16 · 마스터 지적**

```
「스포티지 LPI 만 S 등급인데 시세차 가격이 없어.
 즉 기준가격이 없으면 가격 점수가 맹통이 되는 것 아닌가」
```

---

# 1. 실측 — 지적이 정확합니다

```
SPORTAGE_LPI LPG 2.0 2WD · 2025-08 · 11,439km · 4,400만
시세차 「—」        ←  기준가가 없습니다
등급   S · 94.3% · 330.0/350.0
```

```
분모 350 = 만점 555 − 205
★ 그 205 안에 가격 축이 들어 있습니다
  「가격을 안 보고 매긴 등급」입니다
```

---

# 2. ★★ 왜 심각한가

```
350 중 330 = 94.3%  →  S
555 중 330 = 59.5%  →  D
```

```
★ 같은 차가 축이 빠질수록 좋은 등급을 받습니다
  「모르는 것이 많을수록 좋은 차」가 됩니다
★ 그리고 이 도구는 「값이 싼지 비싼지」를 보려고 만든 것입니다
  그 축이 빠졌는데 S 를 주면 목적을 정면으로 어깁니다
```

---

# 3. 규격 — 개정 287

```
필수   축마다 「없으면 등급을 매기지 않는다」를 정한다
       ★ 지금은 「분모에서 빼면 된다」로 일률 처리합니다.  그것이 틀렸습니다

필수   핵심 축(core)은 빠지면 NOT_RATED
       price.*         기준가가 없으면 값 판단이 불가능하다
       history.damage  사고 이력을 모르면 살 수 없다
       ★ 어느 축이 핵심인지는 config — score_core_axes

필수   보조 축(optional)은 빠지면 분모에서 뺀다
       spec.hud · spec.sunroof 같은 것

필수   화면에 사유를 낸다
       「기준가가 없어 등급을 매기지 않았습니다 — 표본 N건」
금지   핵심 축이 빠졌는데 등급을 내는 것
검산   V3-40  핵심 축이 excluded 인데 등급이 매겨진 건이 있는가
       ★ 있으면 fatal
```

# 4. ★ 그리고 — 기준가가 왜 없습니까

```
확인   ① 시세 중앙값을 낼 표본이 모자란가
        SPORTAGE_LPI 는 177건이 있습니다.  모자라지 않습니다
확인   ② 감가 곡선에 그 차종이 없는가
확인   ③ 2025-08 이라 연차 1년 미만이라 곡선 밖인가
        ★ 앞서 expected_unavailable 30건이 「감가 곡선 구간 밖」이었습니다
```

```
필수   무엇 때문인지 숫자로 확인하십시오
필수   신차 가까운 매물의 기준가를 어떻게 낼지 정하십시오
       ★ 1년 미만은 신차가 대비로 볼 수 있습니다
```
