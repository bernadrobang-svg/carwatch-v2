## 규격 — 원인별로 가릅니다

```
① 새 엔드포인트에서 온 새 필드     ← 받은 게 늘면 늡니다
② 같은 뜻인데 이름이 다른 것       ← ★ 자동으로 이을 수 있습니다
③ 값이 늘 비어 있는 것            ← ★ 안 쓰기로 정하면 됩니다
④ 정말 새로운 것                  ← 사람이 봐야 합니다
```

```
필수   ②  기존 필드와 값 분포가 같으면 「같은 것으로 보입니다」를 제안
필수   ③  전건 null 이면 「안 씀」으로 제안
필수   ④ 만 사람에게 남긴다
       「사람이 봐야 할 것 12개 · 나머지 337개는 제안이 있습니다」

필수   엔드포인트별로 낸다
       「record/summary 에서 온 새 필드 84개」
필수   ★ 각 필드가 몇 건에서 관측됐는지
       ★ 3,528건 전부에 있는 필드와 1건짜리는 급한 정도가 다릅니다
필수   자주 나온 순으로
금지   「349건 미분류」라고만 내는 것
검산   V4-26 · V4-27
```

```

  미분류가 판정을 막습니다 (V4-11)
```
