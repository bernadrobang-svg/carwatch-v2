# 4. 할 일 — 순서

## ① 조사 (코드 없이)

```
1  K카 주소 구조를 찾으십시오
   목록 화면 · 상세 화면 · 검색 조건
2  엔카에서 쓴 방법을 그대로 쓰십시오
   ★ 프런트엔드 번들에서 API 경로를 뽑는 것
   ★ 그게 브라우저를 여는 것보다 빨랐습니다
3  얻은 것을 docs/KCAR_API.md 로 남기십시오
   ★ ENCAR_API.md 와 같은 형식
```

## ② 확인할 것

```
필수   목록 API 가 있는가 · 인증이 필요한가
필수   상세에 무엇이 오는가
       엔카의 4종(상세·점검·이력·옵션)에 해당하는 것이 있는가
필수   차종을 어떻게 고르는가
       엔카는 q= 쿼리였습니다.  K카는 무엇입니까
필수   ★ 「우수등급」을 무엇으로 아는가
       개정 306 의 site_grade_rule 이 될 값입니다
필수   서버에서 부를 수 있는가 · 브라우저가 필요한가
       ★ 엔카는 /search/ 가 407 이었습니다.  K카는?
```

## ③ 어댑터

```
필수   adapters/kcar.py 를 만듭니다
필수   SiteAdapter Protocol 을 따릅니다
필수   엔카 어댑터를 고치지 않습니다
       ★ 사이트가 늘어도 기존 것이 안 바뀌어야 합니다
필수   sites.json 의 kcar 를 planned → active 로
검산   V9-*  (8장 크로스사이트 검사가 있으면 그것을 씁니다)
```

## ④ 한 차종만 먼저

```
필수   KOLEOS_HEV 또는 G80_25T 하나로 끝까지 돌립니다
       목록 → 상세 → 파싱 → 판정
필수   숫자를 내십시오
       매물 몇 건 · 채워진 축 몇 · 엔카와 겹치는 매물 몇
★ 되면 전 차종.  안 되면 왜인지
```
