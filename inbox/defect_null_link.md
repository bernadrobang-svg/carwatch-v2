# ★ 실전 결함 — `null` 로 이동한다

**2026-08-16 · 마스터 실측**

```
사이트에 접근할 수 없음
null 에 접근할 수 없습니다
```

**링크를 눌렀더니 주소가 `null` 이었습니다.**

---

# 1. 제가 소스에서 확인한 것

**템플릿은 대부분 막혀 있습니다.**

```html
{% if r.encar_url %}<a href="{{ r.encar_url }}" ...>{% endif %}
{% if paging.next %}<a href="{{ paging.next }}">다음 ›</a>{% endif %}
```

**그런데 실제로 `null` 이 나왔습니다. 어딘가 안 막힌 곳이 있습니다.**

---

# 2. ★ 찾아야 할 것

```
필수   전 템플릿에서 href · src 가 값을 그대로 쓰는 곳을 찾으십시오
       {% if %} 없이 {{ ... }} 만 쓴 곳
확인   b.url · c.filter_url · c.remove_url · p.url
       g.filter_url (recommend) · b.filter_url (market)
       photo_url · encar_url
```

---

# 3. ★ 규격으로 막으십시오

```
필수   주소가 될 값이 비었으면 링크를 만들지 않는다
       ★ 「빈 링크」가 아니라 「링크 아님」이다
필수   템플릿 엔진이 None 을 렌더할 때 빈 문자를 낸다
       ★ 지금 'null' 이나 'None' 이 찍히고 있을 수 있습니다
필수   src 도 같다.  이미지가 없으면 img 태그를 내지 않는다
검산   V11-72  렌더 결과에 href="" · href="null" · src="null" 이 없는가
```

**★ `V11-72` 를 만드십시오.** 전 화면을 렌더해 문자열로 검사하면 됩니다.
