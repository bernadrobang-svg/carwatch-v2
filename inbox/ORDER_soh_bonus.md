
# 3. 규격

```
필수   SOH 는 가점이다.  축이 아니다
       있으면 더한다 · 없으면 아무 일도 없다
필수   ★ 분모를 늘리지 않는다.  675 그대로
       비율 = (합계 + 가점 − 마이너스) / 625
       ★ 가점이 크면 100% 를 넘는다.  그대로 낸다
필수   화면에 따로 — 「배터리 SOH 94.4% (+24)」
필수   없으면 「배터리 진단 없음」
       ★ 0점이라 적지 않는다.  「확인 못 함」도 아니다
필수   92% 미만이면 「배터리가 닳았다」를 싼 이유로 (개정 296)
       ★ 다만 감점하지 않는다
금지   SOH 가 없다고 감점하는 것
검산   V3-58 · V3-59 · V3-72
```
