# ★★★ 개정 293 — v1 의 근본 한계

**마스터 통찰 — 「한 차종에 집착한 기준을 다른 차에 일관적으로 세워서 그런 듯」**

---

# 1. 정확한 진단입니다

```
v1 은 KOLEOS_HEV 하나만 수집했습니다
그 차를 보며 축을 만들었습니다
  HUD · HDA · 선루프   그 차에서 마스터가 보던 옵션
  엔진보증             내연기관·하이브리드 전제
  틴팅                 그 차 점검부에서 봤던 항목
→ 「한 차를 잘 보는 기준」이 되었습니다
→ 그것을 8차종에 그대로 폈습니다
```

```
그래서 지금
  MODEL_Y (전기)      엔진보증 0점 — 엔진이 없습니다
  G80 (고급)          HUD 가 기본 장착이라 변별력이 없습니다
  SPORTAGE (신차급)   기준가가 없습니다 — 감가 곡선 밖입니다
```

**★ 축이 차종을 못 가립니다.**

---

# 2. 규격

```
필수   축은 「모든 차가 가질 수 있는 것」으로 정의한다
       엔진보증  →  동력계 보증 (엔진 · 모터 · 배터리)
       ★ 전기차도 보증이 있습니다.  오히려 더 깁니다 (8년 16만km)

필수   축을 전 차종에 펴기 전에 결측률을 본다
       ★ 한 차종에서 90% 채워지는데 다른 차종에서 0% 면
         그 축은 그 차종 전용이거나 이름이 잘못된 것입니다

필수   변별력도 본다
       ★ G80 은 HUD 가 기본이라 전건 「있음」입니다
         그러면 그 축이 G80 안에서는 아무것도 안 가릅니다

필수   기준가는 끊기지 않게 잇는다
       1년 미만    신차가 대비
       1~N년      감가 곡선 · 실제 중앙값

금지   한 차종에서 뽑은 축을 검증 없이 전 차종에 적용하는 것
검산   V3-47  축별 차종 간 결측률 편차가 상한 이내
       V3-48  축이 차종 안에서 변별력이 있는가
```

---

# 3. ★ 실측해 주십시오 — 이것이 답을 줍니다

```
표 하나면 됩니다.  축 × 차종
```

| 축 | KOLEOS_HEV | G80_25T | MODEL_Y | SPORTAGE_LPI | … |
|---|--:|--:|--:|--:|---|
| `spec.hud` | 채움률 % · 「있음」 비율 % | | | | |
| `warranty.engine` | | | | | |
| `price.market` | | | | | |
| … | | | | | |

```
필수   축마다 차종별로 두 숫자를 내십시오
       ① 채움률   그 축에 값이 있는 매물 비율
       ② 변별력   값이 갈리는가 (전건 동일이면 0)
필수   ① 이 차종 간에 크게 다른 축을 표시하십시오
필수   ② 가 0 인 (차종, 축) 쌍을 표시하십시오
```

```
★ 이 표 하나면 어느 축이 「한 차종 전용」인지 다 드러납니다
★ 그리고 배점을 어떻게 고칠지도 그 표가 알려 줍니다
```
