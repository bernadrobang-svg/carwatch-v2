# 3. ★ 알아내야 할 것

## ① `005,019,083` 이 무엇인가

```
추정   제조사 · 모델그룹 · 모델
확인   번들이나 검색 화면에서 코드표를 찾으십시오
       ★ 엔카에서 번들을 뒤진 방법 그대로
필수   차종을 늘리려면 이 코드를 알아야 합니다
```

## ② JSON 응답이 있는가

```
확인   /bc/search/CarList 가 HTML 만 주는지 · JSON 도 주는지
       ★ HTML 만 주면 파싱이 어렵습니다
확인   XHR 로 부르는 별도 API 가 있는지
       ★ 번들에서 /api/ · /json · .do 같은 것을 찾으십시오
```

## ③ 인증이 필요한가

```
확인   서버에서 부르면 200 인가 · 401 인가 · 403 인가
       ★ 엔카는 /search/ 가 407 이었습니다
       ★ K카도 막히면 브라우저 수집으로 갑니다
```

## ④ ★ 「우수등급」이 무엇인가

```
개정 306 — 「K카는 등록된 것 자체가 우수등급」
확인   화면에 그것이 어떻게 표시됩니까
      「K Car 인증」 · 「진단 완료」 같은 표시
확인   응답 어느 필드에 있습니까
필수   그것이 sites.json 의 site_grade_rule 이 됩니다
```

## ⑤ 상세에 무엇이 오는가

```
엔카의 4종에 해당하는 것
  상세 · 성능점검 · 보험이력 · 옵션
확인   K카는 몇 개로 나뉘어 있습니까
확인   ★ 같은 차를 가릴 값이 있습니까
      번호판 · 차대번호 · 제시번호
      ★ 없으면 크로스사이트가 안 됩니다
```
