# 1. ★ 트림이 누락됐습니다

```
마스터  「차종의 트림이 모두 누락되어 있다.  v1 에도 없더니」
```

```
★ v1 에 없다고 v2 에도 없어도 되는 것이 아닙니다
  v1 이 못 본 것이 v2 를 만드는 이유입니다
```

## 원문에 있는 것

```json
"Badge"       : "가솔린 2.5 터보 2WD"      ← 지금 씁니다
"BadgeDetail" : "(세부등급 없음)"           ← ★ 안 씁니다
```

```
필수   트림 = Badge + BadgeDetail
       ★ 같은 「2.5 터보 AWD」라도 세부등급이 다르면
         옵션이 다르고 신차가가 다릅니다
필수   「(세부등급 없음)」이면 그대로 냅니다
       ★ 빈 값으로 두면 「못 받았다」와 구분이 안 됩니다
필수   시세를 트림 단위로 냅니다
       ★ G80_25T 1,713건을 한 시세로 묶으면 뜻이 없습니다
필수   화면에 트림 목록 — 세부등급까지 · 건수 · 중앙값 · 신차가
필수   트림을 누르면 그 트림만.  분포도 바뀝니다
검산   V11-85 · V11-86
```

**★ 확인해 주십시오.**

```
BadgeDetail 이 core_listing 에 저장돼 있습니까
없으면 원문에서 다시 뽑으십시오 — S6 재파싱이면 됩니다 (재수집 불필요)
3,470건에 세부등급이 몇 종 있는지 세십시오
```

# 2. ★ 신차가에 무엇이 들어 있나

```
마스터  「신차가는 트림과 옵션가가 포함된 거잖아」
```

```
필수   originPrice 가 무엇을 담는지 실측으로 확인합니다
       ① 트림 기본가만인가
       ② 옵션가가 포함됐나
       ③ 매물마다 다른가
          ★ 같은 트림·같은 연식인데 originPrice 가 다르면 옵션 포함입니다
```

```
필수   확인 결과를 화면에 밝힙니다
       「신차가 5,470만 — 트림 기본가」  또는
       「신차가 5,470만 — 선택 옵션 포함」
필수   옵션이 포함됐으면 어떤 옵션인지 볼 수 있게
       ★ options.choice 에 그 차의 옵션이 있습니다
금지   무엇인지 모른 채 「신차가」라고만 내는 것
검산   V11-87
```

```
★ 왜 중요한가
  「신차가 5,470만 · 지금 2,990만」이면 45% 떨어진 것입니다
  그런데 신차가가 옵션 포함이고 이 차에 그 옵션이 없다면
  실제 감가는 그보다 작습니다
```

# 3. 실측으로 답해 주십시오

```
1  BadgeDetail 이 저장돼 있는가 · 몇 종인가
2  같은 트림·연식에서 originPrice 가 같은가 다른가
   ★ 다르면 옵션 포함입니다.  숫자로 보여 주십시오
   예   G80_25T 가솔린 2.5 터보 AWD 2023년
        originPrice 값 목록과 각각 몇 건
3  그 차이가 options.choice 의 옵션가 합과 맞는가
```

**★ 3번까지 맞으면 「옵션 포함」이 확정됩니다.**
