## ★ 마스터 지적 셋을 반영했습니다

```
「옵션을 신차가격에 반영 안 함」
  → 신차가 = 등급기준 + 선택옵션가 합 (개정 301)
  → 「신차가 대비 80」이 그 신차가를 씁니다
  → ★ 옵션 많은 차가 자동으로 반영됩니다

「신차가 대비 얼마나 싼지 없음」
  → ② 신차가 대비 80점 신설
  → 화면  「신차가 5,273만 → 지금 2,670만 · 49.4% 내렸습니다
           같은 연차 평균은 43% — 6.4%p 더 내렸습니다」

「시세보다 낮은지 높은지 없음」
  → ① 시세 대비 100점
  → 화면  「시세 3,070만 · 이 매물 2,670만 · 13.0% 쌉니다」
```
