# 2. ★ 시세 차종을 제조사·차종·트림으로 고른다

```
지금   /market?target=MODEL_Y  링크만 있습니다
       등록된 11종 중에서만 고릅니다
```

```
마스터 「제조사 차종 트림으로 선택하게 해야지」
```

## 규격

```
필수   시세 화면에 고르는 칸을 둡니다
       제조사 → 차종(모델군) → 트림 → 연식
       ★ 단계마다 앞에서 고른 것에 맞게 좁혀집니다
필수   원문에서 뽑아 채웁니다
       ★ 우리 DB 에 3,470건이 있습니다.  거기서 실제 값을 뽑습니다
       raw_facet 이 있으면 그것이 낫습니다 — 전체 집합이니까
필수   고를 때마다 몇 건인지 즉시 — 「이 조건에 1,223건」
필수   등록 차종이 아니어도 봅니다
       ★ 지금은 targets.json 에 있는 11종만 봅니다
         「이 차 시세가 얼마지」를 못 봅니다
필수   표본이 모자라면 그렇게 적습니다 — 「표본 4건 — 내지 않습니다」
근거   STEP 149r — 고르는 칸은 고를 수 있게 만든다
검산   V11-83  시세 화면에서 제조사·차종·트림을 고를 수 있는가
```

```
★ 왜 중요한가
  시세는 「이 차가 지금 얼마인가」를 보는 화면입니다
  등록 차종만 보면 「내가 지금 궁금한 차」를 못 봅니다
  ★ 그리고 트림별로 시세가 크게 다릅니다
    G80 2.5T 와 3.5T 를 한 시세로 묶으면 뜻이 없습니다
```
