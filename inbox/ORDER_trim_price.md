# ★★★ 트림 점수를 신차가로 — 개정 382

**마스터 지적 — 「그건 너다. 트림별 가격 차이를 고려 안 해서야.**
**트림의 신차 가격이 중요해. 그게 차량의 가격 차이야」**

**★ 맞습니다. 순위로 재면 가격 차이가 사라집니다.**

---

# 1. 무엇이 잘못이었나

```
전   score = (내 트림 순위 k ÷ 전체 트림 수 n) × 25

예   스탠다드 6,500 · 스포츠 7,200 · 스포츠플러스 7,800
     순위로   8.3 / 16.7 / 25
     ★ 700만 · 600만 차이가 사라집니다
     ★ 트림이 10종인 차종이면 한 칸이 2.5점 — 값과 무관해집니다
```

---

# 2. 고친 규격

```
입력   그 차종 트림별 등급기준가 (origin_price 에서 옵션을 뺀 값)
식     score = (내 트림 등급기준가 ÷ 그 차종 최고 트림 등급기준가) × 25
```

| 트림 | 등급기준가 | 비율 | 점수 |
|---|--:|--:|--:|
| 스탠다드 | 6,500만 | 0.833 | **20.8** |
| 스포츠 | 7,200만 | 0.923 | **23.1** |
| 스포츠플러스 | 7,800만 | 1.000 | **25.0** |

```
필수   신차가로 잰다.  순위로 재지 않는다
필수   최고 트림이 25.  나머지는 그에 대한 비율
필수   트림이 1종뿐이면 25
필수   화면에 — 「스탠다드 6,500만 / 최고 7,800만 (20.8/25)」
없으면  등급기준가를 못 내면 0점 · 확인 안 됨
검산   V3-75
```

---

# 3. ★ 마스터 뜻과 맞습니다

```
신차가가 같다면
  스탠다드 + 옵션 700만   트림 20.8 + 옵션 20  =  40.8
  스포츠 깡통            트림 23.1 + 옵션  0  =  23.1
★ 스탠다드가 훨씬 높습니다
```

---

# 4. ★ 트림과 옵션이 하는 일

```
트림 25   이 차가 어느 급인가        — 등급기준가
옵션 20   그 급에서 얼마나 채웠나     — 선택옵션가
★ 둘을 더하면 곧 신차가입니다.  45 가 신차가 총액을 담습니다
```

---

# 5. 개발측이 할 것

```
1  트림별 등급기준가를 낸다
   ★ origin_price − 선택옵션가 합
   ★ 카탈로그가 있어야 옵션가를 뺄 수 있다
2  그 차종 최고 트림 등급기준가를 구한다
3  비율 × 25
4  화면에 — 「스탠다드 6,500만 / 최고 7,800만 (20.8/25)」
5  V3-75
6  ★ GV70_EV 71건으로 확인 — 트림별 점수가 가격 차이를 담는가
```
