
# 4. `null` 원인 역산 (개정 291)

```
필수   축이 NULL 일 때 원인을 자동으로 가른다
       ① 원문을 못 받았다        어느 엔드포인트 · 코드는
       ② 원문은 받았는데 필드가 없다
       ③ 필드는 있는데 값이 null
       ④ 값은 있는데 사전에 없다
       ⑤ 계산에 필요한 다른 값이 없다
필수   화면에 낸다
       「점검부를 받지 못했습니다 (404)」
       「점검부에 틴팅 항목이 없습니다」
필수   원인별 집계를 관리 화면에
       ★ 「404 가 200건」이면 수집을 다시 하면 됩니다
         「원문에 항목 없음이 3,000건」이면 그 축을 접어야 합니다
금지   「확인 못 함」 하나로 뭉치는 것
검산   V3-44
```
