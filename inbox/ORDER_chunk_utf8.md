# 3. 고칠 것

## 3-1. 절단점을 글자 경계로 당긴다 — `[판단]`

```javascript
// admin_collect.html — 자르기 전에 절단점을 물린다
function cut(bytes, off, room) {
  var end = Math.min(off + room, bytes.length);
  // 0b10xxxxxx 는 이어지는 바이트다.  글자 첫 바이트까지 뒤로 물린다
  while (end > off && end < bytes.length && (bytes[end] & 0xC0) === 0x80) {
    end -= 1;
  }
  return end;                    // ★ end === off 면 room 이 너무 작다 — 멈춘다
}
```

```
필수   각 조각이 단독으로 유효한 UTF-8 이어야 한다
근거   그래야 decode → encode 왕복이 무손실이다 (P3)
금지   room 을 키워 해결하는 것 — max_form_bytes 상한은 그대로다
검산   V11-147  모든 절단면의 첫 바이트가 0b10xxxxxx 가 아닌가
```
