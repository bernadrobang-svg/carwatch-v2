```

             수천 장을 받아 두면 디스크와 갱신이 문제가 된다

필수   loading="lazy" — 200행에 200장을 한 번에 받지 않는다
필수   크기를 CSS 로 고정 — 이미지가 오기 전에 칸이 흔들리지 않게
금지   이미지를 서버로 프록시하는 것

```
