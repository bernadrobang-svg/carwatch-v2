---

# 1. 지금 상태

```
전체        3,471건
한 쪽        200건
쪽 수        18쪽
볼 수 있는 것  200건 (5%)
```

**3,271건을 못 봅니다.**

---

# 2. 그런데 200건도 못 봅니다

```
.chips 스타일이 없어 한 행이 화면 하나
200행 × 화면 하나 = 화면 200개 길이
```

**★ 스크롤로 200건을 훑는 것이 불가능합니다.**

---

# 3. 그러므로 순서가 이렇습니다

```
1  .chips 스타일         한 행을 한 줄~세 줄로
2  쪽 넘김               나머지 3,271건을 볼 수 있게
3  「3,471건 중 200건 · 1/18쪽」
```

**1번이 없으면 2·3 을 해도 소용없습니다.**

---

# 4. 쪽 넘김 — 어떻게 낼지

```
필수   앞 · 뒤 · 지금 쪽 번호
       「‹ 이전   3 / 18   다음 ›」
필수   필터·정렬이 걸려 있으면 그것을 유지한 채 넘어간다
       ★ 쪽을 넘겼더니 필터가 풀리면 안 된다
필수   맨 끝에서 「다음」이 안 눌린다
필수   주소에 page 가 들어간다.  새로고침해도 같은 쪽
근거   14장 STEP 149d.  필터가 다음 행동의 조건이다
검산   V11-55  전체 건수와 쪽이 표시되는가
       V11-58  쪽을 넘겨도 필터가 유지되는가
```

---

# 5. 그리고 — 한 쪽 200건이 맞습니까

```
지금   rows_per_page 200
```

```

  한 행이 세 줄이어도 600줄입니다
확인   50 이나 30 이 나은지 실제로 보고 정하십시오
      마스터가 휴대폰으로만 씁니다.  그것이 기준입니다
```

**정하시면 `config/web.json` 의 `rows_per_page` 만 바꾸면 됩니다.**
