# 1. ★ 지금 바로 이것부터 하십시오 — 10분

```bash
# ① 목록이 서버에서 되는가
curl -s -o /dev/null -w "%{http_code} %{size_download}\n" -m 20 \
  "https://m.kcar.com/bc/search/CarList?searchCond=..."

# ② 상세가 되는가
curl -s -o /dev/null -w "%{http_code} %{size_download}\n" -m 20 \
  "https://m.kcar.com/bc/detail/carInfoDtl?i_sCarCd=EC61393706"

# ③ 응답이 HTML 인가 JSON 인가
curl -s -m 20 "https://m.kcar.com/bc/detail/carInfoDtl?i_sCarCd=EC61393706" | head -c 300
```

```
확인   ① 코드가 200 인가 · 403 인가 · 407 인가
      ② HTML 이면 그 안에 데이터가 있는가 · JS 가 나중에 채우는가
      ③ 앵커 6개가 별도 XHR 을 부르는가 — 번들에서 찾으십시오
```
