# 1. ★★★ 결함 ① — 등급 상한이 없습니다

```
G70_20T · 2022-11 · 52,176km · 2,670만
등급 S · 78.0% · 433/555
용도    렌트 이력 (점검부 · 보험 · 번호판 — 세 곳에서 확인)
우수등급  없음
신뢰도   보통
```

```
★ 지금 배점으로는 이렇게 됩니다
  용도 렌트      ② 상태 25점 중 0점
  우수등급 없음   ⑤ 사이트 보증 30점 중 0점
  합쳐 55점 = 555 의 10%
  → 나머지가 좋으면 78% 가 나옵니다
```

**★ 그런데 사람 눈에는 「렌트였던 차가 S」가 말이 안 됩니다.**

## 왜 점수만으로는 안 되나

```
점수는 「전부를 더한 것」입니다.  어떤 흠은 더해서 지워지지 않습니다
★ 감점으로 하면 다른 축이 좋을수록 그 흠이 묻힙니다
★ 상한은 묻히지 않습니다.  「이건 안 된다」가 남습니다
```

## 규격 — 등급 상한

```
렌트·영업용 이력       상한 B
사이트 우수등급 없음    상한 A
자차 미가입 30% 이상   상한 B
점검을 판매자가 등록    상한 A
사고 2회 이상          상한 B
골격 판금·용접         상한 C
```

```
필수   여러 상한이 걸리면 가장 낮은 것
       ★ 위 실측은 렌트(B) + 우수등급 없음(A) → B
필수   상한으로 내려갔으면 화면에 낸다
       「점수는 S 이지만 렌트 이력이 있어 B 로 봅니다」
       ★ 조용히 내리지 않습니다
필수   config — scoring.grade_caps
금지   점수만으로 등급을 정하는 것
검산   V3-60 · V3-61
```

```
★ 사람이 알고 사면 됩니다
  「렌트였지만 값이 싸서 산다」는 사람의 판단입니다
  우리는 「렌트였다」를 감추지 않으면 됩니다
```
