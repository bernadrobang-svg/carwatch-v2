# 1. ★ 옵션 30 — 이것이 0점이던 자리입니다

```
입력   options_choice 의 옵션 코드 · 카탈로그의 코드별 price

식     내 옵션가 합 v = Σ price
      그 차종·트림의 옵션가 합 분포에서 P90 을 기준값 B
      ★ 최대가 아니라 P90 입니다.  최대는 이상치입니다
      score = min(v / B, 1) × 30

예     v=713만 · B=900만  →  23.8
      v=713만 · B=500만  →  30 (상한)
```

## ★ 없을 때 셋을 가릅니다

```
① 옵션이 정말 없다 (options_choice 가 빈 목록)
   →  0점 · 확인됨.  「선택 옵션 없음」
② 옵션은 있는데 카탈로그가 없어 가격을 모른다
   →  ★ 0점 · 확인 안 됨.  「옵션 4종 · 가격 미상」
   ★ 지금 이것이 그냥 0점으로만 나오고 있습니다
③ 그 차종의 P90 을 못 낸다 (표본 5건 미만)
   →  0점 · 확인 안 됨
```

```
필수   B 는 차종·트림 단위.  전 차종을 뭉치지 않는다
       ★ 제네시스와 스포티지의 옵션가 폭이 다릅니다
필수   B 를 화면에 — 「옵션 713만 / 이 트림 기준 900만」
```

# 2. 트림 45 — 식을 명확히 했습니다

```
식   그 차종 트림을 origin_price 오름차순으로 줄 세운다
     내 트림 순위 k · 전체 트림 수 n
     score = (k / n) × 45
없으면 트림이 1종뿐이면 45 를 준다
     ★ 그 차종 안에서 못 가르는 것이지 나쁜 것이 아닙니다
```

# 3. 값 250 — 선형 보간

```
시세 대비 120
  r = (중앙값 − 가격) / 중앙값
  r ≤ −0.20 → 0 · r = 0 → 60 · r ≥ +0.20 → 120 · 사이는 선형

감가 70
  실제 a = 1 − 가격/신차가
  기준 e = 1년 0.12 · 2년 0.22 · 3년 0.33 · 이후 +0.07/년 (상한 0.85)
  d = a − e
  d ≤ −0.10 → 0 · d = 0 → 35 · d ≥ +0.10 → 70

주행 60
  연평균 m = 주행/경과연수
  10,000↓ 60 · 15,000 45 · 20,000 30 · 25,000 15 · 30,000↑ 0 · 사이 선형
전기차   주행 30 + SOH 30 (개정 318)
```
