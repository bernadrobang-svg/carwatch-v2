# ★★★ 개정 367 — 마스터가 못 정합니다

**마스터 지적 — 「이걸 보고 내가 무엇을 하라는 말이지? 뭔지도 모르겠는데」**

---

# 1. 지금 화면

```
detail:advertisement.verification
제안: 사람이 봐야 합니다 · 관측 200/200
```

```
★ 원문 필드 경로일 뿐입니다
★ 무엇인지도 · 무엇을 고르라는지도 없습니다
★ 「사람이 봐야 합니다」는 선택지가 아닙니다
```

**★ 그러면 아무도 못 정합니다. 판정이 영영 막힙니다.**

---

# 2. 한 항목에 이 다섯이 있어야 합니다

```
① 실제 값과 분포
   「true 180건 · false 20건」
   「"우수" 130 · "일반" 45 · null 25」
   ★ 값을 보면 무엇인지 짐작이 됩니다

② 판정에 쓰이는가
   「지금 안 쓰임」 · 「warranty.site 에 쓸 수 있음」

③ 원문에서 어디에 있었나
   「detail 의 advertisement 아래.  옆에 price · status 가 있습니다」
   ★ 옆을 보면 뜻이 잡힙니다

④ 고를 것을 단추로
   [쓴다]  [안 쓴다]  [나중에]

⑤ 안 정하면 무엇이 막히나
   「판정이 막힙니다」 · 「막지 않습니다 — 그냥 안 씁니다」

금지   경로만 내고 「사람이 봐야 합니다」라 하는 것
검산   V4-28
```

---

# 3. ★ 판정 막는 것만 먼저

```
지금   「사람이 봐야 할 것 120건」
```

```
필수   기본 화면은 판정을 막는 32건만
필수   나머지는 접는다 — 「지금 안 봐도 되는 것 88건」
       ★ 120건을 한꺼번에 보라 하면 아무도 안 봅니다
필수   많이 관측된 순으로
필수   ★ 같은 뜻으로 보이는 것을 묶어 한 번에
       「advertisement.verification 계열 4개를 함께 정합니다」
검산   V4-29
```
