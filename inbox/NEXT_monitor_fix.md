# 2. `STEP 136f` — `/admin/status` 신설

## 무엇을 내는가

```
① 지금 도는 것
   단계 (S5 · S6 · S9 · S10 · S7) · 요청/완료/실패
   경과 시간 · 남은 것 추정 · 마지막으로 처리한 매물

② 방금 끝난 것
   무엇이 · 언제 · 몇 건 · 실패 몇

③ 숫자가 어떻게 변했나
   raw_response · core_listing · result_score
   ★ 「받았다」와 「쓰였다」를 함께 (개정 268)

④ 실패
   무엇이 왜.  「로그를 보십시오」라고 하지 않는다
```

## 규칙

```
필수   스스로 갱신한다 (status_poll_sec · 기본 5)
필수   갱신 간격과 마지막 갱신 시각을 화면에
필수   폴링 실패해도 진행은 남는다 — 「연결이 끊겼습니다 · 마지막 확인 HH:MM」
필수   「대기 중」과 「멈춘 것」을 가른다
       마지막 처리가 N분 전이면 「N분째 진척 없음」
필수   읽기 전용
필수   JS 가 꺼져도 새로고침하면 지금 상태가 보인다
금지   ★ 실행 단추를 이 화면에 두는 것
금지   진행이 없는 동안 빈 화면
검산   V11-51 · V11-52
```
