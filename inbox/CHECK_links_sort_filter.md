# 3. 정렬 — 규격은 맞는데 마스터 요구가 안 들어갔습니다

```sql
ORDER_HEAD = CASE WHEN grade IN ('E','NOT_RATED') THEN 1 ELSE 0 END
ORDER_TAIL = earned/denominator DESC, price ASC, listing_id ASC
```

```
E · NOT_RATED 는 뒤로   ○ 규격대로
비율 높은 순             ○ 규격대로
```

## ★ 다만 C·D 가 여전히 앞에 섞입니다

```
비율 순이므로 C 도 D 도 A·B 사이에 섞입니다
마스터 지적 — 「볼 필요 없는 C·D·미분류가 잔뜩」
```

```
필수   「A 이상만」 · 「B 이상만」 단추를 두십시오 (STEP 149s)
       한 번 누르면 C 이하가 사라집니다
필수   기본으로 무엇이 걸려 있는지 적으십시오
검산   V11-65
```
