# 3. ★★ 「시세차」 — 판정 신뢰성 문제

```
마스터 「시중가보다 1000만원 비싼데 S 등급이네」
화면   2,990만 · 시세차 −1,337만 · 90.7% S
```

**시세차가 −1,337만인데 사람이 보기에 비싸다면, 「시세」가 실제 시세가 아닙니다.**

```
지금   시세차 = 감가 곡선의 이론가 − 실제가 (STEP 70)
문제   이론가가 실제 시장보다 높으면 전부 「싸다」로 나온다
       그러면 「싸다」가 아무 뜻이 없다
```
