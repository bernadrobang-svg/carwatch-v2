# ★★★ 분모는 고정이다 — 개정 289

**마스터 지적 — 「못 찾은 것은 니 사정이지. 왜 평가를 왜곡하니」**

---

# 1. 무엇이 무논리였나

```
축을 못 보면 분모에서 뺐다
→ 못 볼수록 비율이 올라간다
→ 못 찾을수록 좋은 등급을 받는다
```

```
330/350 = 94.3%  →  S
330/555 = 59.5%  →  D
```

**★ 우리가 데이터를 못 받은 것을 그 매물의 장점으로 만들었습니다.**

---

# 2. 규격

```
필수   분모는 만점 그대로다.  555 다.  예외 없다
필수   못 본 축은 0점이다
       ★ 「우리가 못 받았다」는 그 차의 사정이 아니라 우리 사정이다
필수   왜 0점인지는 화면에 낸다 — 사람이 판단할 재료다
       missing · no_mention · expected_unavailable
필수   「555점 중 330점.  205점은 확인하지 못했습니다」를 함께 낸다
금지   분모를 줄이는 것.  어떤 사유로도
금지   excluded 를 분모 조정에 쓰는 것
       ★ excluded 는 「왜 0점인가」의 사유로만 남긴다
검산   V3-41  전 매물의 분모가 만점과 같은가 — 하나라도 다르면 fatal
```

---

# 3. ★ 이것이 뜻하는 것

```
정보가 적은 매물은 낮은 점수를 받는다.  그것이 맞다
「모르는 차」와 「좋은 차」는 다르다
판매자가 정보를 안 주는 것도 그 매물의 성질이다
```

```
★ 등급이 전반적으로 내려갑니다.  그것도 맞습니다
  지금 등급이 부풀려져 있었을 뿐입니다
```

---

# 4. ★ 등급 경계를 다시 잡아야 합니다

```
필수   분모가 바뀌면 경계도 바뀌어야 한다
필수   실측으로 정한다
```

**실측해 주십시오.**

```
1  전 3,470건을 분모 555 로 다시 계산하십시오
2  비율 분포를 내십시오
   최저 · P10 · P25 · 중앙 · P75 · P90 · 최고
3  지금 경계(S·A·B·C·D)로 매기면 각 등급이 몇 건입니까
4  ★ 그 분포를 보고 경계를 다시 제안하십시오
   예   S 는 상위 1% · A 는 5% · B 는 20% …
   ★ 근거와 함께
```

---

# 5. 미확정 하나 — 차종 특성

```
예   전기차에 엔진보증 · 디젤에 LPG 관련 축
```

```
★ 이것도 0점으로 하면 그 차종이 통째로 불리해집니다
★ 그렇다고 분모를 줄이면 위 규격을 어깁니다
미확정   배점을 차종별로 둘 것인가
        아니면 전 차종 공통 축만 쓸 것인가
필수    정해질 때까지는 0점.  분모를 줄이지 않습니다
```

**★ 이건 §4 의 실측을 보고 정하겠습니다.**
**전기차가 실제로 얼마나 불리해지는지 숫자로 봐야 합니다.**
