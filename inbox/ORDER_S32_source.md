# 1. 다섯 층

|---|---|---|---|
| **`[마스터]`** | 마스터가 정한 것 | **마스터만** | **★ 최우선 결함** |
| **`[시안]`** | `ref/screens/` · `ref/v1-ui/` | **마스터만** | **★ 최우선 결함** |
| `[원문]` | 사이트가 주는 것 | 못 바꿈 | 사실과 어긋남 |

| **`[판단]`** | **가이드가 정한 것** | 가이드 | ★ 가장 틀리기 쉽다 |
| `[기술]` | 기술 제약 | 마스터 승인 | 0장 원칙 |
