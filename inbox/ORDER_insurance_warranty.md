# ★★★ 자차 미가입 · 보증 정리 — 개정 294·295

**마스터 물음 — 「자차보험을 들지 않은 차와 든 차를 구분 가능해?」**

---

# 1. ★ 구분할 수 있습니다. 그리고 이것이 큰 함정입니다

## 조사한 것

```
「자차 미가입 기간이 있거나 사고 이후 자비로 수리하는 경우,
 보험 이력에 남지 않아 구매자는 이를 모를 수밖에 없다」

「이 차량은 5년간 자차보험에 미가입되어 있었기 때문에
 이 기간 동안 어떤 사고가 났는지는 전혀 알 수 없습니다」
 — 렌터카로 쓰인 기간이었다

「보험이력 없음이 곧 완전 무사고를 뜻하지는 않습니다」
```

**★ 카히스토리 이력에 「자차 가입 기간」이 나옵니다.**

## 「내차 피해 0원」은 두 가지 뜻입니다

```
① 자차 가입 상태로 사고가 없었다     ←  진짜 무사고
② 자차 미가입이라 기록이 안 남았다   ←  알 수 없음
★ 지금 우리는 ②를 「무사고」로 읽고 있습니다
```

---

# 2. 규격 — 개정 294

```
필수   자차 가입 기간을 원문에서 확인한다
필수   미가입 기간이 있으면 낸다
       「자차 미가입 5년 — 그 기간의 사고는 알 수 없습니다」
필수   「무사고」를 세 갈래로
       무사고        자차 가입 전 기간 · 이력 없음      O
       사고 N회      이력에 있음                       -
       확인 불가      자차 미가입 기간이 있음            ?
       ★ A-4 의 O · - · ? 가 여기에도 적용됩니다
필수   미가입 30% 이상이면 「확인 불가」로 — 만점을 주지 않는다
금지   자차 미가입 차를 「무사고」로 내는 것
검산   V3-49
```

```
★ 이 도구의 목적과 직결됩니다
  값이 싼 이유가 「자차 미가입 기간이 길어서」일 수 있습니다
  그것을 모르면 「싸고 무사고」로 보입니다
```

# 5. 보증 정리 — 아직 안 됐습니다

**마스터 물음 — 「보증에 대한 정리는 차종별로 다를 건데 잘 정리가 되었지?」**

**★ 아직입니다. 확인이 먼저입니다.**

```
1  원문 어디에 보증이 있습니까
   manage · inspection · category 중 어디입니까
   ★ 필드 이름과 형식

2  무엇이 나옵니까
   일반보증 만료일 · 동력계 보증 만료일 · 주행거리 조건
   ★ 제조사마다 다릅니다
     현대·기아  일반 3년/6만 · 동력계 5년/10만

     테슬라     4년/8만 · 배터리 8년/16만
   ★ 원문에 실제 값이 있으면 그것을 씁니다
     없으면 제조사별 표를 config 로 둡니다

3  차종별로 보증 필드가 채워진 비율을 내십시오
   ★ 개정 293 의 「축 × 차종」 표에 이것도 넣으십시오
```
