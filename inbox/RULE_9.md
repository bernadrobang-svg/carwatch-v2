
---

## 규칙 9

```
작업을 시작하기 전에 항상 git pull 한다.

inbox/ 에 새 파일이 있으면 규칙 5 대로 처리한다
  ① 읽는다  ② docs/ 는 이미 반영돼 있다  ③ 처리 후 지운다
  ④ 무엇을 읽었는지 보고한다  ⑤ 지금 작업과 어긋나면 멈추고 묻는다

docs/ 는 가이드가 직접 push 한다.
  tar.gz 를 풀 필요가 없다. 이미 파일로 들어와 있다
  ★ 너는 여전히 docs/ 를 고치지 마라 (규칙 2). 읽기만 해라
  정정이 필요하면 보고해라 — 지금까지와 같다

push 하기 전에 git pull --rebase 한다.
  가이드와 네가 같은 시각에 쓰면 충돌한다
  docs/ 는 가이드만, 그 밖은 너만 쓰므로 실제 충돌은 드물다
```
