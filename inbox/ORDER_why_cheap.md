# 2. 개정 299 — 「왜 싼가」를 말한다

```
필수   「싸다」를 말할 때 「왜 싼가」를 함께 낸다

       ① 플랫폼 진단·보증이 없다
       ② 성능점검을 판매자가 올렸다
       ③ 렌트·리스 이력

       ⑥ 인기 없는 색 · 트림

       「싼 이유를 찾지 못했습니다.  직접 확인하십시오」
       ★ 그것이 오히려 위험 신호입니다
금지   「시세차 −1,100만」만 내고 끝내는 것
```

# 3. 개정 300 — 점검의 출처

```
엔카직영 점검   엔카가 직접 · 플랫폼이 책임진다
판매자 등록     「모든 책임은 판매자에게 있습니다」   ← 실물 문구
```

```
필수   플랫폼 신뢰도로 낸다
       높음   엔카진단 · 엔카보증 · 엔카직영 점검
       보통   엔카직영 점검만
       낮음   판매자 등록 점검만
       없음   점검 자체가 없음
필수   화면에 그대로 — 「점검을 판매자가 올렸습니다」
근거   ★ 같은 값이라도 누가 보증하느냐가 다릅니다
검산   V3-53
```
