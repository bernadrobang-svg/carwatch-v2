# 3. 규칙 10 — 이렇게 읽는다

```
필수   작업을 시작하면 INDEX.md 를 먼저 본다 (2KB)
       ★ 「어느 파일에 무엇이 있나」가 거기 있다
필수   고칠 소스가 정해져 있으면 MAPPING.md 로 챕터를 찾는다 (3KB)
       예   score/ 를 고친다  →  30-score/
필수   그 챕터만 연다.  다른 것을 열지 않는다
필수   STEP 번호를 알면 INDEX 의 「STEP 범위」로 파일을 짚는다
       예   STEP 149 → 61-web.md

필수   부록은 그때만 연다
       A-check   검사 목록을 볼 때
       B-config  설정 키를 볼 때
       E-attach  원문 구조를 볼 때

금지   docs/ 전체를 읽는 것
금지   guide/03_이력.md 를 통째로 읽는 것 (58KB · 개정 292건)
       ★ 특정 개정을 찾을 때는 grep 으로 그 줄만 본다
       예   grep -n "개정 289" docs/guide/03_이력.md
```

---

# 4. ★ 검색으로 찾는다

```
필수   「이 규칙이 어디 있나」는 grep 으로 찾는다
       grep -rn "분모" docs/chapters/30-score/
       grep -rn "V11-79" docs/
필수   찾은 뒤 그 파일의 그 절만 읽는다
       ★ 파일 전체를 열지 않아도 된다
```

**예시.**

```
「배점을 고쳐라」
  → grep -rn "배점" docs/INDEX.md docs/MAPPING.md
  → 30-score/a-frame.md 를 연다 (19KB)
  → 다른 52파일은 안 연다
```

# 6. 확인해 주십시오

```

   ★ 매번 docs/ 를 통째로 읽습니까
   ★ 아니면 필요한 것만 엽니까
```

**★ 3번이 중요합니다.**
**색인이 쓸모없으면 그건 제 잘못입니다. 고쳐야 합니다.**
