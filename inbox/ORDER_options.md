# ★★ 옵션 — 개정 288

**마스터 지적 — 「제네시스는 트림 대신에 옵션으로 차값을 결정한다」**

---

# 1. 원문에 다 있습니다

```
options.choice        그 차에 달린 선택 옵션 (상세)
카탈로그
  "optionCd"   : "1009"
  "optionName" : "BOSE 서라운드 사운드 시스템(10 스피커) + …"
  "price"      : 129        ★ 옵션마다 가격이 있습니다 (만원)
category.originPrice   트림 신차가
```

**★ 우리가 147건의 카탈로그를 이미 받아 뒀습니다.**

---

# 2. ★ `spec` 축과 옵션은 다릅니다

```
spec.hud     판정용 — 있나 없나.  점수를 준다
옵션 목록     값 결정 — 얼마짜리가 달렸나.  신차가를 만든다
```

```
★ 둘을 섞지 않습니다
  「HUD 있음」과 「HUD 패키지 129만」은 다른 말입니다
```

---

# 3. 규격

```
필수   매물마다 달린 선택 옵션을 낸다 — 이름 · 가격 · 합계
       예   BOSE 사운드 129만 · 파노라마 선루프 130만 · … 합 512만
필수   신차가의 구성을 밝힌다
       「트림 기본 5,470만 + 선택 옵션 512만 = 5,982만」
       ★ 그래야 「지금 2,990만」이 얼마나 떨어진 것인지 압니다
필수   옵션가를 모르면 「옵션 5종 · 가격 미상」
필수   목록은 합계와 개수만 — 「옵션 5종 512만」
       상세(/why)에서 이름을 다 냅니다
필수   옵션 차이가 큰 차종은 알립니다
       「이 차종은 옵션에 따라 신차가가 N만 ~ M만입니다」
검산   V11-88 · V11-89
```

---

# 4. ★ 그리고 「시세」와 이어집니다

```
같은 트림 1,223건의 중앙값이 3,750만이라 해도
그 안에 옵션 512만짜리와 0원짜리가 섞여 있습니다
★ 옵션을 모르면 「싸다」를 판단할 수 없습니다
```

```
필수   시세를 낼 때 옵션가를 어떻게 다룰지 정합니다
       ① 그대로 섞어 낸다 (지금) — 다만 「옵션 차이가 섞여 있다」를 적는다
       ② 옵션가를 뺀 값으로 낸다
       ③ 옵션 구간별로 나눠 낸다
★ ①로 하되 그 사실을 밝히는 것이 먼저입니다
```
