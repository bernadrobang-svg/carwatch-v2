# 2. 사이트마다 세 칸

## ① 검색 필터

```
항목명 · 선택지 전부 · 개수
★ 「옵션 79개」처럼 뭉치지 말고 전부 적는다
★ 선택지 옆에 매물 수를 함께 주는 사이트는 그것도 적는다
정렬 종류 · 쪽당 개수 · 최근검색 저장 여부
```

## ② 목록 한 행에 표시되는 항목

```
왼쪽부터 오른쪽까지 순서대로 전부
★ 배지 · 단추 · 아이콘도 항목이다
★ 딜러 홍보문구 · 조회수 · 찜 수처럼 차량 정보가 아닌 것도 적는다
```

## ③ 매물 상세에 표시되는 항목

```
★ 절 단위로 나눠 적는다 (사진 / 머리 / 가격 / 기본정보 / 제원 / 옵션 / 판매자 …)
★ 절마다 항목을 전부 나열한다
★ 팝업으로 열리는 것도 적는다 (성능기록부 · 보험이력 · 등록증 …)
★ 계산해서 보여주는 값을 반드시 표시한다
  예 — 보배드림 「신차대비 65%」 · 「총비용 계산기」
```

# 3. 규칙

```
필수   ★ 원문 화면을 직접 열어 뽑는다
필수   스크린샷을 함께 남긴다 — outputs/sites/shot/{사이트}_{목록|상세}.png
필수   ★ 막히면 「막힘 — 사유」라 적는다.  짐작으로 채우지 않는다
       엔카는 자동 접속을 막는다 (실측 — 「비정상적인 트래픽」)
필수   같은 항목이라도 사이트가 부른 이름 그대로 적는다
       ★ 우리 말로 바꾸지 않는다.  이름 차이가 자료다
금지   ★ 해석 · 평가 · 「이게 좋다/나쁘다」를 적는 것
금지   항목을 요약하거나 대표만 적는 것
금지   API 를 뒤져 필드명을 적는 것 — ★ 화면에 보이는 것만이다
```

# 4. 산출

```
outputs/sites/01_엔카.md  …  20_카바조.md          20개
outputs/sites/_합집합.md                            1개
outputs/sites/shot/                                스크린샷
```

## `_합집합.md` 형식

| 항목 | 쓰는 사이트 수 | 어디 | 우리에게 있나 |
|---|--:|---|:--:|
| 신차대비 % | 3 / 20 | 보배드림 · … | ✗ |
| 시트(내장) 색상 | 2 / 20 | KB차차차 · … | 배지만 |
| 제로백 | 1 / 20 | 보배드림 | ✗ |

```
필수   ★ 「우리에게 있나」 칸은 CarWatch 화면 기준으로 적는다
       ○ 화면에 있다 · △ 데이터는 있는데 화면에 없다 · ✗ 없다
필수   많이 쓰는 순으로 정렬한다
```
