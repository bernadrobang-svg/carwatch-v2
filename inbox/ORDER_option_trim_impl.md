# 5. ★ 비교 (/compare) — 여기가 핵심입니다

```
필수   옵션 차이만 냅니다.  같은 것은 접습니다
       「A 에만 있음   파노라마 선루프 140만 · 드라이빙 어시스트 150만」
       「B 에만 있음   2열 컴포트 패키지 250만」
       「둘 다 있음    3종 (접기)」
필수   차이의 값 합계를 냅니다 — 「A 가 290만어치 더 있습니다」
필수   트림이 다르면 그것을 먼저 냅니다
       ★ 트림이 다르면 옵션 비교가 뜻이 흐려집니다
검산   V11-102
```

```
★ 같은 트림이면 옵션이 값을 가릅니다
  비교 화면이 그것을 보여 주지 못하면 비교가 아닙니다
```
